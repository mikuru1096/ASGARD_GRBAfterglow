\begin{abstract}
Interpreting multiwavelength \grb\ afterglows requires more than a final light curve when density structure, reverse shocks, inverse-Compton cooling, hadronic channels, or secondary pairs are active.  We present \asgard, a Python/Fortran afterglow model that evolves a radius-ordered local physical state and only then projects that state to observer time.  The implemented model supports top-hat, Gaussian, and power-law jet initial profiles; uniform, \(k=2\) wind, and tabulated external media; implicit, characteristic, discontinuous-Galerkin, and selected \(\chi\)-resolved electron solvers; forward-shock synchrotron and SSC emission; optional one-dimensional hadronic transport with secondary feedback; optional magnetized and density-jump reverse-shock diagnostics; and component-resolved observer projection.  The central contribution is the explicit state contract: dynamics, electrons, photon fields, hadronic species, reverse-shock variables, absorption factors, and observer components are carried as inspectable objects rather than being collapsed directly into \(F_\nu(t_{\rm obs})\).  The present release is a methods baseline with explicit boundaries.  Formal hadronic feedback is one-dimensional, \(\chi\)-resolved hadronic transport and IC-mediated electromagnetic cascades are not implemented, user-defined media do not enter the Fortran transport kernels, wind profiles with \(k\ne2\) are rejected, and jet spreading is outside the current backend.
\end{abstract}

\section{Introduction} \label{sec:intro}

Gamma-ray burst afterglows are commonly interpreted as synchrotron radiation from nonthermal particles accelerated by a relativistic blast wave \citep{MeszarosRees1997,Sari1998,Granot2002}.  The basic inference problem has expanded during the past decade.  Structured jets, off-axis viewing, reverse shocks, polarization, inverse-Compton emission, density structure, and possible hadronic components are all used in current afterglow modeling \citep{SariPiran1999,Kobayashi2000,ZhangKobayashi2005,ChevalierLi2000,Murase2007,GillGranot2018Polarization,vanEerten2018BlastWaves,Salafia2022JetStructure}.  The observational motivation is concrete.  GRB 170817A required structured-jet and off-axis calculations and has continued to constrain late-time jet dynamics \citep{Troja2017GW170817Xray,Hallinan2017GW170817Radio,LambKobayashi2017Structured,Mooley2018WideAngle,Mooley2018Superluminal,Lazzati2018CollimatedJet,Margutti2018GW170817,Alexander2018GW170817,Ghirlanda2019StructuredJet,Troja2019GW170817,Hajela2022GW170817,Katira2025GW170817,Ryan2024}.  GRB 190114C, GRB 190829A, and GRB 221009A made high-energy afterglow components and narrow structured-jet interpretations part of routine model comparison \citep{MAGIC2019TeV,MAGIC2019IC,HESS2019VHE,HESS2021GRB190829A,LHAASO2023TeVAfterglow,LHAASO2023Beyond10TeV,Laskar2023GRB221009A,OConnor2023GRB221009A}.

This paper has a narrower purpose than a review of those data.  It records the physical contract implemented by the present \asgard\ model.  The central claim is that, in afterglow calculations where intermediate states matter, \asgard\ provides a radius-ordered state chain for dynamics, electrons, photon fields, optional hadrons, optional reverse shocks, and observer projection.  Claims outside that state chain are treated as unsupported boundaries.

Several published codes define the context.  \afterglowpy\ provides efficient synchrotron flux calculations for structured jets and off-axis geometries \citep{Ryan2020}.  \jetsimpy\ emphasizes hydrodynamically motivated thin-shell evolution and lateral structure \citep{Wang2024Jetsimpy}.  \vegas\ provides a useful reference for organizing an afterglow code paper around jets, media, dynamics, radiation, geometry, examples, and performance, and for reverse-shock jump-condition calculations \citep{Wang2025VegasAfterglow}.  \pyblast\ is a modular multiphysics blast-wave framework for transient counterparts \citep{Nedora2025PyBlastAfterglow}.  \asgard\ is complementary to these tools: it is organized around inspectable local state and component accounting, not around replacing a faster light-curve model.

The manuscript follows the calculation order used by modern afterglow code papers, but shifts the emphasis to \asgard's radius-local state ledger.  Section~\ref{sec:contract} defines the public input model and the state variables written by each stage.  Section~\ref{sec:dynamics} gives the jet, medium, energy-injection, and dynamics layer.  Sections~\ref{sec:electron}--\ref{sec:reverse-shock} give the radiation and feedback layers: electron transport, photon-field assembly, hadronic transport, and reverse-shock branches.  Section~\ref{sec:projection} gives the geometry and equal-arrival-time projection.  Section~\ref{sec:fitting} records the fitting and runtime contract.  Section~\ref{sec:verification} replaces a feature showcase with figure-backed state diagnostics and benchmark evidence.  Section~\ref{sec:limits} states unsupported combinations.

\section{Model Contract and State Variables} \label{sec:contract}

The methodological choice in \asgard\ is to evolve a local physical state before computing observer products.  This choice is motivated by a specific limitation of flux-only afterglow calculations: once angular structure, density changes, reverse shocks, inverse-Compton losses, or hadronic secondaries are active, a final light curve no longer identifies which local state variable or component produced a feature.  A calculation that exposes only \(F_\nu(t_{\rm obs})\) can still fit data, but it cannot by itself distinguish a dynamical break, an angular-projection effect, a cooling transition, a component crossing, or a photon-survival effect.  The relevant physical operations are therefore kept at the shock-radius level until the local source terms and absorption factors have been assembled \citep{Granot2002,vanEerten2010,vanEerten2012,vanEerten2018BlastWaves,Salafia2022JetStructure}.

The radius coordinate is also the natural coordinate for the implemented couplings.  The blast-wave state fixes \(n(R)\), \(\Gamma(R)\), \(B'(R)\), the swept mass, and the internal energy; the electron equation, seed synchrotron field, synchrotron self-absorption, \(p\gamma\), Bethe-Heitler, \(pp\), and \(\gamma\gamma\) terms are then evaluated against that same local shell state.  Observer time is introduced only after this step, through Doppler and equal-arrival-time projection.  This separation matters for off-axis and structured jets because different angular cells map the same radius sequence to different observer-time sequences, and it matters for high-energy branches because the target photon field and photon survival are local shell quantities before projection \citep{Ryan2020,Murase2007,GouldSchreder1967,Svensson1987}.

This motivation also sets the limits of the paper.  \asgard\ is not presented as a replacement for faster afterglow light-curve codes.  Its role is to make a coupled afterglow calculation inspectable: dynamics, electrons, photon fields, optional hadrons, optional reverse shocks, and observer components are carried as one state chain.  The same methodological choice forces explicit rejection boundaries.  If a physical combination is not represented by a supported state chain, the manuscript treats it as unsupported rather than interpreting an interpolated or partial product as a modeled prediction.

\asgard\ separates model construction from kernel execution.  This section is the input-model layer of the paper: before any radiation equation is evaluated, it defines what a model contains and which state each stage is allowed to write.  A calculation is specified by a jet profile, external medium, observer, forward-radiation parameters, numerical grid, and optional reverse-shock and hadronic parameters.  These inputs are normalized once and then passed through a fixed state chain.  The returned state stores the dynamics, electron distribution, photon fields, optional hadronic solution, optional reverse-shock emission, observer state, and component fluxes.

The execution order is fixed:
\[
\begin{aligned}
\text{public inputs}
&\rightarrow
\text{runtime configuration}
\rightarrow
\text{dynamics}
\rightarrow
\text{electron}
\\
&\rightarrow
\text{photon field}
\rightarrow
\text{hadronic stage}
\rightarrow
\text{reverse-shock emission}
\rightarrow
\text{observer assembly}.
\end{aligned}
\]
If joint electron-photon coupling is requested, the electron and hadronic stages are iterated inside this sequence, but the observer stage still comes after local source terms and absorption have been assembled.

The local state can be summarized as
\[
\mathcal{S}(R)=
\left\{
\Gamma,\mathcal{M}_{\rm sw},U,B',
N_e,n_\gamma,N_p,N_\pi,N_\mu,
Q_{e,{\rm sec}},\tau_{\gamma\gamma},L_\nu^{\rm comp}
\right\}.
\]
The set is not meant to imply that every member exists in every run.  It is the contract for stages that are active: one-dimensional leptonic calculations populate only the forward-shock electron, photon, and synchrotron/SSC component fields; formal hadronic calculations add proton, pion, muon, neutrino, photon-loss, and secondary-pair fields; reverse-shock calculations add a separate region-3 state before observer assembly.

The observer products include multi-frequency fluxes, spectra, band-integrated fluxes, exposure-averaged fluxes, sky images, polarization curves, component-resolved fluxes, and diagnostic state tracks.  The component ledger contains total flux, forward-shock synchrotron and SSC components, reverse-shock synchrotron and SSC components, optional cross-zone inverse-Compton emission, optional hadronic synchrotron, optional pair-production synchrotron, and optional neutrino outputs when the relevant branch is active.  The detailed state exposes radius, Lorentz factor, magnetic field, electron spectra, \(\chi\)-resolved electron fields, hadronic species, photon-survival factors, reverse-shock state, and secondary reverse-shock event diagnostics when those stages are active.

The model contract is intentionally restrictive.  A user-defined medium can evaluate a density in Python, but it cannot be dispatched into the Fortran transport kernels unless it is one of the supported kernel media.  The structured backend rejects jet spreading.  Adaptive observer-time grids are currently limited to direct top-hat kernel-backed models.  These checks prevent unsupported physical combinations from being interpreted as modeled behavior.

\section{Dynamics, Media, and Jet Initialization} \label{sec:dynamics}

\subsection{Implemented external media}

The external medium enters the dynamics as one of three supported profiles: a uniform medium, a \(k=2\) stellar-wind medium, or a tabulated radial profile.

For a uniform medium, the proton number density is
\[
n(R)=n_{\rm ISM},
\]
with no wind component.

For a wind medium, only \(k=2\) is implemented.  The density module first forms the Chevalier--Li profile
\[
n_w(R)=\frac{A}{m_pR^2},
\qquad
A=5\times10^{11}A_\ast\ {\rm g\ cm^{-1}},
\]
which is numerically \(n_w\simeq3.0\times10^{35}A_\ast R^{-2}\ {\rm cm^{-3}}\) in cgs units \citep{ChevalierLi2000}.  The implemented baseline then switches to the ISM density when the wind has fallen below one quarter of the ISM value:
\[
n_{\rm base}(R)=
\begin{cases}
n_{\rm ISM}, & n_w(R)\le n_{\rm ISM}/4,\\
n_w(R), & n_w(R)> n_{\rm ISM}/4,
\end{cases}
\]
where the factor of four is an explicit wind-to-ISM transition boundary rather than a smoothed termination-shock solution.  If the public wind model is given a positive density cap \(n_{\rm cap}\), the Python setup converts it to the radius
\[
R_0=\left(\frac{A}{m_p n_{\rm cap}}\right)^{1/2}.
\]
The compiled density kernel receives only this radius.  For \(R<R_0\), it overwrites the density after the base-profile and jump logic with the unperturbed inner value: analytic wind media use \(n_w(R_0)\), uniform media use \(n_{\rm ISM}\), and tabulated media use the log-log table value at \(R_0\).  The cap is therefore a hard inner-radius state, not an additional Gaussian enhancement.  A wind profile with \(k\ne2\) is outside the implemented model.

For a tabulated medium, the model stores two strictly increasing positive arrays, \(R_i\) and \(n_i\), with at most 96 points.  The density is log-log interpolation,
\[
n(R)=
\exp\left[
\operatorname{interp}\left(\ln R;\,\ln R_i,\,\ln n_i\right)
\right].
\]
Equivalently, between the bracketing points \(i\) and \(i+1\),
\[
n(R)=
n_i
\left(\frac{R}{R_i}\right)^{
\ln(n_{i+1}/n_i)/\ln(R_{i+1}/R_i)
}.
\]
The implementation uses the first two table points for \(R<R_1\) and the last two points for \(R>R_N\), so this is a power-law extrapolation outside the tabulated range, not a clamp.  When a tabulated profile is active, the density-jump enhancement described below is not applied.

Density jumps are represented separately from the base medium and are applied only when the caller requests the jump-bearing density.  The implemented multi-jump form is an additive Gaussian multiplier,
\[
n(R)=n_{\rm base}(R)
\left[
1+\sum_j
(f_j-1)
\exp\left(
-\frac{(R-R_j)^2}{2(w_jR_j)^2}
\right)
\right].
\]
The legacy single-jump path is the same formula with \(R_j=R_{\rm tr}\), \(f_j=f_{\rm jump}\), and \(w_j=f_{\rm wide}\).  The public field name \texttt{jump\_width\_log10} is a historical ABI name; in the compiled density kernel the value is a linear fractional width, \(\sigma_{R,j}=w_jR_j\), not a logarithmic width.  The jump radii, factors, and fractional widths must be positive and have matching lengths.  Because the current multi-jump contract adds the Gaussian excesses before multiplying the base density, overlapping strong density drops are physically meaningful only while the bracketed enhancement remains positive.  This representation is motivated by afterglow density-structure work, but the manuscript does not interpret every Gaussian bump as a unique astrophysical environment without a separate model comparison \citep{DaiLu2002,NakarGranot2007,UhmZhang2014}.

The density module is configured once per dynamics or transport call by unpacking the runtime boundary vector.  It supports at most eight Gaussian density structures and at most 96 tabulated medium points.  The setup step rejects nonpositive jump radii, factors, or widths; nonpositive table radii or densities; a one-point table; and non-monotonic table radii.  These are boundary conditions on the medium definition, not additional physics.

\subsection{Implemented jet profiles}

The implemented jet profiles are top-hat, Gaussian, and power-law initial angular profiles.  They specify isotropic-equivalent energy and initial Lorentz factor as functions of polar angle.  The top-hat profile uses
\[
E_{\rm iso}(\theta)=
\begin{cases}
E_0, & \theta<\theta_j,\\
0, & \theta\ge\theta_j,
\end{cases}
\qquad
\Gamma_0(\theta)=
\begin{cases}
\Gamma_0, & \theta<\theta_j,\\
1, & \theta\ge\theta_j.
\end{cases}
\]
The Gaussian constructor uses
\[
E_{\rm iso}(\theta)=E_c\exp\left[-\frac{1}{2}\left(\frac{\theta}{\theta_c}\right)^2\right],
\qquad
\Gamma_0(\theta)=1+(\Gamma_c-1)
\exp\left[-\frac{1}{2}\left(\frac{\theta}{\theta_c}\right)^2\right],
\]
with an outer angular support stored as \(\theta_{\max}\).  The power-law constructor uses
\[
E_{\rm iso}(\theta)=
E_c
\begin{cases}
1, & \theta\le \theta_c,\\
(\theta/\theta_c)^{-k_E}, & \theta>\theta_c,
\end{cases}
\]
and
\[
\Gamma_0(\theta)=
\begin{cases}
\Gamma_c, & \theta\le \theta_c,\\
1+(\Gamma_c-1)(\theta/\theta_c)^{-k_\Gamma}, & \theta>\theta_c.
\end{cases}
\]
The power-law profile sets \(k_\Gamma=k_E\) unless a separate Lorentz-index argument is supplied.  These are initial angular profiles; the current backend does not implement lateral spreading.

\subsection{Forward dynamics variables}

The forward dynamics integrate the state
\[
Y=(\Gamma,\mathcal{M},U,R)
\]
over the source-frame on-axis arrival-time coordinate \(T\), where the output observer time is \(T_{\rm obs}=T(1+z)\).  The radius derivative used by all three dynamics branches is
\[
D_R\equiv\frac{dR}{dT}
=\frac{\beta c}{1-\beta},
\qquad
\beta=\sqrt{1-\Gamma^{-2}}.
\]
The dynamics branch computes a local magnetic field estimate from the shocked energy density.  With \(e'_{\rm sh}\simeq4(\Gamma^2-1)n(R)m_pc^2\),
\[
B'=\left(8\pi\epsilon_B e'_{\rm sh}\right)^{1/2}
=\left[32\pi\epsilon_B n(R)m_pc^2(\Gamma^2-1)\right]^{1/2}.
\]
The cgs coefficient used internally is therefore fixed by \(\sqrt{32\pi m_pc^2}\), not by a fit to a light curve.  The corresponding synchrotron-cooling Lorentz factor is
\[
\gamma_c=
\frac{6\pi m_ec}{\sigma_T B'^2\Gamma T},
\qquad
\gamma_m=
1+\frac{\epsilon_e}{f_e}
\frac{m_p}{m_e}
\frac{p-2}{p-1}
(\Gamma-1).
\]
If \(\gamma_c>\gamma_m\) and \(p\ge2\), the dynamics branch uses the effective radiative fraction
\[
\epsilon_{\rm eff}=\epsilon_e\left(\frac{\gamma_m}{\gamma_c}\right)^{p-2};
\]
otherwise \(\epsilon_{\rm eff}=\epsilon_e\).  This cooling diagnostic is used only inside the dynamics branch; the later electron transport evolves the electron distribution explicitly.

The early logarithmic grid is placed using the deceleration-scale variables
\[
\mathcal{D}_0=
\frac{E_{\rm iso}}{(\eta_0-1)4\pi m_pc^2},
\]
\[
R_{\rm dec,ISM}=
\left(\frac{n_{\rm ISM}\eta_0}{\mathcal{D}_0}\right)^{-1/3},
\qquad
R_{\rm dec,wind}=
\frac{3\mathcal{D}_0}{2(A/m_p)\eta_0},
\]
with \(R_{\rm dec}=\min(R_{\rm dec,ISM},R_{\rm dec,wind})\) for wind media and \(R_{\rm dec}=R_{\rm dec,ISM}\) otherwise.  The logarithmic integration grid begins before \(t_{\rm dec}=R_{\rm dec}/(2\eta_0^2c)\), so the coasting-to-decelerating transition is sampled rather than imposed as a broken power law.

\subsection{The three dynamics branches}

The default dynamics option is branch 3.  The model nevertheless exposes three branches, named here by their integer index because the implementation does not attach a unique literature name to every branch.  Branch 1 uses the radiative-efficiency denominator associated with generic afterglow dynamics \citep{BlandfordMcKee1976,HuangDaiLu1999}.  Branches 2 and 3 use a variable effective adiabatic index,
\[
u=\Gamma\beta,\qquad
\Theta=\frac{u}{3}\frac{u+1.07u^2}{1+u+1.07u^2},
\qquad
z_\Theta=\frac{\Theta}{0.24+\Theta},
\]
\[
\hat{\gamma}=
\frac{
5-1.21937z_\Theta+0.18203z_\Theta^2
-0.96583z_\Theta^3+2.32513z_\Theta^4
-2.39332z_\Theta^5+1.07136z_\Theta^6
}{3},
\]
where the numerical coefficients are the fitted equation-of-state coefficients of the relativistic Maxwell--Juttner gas approximation used in blast-wave calculations \citep{Service1986,Peer2012}.  They are not tuned to the afterglow data or to the validation examples.

Let
\[
\mathcal{A}(T)=
\begin{cases}
L_0(T/t_1)^{q}, & t_1\le T\le t_2,\\
0, & \text{otherwise},
\end{cases}
\]
where \(t_1\) and \(t_2\) are source-frame injection bounds, \(L_0\) is the injected luminosity normalization, and \(q\) is the temporal injection index.  In the public model, \texttt{Magnetar}(\(L_0,t_0,q\)) stores \(L_0\), \(t_0\), and \(q\); the dynamics kernel then converts the configured injection bounds to the source frame by dividing by \(1+z\), so the upper bound entering the equation is \(t_2=t_0/(1+z)\).  The lower injection bound \(t_1\) remains the runtime injection-start parameter and is converted in the same way.  The public name is therefore a compact energy-injection constructor, not a claim that the dynamics solve a separate magnetar spin-down equation.

The injection term is branch dependent.  Branches 1 and 3 use \(\mathcal{A}(T)\) as a luminosity source in the source-frame time equation, while branch 2 has no injection source in its Lorentz-factor equation.  The manuscript therefore treats energy injection as part of the selected dynamics branch, not as a branch-independent postprocessing correction.  The swept-medium derivative is
\[
D_{\mathcal{M}}=
\begin{cases}
n(R)R^2D_R, & \text{branches 1 and 2},\\
4\pi n(R)R^2m_pD_R, & \text{branch 3}.
\end{cases}
\]
Branches 1 and 2 use the swept number column \(d\mathcal{M}/dT=nR^2D_R\).  Their ejecta normalization is therefore the isotropic-equivalent rest-energy column
\[
\mathcal{M}_{0,N}=\frac{E_{\rm iso}}{4\pi(\eta_0-1)m_pc^2}.
\]
When these legacy branches are exposed through the public state, the internal swept column is converted to total swept mass as \(M_{\rm sw}=4\pi m_p\mathcal{M}\).  In branch 3, \(\mathcal{M}\) is already the total swept mass in grams.
For branch 1,
\[
\frac{d\Gamma}{dT}=
\frac{-(\Gamma^2-1)D_{\mathcal{M}}
+\mathcal{A}(T)/(4\pi m_pc^2)}
{\mathcal{M}_{0,N}+\epsilon_{\rm eff}\mathcal{M}
+2(1-\epsilon_{\rm eff})\Gamma\mathcal{M}},
\qquad
\frac{dU}{dT}=(\Gamma-1)D_{\mathcal{M}}.
\]
For branch 2, the same \(\mathcal{M}_{0,N}\) is used, but the numerator and denominator are
\[
\mathcal{N}_2=
\hat{\gamma}(\Gamma^2-1)-(\hat{\gamma}-1)\Gamma\beta^2,
\]
\[
\mathcal{D}_2=
\mathcal{M}_{0,N}+\epsilon_{\rm eff}\mathcal{M}
+(1-\epsilon_{\rm eff})\mathcal{M}
\left[
2\hat{\gamma}\Gamma-(\hat{\gamma}-1)(1+\Gamma^{-2})
\right],
\]
\[
\frac{d\Gamma}{dT}=-
\frac{\mathcal{N}_2}{\mathcal{D}_2}
D_{\mathcal{M}},
\qquad
\frac{dU}{dT}=(\Gamma-1)D_{\mathcal{M}}.
\]
Branch 2 is retained as a selectable legacy option; branch 3 is the default publication branch.

For the default branch 3, \(\mathcal{M}\) is physical swept mass in grams and \(U\) is internal energy.  With
\[
\mathcal{M}_0=\frac{E_{\rm iso}}{(\eta_0-1)c^2},
\qquad
X=\Gamma^2-1,
\]
the implemented numerator and denominator are
\[
\mathcal{N}_3=
-\frac{D_{\mathcal{M}}}{D_R}c^2\Gamma X
(\hat{\gamma}\Gamma-\hat{\gamma}+1)
-(\hat{\gamma}X+1)\Gamma(1-\hat{\gamma})
\frac{3U}{R}
+\Gamma^2\frac{\mathcal{A}(T)}{D_R},
\]
\[
\mathcal{D}_3=
\Gamma^2(\mathcal{M}_0+\mathcal{M})c^2
+(\hat{\gamma}^2X+3\hat{\gamma}-2)U,
\]
\[
\frac{d\Gamma}{dT}=
\frac{\mathcal{N}_3}{\mathcal{D}_3}D_R,
\]
\[
\frac{dU}{dT}=
\left[
(1-\epsilon_{\rm eff})(\Gamma-1)
\frac{D_{\mathcal{M}}}{D_R}c^2
-(\hat{\gamma}-1)
\left(\frac{3}{R}-\frac{1}{\Gamma D_R}\frac{d\Gamma}{dT}\right)U
\right]D_R
+\mathcal{A}(T).
\]
These equations define the branch-3 dynamics used for the default forward-shock calculations.

\subsection{Forward-dynamics integration algorithm}

The forward-dynamics kernel maps the runtime boundary vector to physical scalars once at entry:
\[
\mathcal{B}\mapsto
\left(
\eta_0,\epsilon_e,\epsilon_B,p,z,n_{\rm ISM},A_\ast,E_{\rm iso},
\log_{10}T_{\rm end},f_e,t_1,t_2,L_0,q,R_{\rm tr},f_{\rm jump},
w_{\rm jump},R_0
\right).
\]
It then fixes the density profile and integrates the four-component state
\[
Y=(\Gamma,\mathcal{M},U,R)
\]
from the runtime initial condition
\[
Y_0=(\eta_0-10^{-3},\mathcal{M}_{\rm init},U_{\rm init},R_{\rm init}),
\]
where \(\mathcal{M}_{\rm init}\), \(U_{\rm init}\), and \(R_{\rm init}\) are supplied by the runtime boundary rather than recomputed inside the kernel.  The output time grid is
\[
T_i=10^{t_{\min}+(\log_{10}T_{\rm end}-t_{\min})(i-1)/(N_R-1)},
\qquad
t_{\min}=\min\left[-5,\log_{10}(0.1t_{\rm dec})\right],
\]
and the time-ordered integration contract is
\[
H_i=T_i-T_{i-1},\qquad T_0=0,
\qquad
Y_i=Y_{i-1}+\int_{T_{i-1}}^{T_i}F(T,Y)\,dT,
\]
with \(F=dY/dT\) given by the branch equations above.  The stored public arrays are therefore paired as
\[
\left(T_{{\rm obs},i},\Gamma_i,M_{{\rm sw},i},R_i\right)
=
\begin{cases}
\left((1+z)T_i,Y_i^{(1)},4\pi m_pY_i^{(2)},Y_i^{(4)}\right), & \text{branches 1 and 2},\\
\left((1+z)T_i,Y_i^{(1)},Y_i^{(2)},Y_i^{(4)}\right), & \text{branch 3}.
\end{cases}
\]

For \(T_{i-1}>0\), the integrator changes variables from \(T\) to
\[
s=\ln(T/T_{i-1}),
\qquad
\frac{dY}{ds}=T\frac{dY}{dT}=T\,F(T,Y),
\]
and uses classical fourth-order Runge--Kutta substeps over
\[
0\le s\le \ln(T_i/T_{i-1}),
\qquad
|\Delta s|\le0.25.
\]
For the first interval, where \(T_{i-1}=0\), the same RK4 tableau is applied directly in linear time.  The refinement criterion compares successive integrations of the same interval:
\[
P=\max_k
\frac{2|Y_k^{(m)}-Y_k^{(m/2)}|}
{Y_k^{(m)}+Y_k^{(m/2)}},
\]
and halves the substep until \(P<10^{-5}\).  The comparison is made only for positive paired states and with \(\Gamma>1\); these are the physical state-domain conditions of the relativistic blast-wave variables, not a smoothing or postprocessing correction.

\subsection{Dynamics binding boundary}

The Python \texttt{src.Dynamics} package initializer is not a hydrodynamic solver.  It defines the package-level binding map
\[
\texttt{dynamics\_forward}\mapsto\texttt{Dynamics\_forward},
\qquad
\texttt{dynamics\_reverse}\mapsto\texttt{Dynamics\_reverse},
\]
and resolves each entry on demand from the compiled f2py module of the same physical branch.  This layer therefore contributes no additional blast-wave equation, shock jump condition, or integration step.  Its physical role is a boundary condition on the code architecture: higher-level Python orchestration may request the forward or reverse dynamics kernel through a stable package-level name, but the equations are those of the compiled dynamics kernels described in this section and in Section~\ref{sec:reverse-shock}.

\section{Electron Transport and Synchrotron Stage} \label{sec:electron}

The electron stage solves a radius-evolution problem for the shock-accelerated electron distribution before any observer-time projection is applied.  The implemented solver families are the implicit \texttt{fullhide} branch (\texttt{fullhide\_1d}, \texttt{fullhide\_1d\_hz}, and \texttt{fullhide\_2d}), the characteristic-integration branch (\texttt{charint\_1d} and \texttt{charint\_2d}), the one-dimensional nodal discontinuous-Galerkin branch (\texttt{dg\_1d}), and one-dimensional transport alternatives (\texttt{slc1\_1d}, \texttt{t2g1\_1d}, and \texttt{weno5\_1d}).  The default solver is \texttt{fullhide\_1d}.  One-dimensional solvers return \(N_e(\gamma_e,R)\), synchrotron luminosity, seed synchrotron photon density, and spectral-break diagnostics.  Two-dimensional solvers additionally return \(\chi\)-resolved electron, synchrotron, seed, optical-depth, radius, bulk-Lorentz-factor, and volume-weight arrays.  The \(\chi\)-resolved \eats\ projection is restricted to the supported two-dimensional projection path.  The DG, finite-volume, and WENO options are numerical transport options for the same electron equation rather than different physical electron models \citep{LeVeque2002,JiangShu1996,HesthavenWarburton2008}.

The package-level electron namespace is only an ABI resolver for compiled kernels.  It defines a finite map \(\mathcal{M}_{e}\) from the aliases \texttt{fs\_charint\_1d}, \texttt{fs\_dg\_1d}, \texttt{fs\_fullhide\_1d}, \texttt{fs\_fullhide\_hz}, \texttt{fs\_transport\_2d}, \texttt{fs\_slc1\_1d}, \texttt{fs\_t2g1\_1d}, \texttt{fs\_weno5\_1d}, and \texttt{electron\_reverse\_kernel} to their compiled modules.  The mapping is one-to-one with the corresponding \texttt{electron\_forward\_*} module names except for \texttt{fs\_fullhide\_hz}, which resolves to \texttt{electron\_forward\_fullhide\_1d\_hybrid}, and \texttt{fs\_transport\_2d}, which resolves to \texttt{electron\_forward\_transport\_2d}.
For a requested public symbol \(a\), the resolver performs
\[
a\in{\rm dom}\,\mathcal{M}_e:\quad
v_a={\rm getattr}\left[
{\rm import}\left(\texttt{src.Electron.}\mathcal{M}_e(a)\right),a\right],
\qquad {\rm globals}(a)\leftarrow v_a ,
\]
and otherwise raises an attribute error.  This cache changes only symbol lookup.  Radiation helpers such as \texttt{electron\_radiation}, the coupled \texttt{fullhide\_1d} pass, and solver-selection logic in the runtime are imported explicitly by their callers, so the package namespace contributes no additional injection, cooling, emissivity, or transport equation.  The historical \texttt{fullhide\_2d\_pic} runtime name is not part of this package-level public map and has no current tracked source/build contract.

The common equation is written in radius form as
\[
\frac{\partial N_e}{\partial R}
+\frac{\partial}{\partial\gamma_e}
\left(\dot{\gamma}_{e,R}N_e\right)
=Q_{e,R}+Q_{e,{\rm sec},R},
\]
where \(Q_{e,{\rm sec},R}=0\) in separated forward-shock calculations and is supplied by the joint hadronic-feedback branch when Bethe-Heitler, \(pp\), or \(\gamma\gamma\) secondaries are fed back into the electron equation.  For the default implicit solver the transported variable is \(N_x=\gamma_e\ln 10\,N_e\) on \(x=\log_{10}\gamma_e\).  The shell update is an implicit upwind solve,
\[
\left(\mathbf{I}-\mathbf{A}_i\right)\mathbf{N}_{x,i+1}
=\mathbf{N}_{x,i}+\Delta R_i\,\mathbf{Q}_{x,i},
\]
where the upper-bidiagonal matrix \(\mathbf{A}_i\) is assembled from the face drift coefficients \(\Delta R_i\,\dot{x}_{R,j+1/2}/\Delta x\) and solved by a high-to-low-energy backward sweep.  The source term is integrated over log-\(\gamma_e\) cell edges, so the update evolves cell averages rather than only point values.

The shared electron common layer unpacks the public boundary array, installs the active density-profile state, and defines the solver-independent initialization formulas.  For the built-in uniform and \(k=2\) wind media, the initial local density used by the electron kernels is the same density law as the dynamics layer.  With \(A_w=3\times10^{35}A_\star\), wind floor radius \(R_f=(4A_w/n_{\rm ISM})^{1/2}\), and optional wind cap radius \(R_0\), the local density at the starting radius is
\[
n(R)=
\begin{cases}
n_{\rm ISM}, & A_\star\le0,\\
A_w/R_0^2, & A_\star>0,\ R_0>0,\ R<R_0,\\
n_{\rm ISM}, & A_\star>0,\ A_w/R^2\le n_{\rm ISM}/4,\\
A_w/R^2, & {\rm otherwise}.
\end{cases}
\]
The corresponding initial swept electron count is the volume integral of this same piecewise profile.  Thus \(N_{\rm init}=4\pi R_{\rm ini}^3 n_{\rm ISM}/3\) for the uniform branch.  For the capped wind branch,
\[
N_{\rm init}=
\frac{4\pi}{3}\frac{A_w}{R_0^2}\min(R_{\rm ini},R_0)^3
+4\pi A_w\,[\min(R_{\rm ini},R_f)-R_0]_+
+\frac{4\pi}{3}n_{\rm ISM}
\left[R_{\rm ini}^3-\max(R_0,R_f)^3\right]_+ ,
\]
where \([x]_+=\max(x,0)\).  For an uncapped wind the first, capped-core term is omitted and the remaining terms use \(R_0=0\).

The nonthermal source in a shell is a power law with an exponential high-energy cutoff,
\[
Q_{x,j}=\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
Q_0\,10^{(1-p)x}
\exp\!\left[1-\frac{10^x}{\gamma_{\max}}\right]
H(10^x-\gamma_m)\,dx,
\]
where \(H\) is the Heaviside function and
\[
Q_0=\frac{\Delta V_i}{\Delta R_i}\,n(R_i)f_e
\frac{1-p}{\gamma_{\max}^{1-p}-\gamma_m^{1-p}}.
\]
Here \(\Delta V_i=(4\pi/3)(R_i^3-R_{i-1}^3)\), so \(Q_0\) is a radius-source normalization; multiplication by the shell step \(\Delta R_i\) in the update gives the finite injected electron number.  The maximum Lorentz factor used by the electron kernels is
\[
\gamma_{\max}=\frac{3m_ec^2}{\left(8e^3B'\right)^{1/2}},
\]
and the injection minimum is evaluated with the full \(p\) branch.  For \(p>2\),
\[
\gamma_m=1+\frac{p-2}{p-1}
\frac{\epsilon_e}{f_e}
\frac{m_p}{m_e}(\Gamma-1),
\]
whereas for \(1<p<2\),
\[
\gamma_m=
\left[
\frac{2-p}{p-1}
\frac{\epsilon_e}{f_e}\frac{m_p}{m_e}(\Gamma-1)
\gamma_{\max}^{p-2}
\right]^{1/(p-1)}+1.
\]
For \(p=2\), the code solves the logarithmic normalization
\[
\gamma_m\ln\left(\frac{\gamma_{\max}}{\gamma_m}\right)
=\frac{\epsilon_e}{f_e}\frac{m_p}{m_e}(\Gamma-1).
\]
A single \(p>2\) formula therefore does not represent the implemented injection model.  The common initialization grid is logarithmic,
\[
\gamma_i=3\left(\frac{30\gamma_{\max,0}}{3}\right)^{(i-1)/(N_\gamma-1)} ,
\]
and the injection-profile module supplies the same physical spectrum to all electron solvers in the coordinate measure requested by the caller.  The high-energy cutoff is
\[
\mathcal{C}_{\max}(\gamma_e)=
\begin{cases}
1, & \gamma_e\le\gamma_{\max},\\
\exp(1-\gamma_e/\gamma_{\max}), & \gamma_e>\gamma_{\max}.
\end{cases}
\]
For any power-law segment \(dN/d\gamma=A\gamma^{-s}\mathcal{C}_{\max}\),
\[
\frac{dN}{dx}=A\ln10\,\gamma^{1-s}\mathcal{C}_{\max}(\gamma),
\qquad x=\log_{10}\gamma .
\]
The initial fast- or slow-cooling spectrum is then
\[
\frac{dN}{d\gamma}=
\begin{cases}
N_0\gamma_c\gamma^{-2}\mathcal{C}_{\max},&
\gamma_c\le\gamma<\gamma_m,\quad \gamma_m>\gamma_c,\\
N_0\gamma_c\gamma_m^{p-1}\gamma^{-p-1}\mathcal{C}_{\max},&
\gamma\ge\gamma_m,\quad \gamma_m>\gamma_c,\\
N_0(p-1)\gamma_m^{p-1}\gamma^{-p}\mathcal{C}_{\max},&
\gamma_m\le\gamma<\gamma_c,\quad \gamma_m\le\gamma_c,\\
N_0(p-1)\gamma_m^{p-1}\gamma_c\gamma^{-p-1}\mathcal{C}_{\max},&
\gamma\ge\gamma_c,\quad \gamma_m\le\gamma_c,\\
0, & \text{otherwise}.
\end{cases}
\]
The centered initialization path samples this expression at \(\gamma_i\).  The conservative log-gamma path instead stores
\[
N_{x,j}^{\rm init}=\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
\frac{dN_e}{dx}\,dx ,
\]
with the integral split at \(\gamma_m\), \(\gamma_c\), and \(\gamma_{\max}\).  Each smooth segment is integrated with the three-point Gauss--Legendre rule,
\[
\int_a^b F(x)\,dx\simeq
\frac{b-a}{2}\sum_{q=1}^3 w_q
F\!\left[\frac{a+b}{2}+\frac{b-a}{2}\xi_q\right],
\]
\[
(\xi_1,\xi_2,\xi_3)=
\left(-\sqrt{\frac{3}{5}},0,\sqrt{\frac{3}{5}}\right),
\qquad
(w_1,w_2,w_3)=\left(\frac{5}{9},\frac{8}{9},\frac{5}{9}\right).
\]
For a four-velocity coordinate \(y\), the same physical spectrum is transformed by the Jacobian,
\[
N_{y,j}^{\rm init}=\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}
\frac{dN}{dx}[x(y)]\,\frac{dx}{dy}\,dy .
\]
The forward-shock source builder uses only the injection branch \(\gamma\ge\gamma_m\).  If the caller has already formed the radial source normalization \(Q_0\),
\[
Q_{x,j}=\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
Q_0\ln10\,\gamma^{1-p}
\mathcal{C}_{\max}(\gamma)\,dx ,
\]
and the \(y\)-coordinate source is again multiplied by \(dx/dy\) inside the integral.  This construction is why the solver-specific wrappers can change numerical coordinates without changing the injected physical distribution.

The reverse-shock kinetic source is a distinct normalized shape.  It is not represented by the forward \(\gamma^{-p}\) source because the intended spectrum is a power law in kinetic energy.  In the log-gamma coordinate the unnormalized source density is
\[
\Psi_x(\gamma)=\gamma\ln10\,(\gamma-1)^{-p}
\mathcal{C}_{\max}(\gamma)\,\mathbf{1}_{\gamma>\gamma_m}.
\]
The module computes the cell averages \(\bar\Psi_{x,j}\) by the same three-point rule and then normalizes them to the requested total source count \(Q\),
\[
Q_{x,j}^{\rm kin}=Q\,
\frac{\bar\Psi_{x,j}}
{\sum_l \bar\Psi_{x,l}\Delta x_l}.
\]
The four-velocity-coordinate kinetic source uses
\[
\Psi_y(y)=\gamma(y)\ln10\,\frac{dx}{dy}
[\gamma(y)-1]^{-p}
\mathcal{C}_{\max}[\gamma(y)]\,\mathbf{1}_{\gamma(y)>\gamma_m},
\]
and is normalized in the same way.  If the support integral is zero, the code stops; it does not insert an artificial floor or renormalize an empty source.

Optional thermal electrons add \(N_{\rm th}\) particles with a Maxwell--Juttner shape.  From the caller's shock-front four-speed \(u\), the dimensionless temperature is
\[
\Theta(u)=
\frac{u(1+1.07u)}{3(1+u+1.07u)} .
\]
The continuous shape used by the module is
\[
\phi_\gamma(\gamma;\Theta)=
\frac{\gamma^2\beta_\gamma e^{-\gamma/\Theta}}
{\Theta K_2(1/\Theta)},
\qquad
\beta_\gamma=(1-\gamma^{-2})^{1/2}.
\]
Because the thermal population is added on the finite electron grid, the code renormalizes this shape on that grid,
\[
\mathcal{N}_{\rm th}=
\frac{1}{2}\sum_{j=1}^{N_\gamma-1}
[\phi_\gamma(\gamma_j)+\phi_\gamma(\gamma_{j+1})]
(\gamma_{j+1}-\gamma_j),
\]
then uses
\[
\phi_x(\gamma_j)=
\frac{\phi_\gamma(\gamma_j)}{\mathcal{N}_{\rm th}}\,
\gamma_j\ln10 .
\]
For a source update, \(N_{\rm th}\phi_x\) is added to the log-coordinate source array; for an initial centered population, \(N_{\rm th}\phi_x/(\gamma\ln10)\) is added to \(dN/d\gamma\).  The positivity of \(\Theta\), the \(\gamma>1\) grid, and the non-zero thermal normalization are physical domain requirements checked at the module boundary.

Several one-dimensional and \(\chi\)-resolved electron solvers use a shared energy-coordinate module before applying their own transport update.  The module keeps \(x_g=\log_{10}\gamma_e\) as the reference energy coordinate.  In the log-gamma branch,
\[
y=x_g,\qquad \gamma_e(y)=10^y,\qquad \frac{dx_g}{dy}=1.
\]
In the four-velocity branch it uses the squared electron four-velocity \(u_e^2=\gamma_e^2-1\) and a scale \(s=\gamma_{\rm scale}^2-1\).  The implemented map is
\[
y=\log_{10}\left(1+\frac{u_e^2}{s}\right)
=\log_{10}\left[1+\frac{\gamma_e^2-1}{s}\right],
\]
with inverse and Jacobian
\[
\gamma_e(y)=\left[1+s(10^y-1)\right]^{1/2},
\qquad
x_g(y)=\log_{10}\gamma_e(y),
\qquad
\frac{dx_g}{dy}=\frac{s10^y}{2\gamma_e^2}.
\]
The current four-velocity callers set \(\gamma_{\rm scale}=2\).  A grid with \(N_\gamma\) cells is uniform in \(y\),
\[
y_{i+1/2}=y_{\min}+\frac{i}{N_\gamma}(y_{\max}-y_{\min}),
\qquad
y_{\min,\max}=\log_{10}\left[1+\frac{\gamma_{\min,\max}^2-1}{s}\right],
\]
and the returned diagnostic arrays are
\[
x_{g,i+1/2}=x_g(y_{i+1/2}),\qquad
\gamma_i=\gamma_e\left(\frac{y_{i-1/2}+y_{i+1/2}}{2}\right).
\]
The conditions \(\gamma_{\rm scale}>1\) and \(\gamma_{\max}>\gamma_{\min}\) are the domain constraints that make \(s>0\) and the coordinate interval non-degenerate.  The Jacobian \(dx_g/dy\) is the factor used by injection integrals, cooling face displacements, and output conversion between coordinate density and \(dN_e/d\gamma_e\).

The shared shell-transport layer then exposes only two accepted shell solvers,
\[
{\cal S}\in\{\texttt{fullhide},\texttt{dg}\},
\]
with \texttt{fullhide} selected when no solver id is supplied.  This selector does not change the electron equation; it only chooses which numerical representation advances the same shell-local population.
For the finite-volume shell step, the input state is the coordinate-cell content
\[
N_{y,j}(R)=\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}\frac{dN_e}{dy}\,dy ,
\qquad
\Delta y_j=y_{j+1/2}-y_{j-1/2}.
\]
Given node loss coefficients \(D_j\) already assembled from radiation and an adiabatic rate \(D_{\rm ad}\), the module places the face drift at
\[
v_{j+1/2}=
\frac{(D_j+D_{j+1})/2+D_{\rm ad}}
{\ln10\,(dx_g/dy)_{j+1/2}} .
\]
The numerator is the radius derivative of \(\ln\gamma_e\); division by \(dx_g/dy\) converts that physical cooling speed to the computational coordinate \(y\).
The conservative implicit update is
\[
N_j^{n+1}=N_j^n+\Delta R\,Q_j
+\frac{\Delta R}{\Delta y_j}
\left[
v_{j+1/2}^{+}N_{j+1}^{n+1}
+v_{j+1/2}^{-}N_{j}^{n+1}
-v_{j-1/2}^{+}N_j^{n+1}
-v_{j-1/2}^{-}N_{j-1}^{n+1}
\right],
\]
where \(v^+=\max(v,0)\) and \(v^-=\min(v,0)\).  The low-energy face is closed for the shared shell step, so a particle packet that cools below the first active face is retained in the first coordinate cell rather than removed from the finite shell population.  The resulting tridiagonal system is solved by the Thomas algorithm, and the stored population is projected onto the physical non-negative domain \(N_{y,j}\ge0\).

When a coordinate-space solution is written back to the diagnostic \(dN_e/d\gamma_e\), the same layer reconstructs a positive exponential profile inside each cell,
\[
\frac{dN_e}{dy}=A_j\exp[\sigma_j(y-y_j)],
\qquad
y_j=\frac{y_{j-1/2}+y_{j+1/2}}{2}.
\]
For interior cells with three positive neighboring averages, \(\sigma_j\) is the monotone log-slope
\[
\sigma_j={\rm minmod}\left[
\frac{\ln N_{y,j}-\ln N_{y,j-1}}{y_j-y_{j-1}},
\frac{\ln N_{y,j+1}-\ln N_{y,j}}{y_{j+1}-y_j}
\right],
\]
and otherwise \(\sigma_j=0\).  Conservation of the cell average fixes
\[
A_j=
\begin{cases}
N_{y,j}, & z_j=0,\\
N_{y,j}\,z_j/\sinh z_j, & z_j\ne0,
\end{cases}
\qquad
z_j=\frac{1}{2}\sigma_j\Delta y_j .
\]
The centered diagnostic is therefore
\[
\left.\frac{dN_e}{d\gamma_e}\right|_j
=
\frac{A_j}{d\gamma_e/dy}
=
\frac{A_j}{\gamma_j\ln10\,(dx_g/dy)_j}.
\]
This conversion is used by the one-dimensional \texttt{fullhide} and reverse-shock finite-volume branches and by the \(\chi\)-resolved and DG drivers when they need shell-centered \(dN_e/d\gamma_e\) diagnostics.

The common cooling-break diagnostic used by the \(\chi\)-resolved path solves a local equality between the face-averaged loss coefficient and the expansion scale.  With midpoint energies
\[
\gamma_{j+1/2}=(\gamma_j\gamma_{j+1})^{1/2},
\]
the diagnostic \(\gamma_c\) is the log-interpolated solution of
\[
\bar{\Lambda}(\gamma_c)=\frac{1}{R\ln 10},
\]
where \(\bar{\Lambda}\) is the supplied face-averaged loss array.  The injection-support locator uses the same log-edge grid and selects all cells overlapping
\[
\log_{10}\gamma_m\le x\le \log_{10}(30\gamma_{\max}).
\]
For adaptive one-dimensional electron substeps, the shared error metric is
\[
\epsilon_{\rm step}=
\max_j\frac{|N^{(2\times1/2)}_j-N^{(1)}_j|}
{\max(|N^{(1)}_j|,10^{-99})},
\]
where \(N^{(1)}\) is the one-full-step trial and \(N^{(2\times1/2)}\) is the two-half-step trial.

The shared transport-common module supplies the numerical primitives used by these one- and two-dimensional branches.  Its implicit upper-triangular cooling primitive is written in terms of face coefficients \(u_{j+1/2}\).  For a diagonal base \(b_0\), it forms
\[
p_j=b_0-u_{j-1/2}\quad (j\ge2),\qquad
p_1=p_2,\qquad
c_j=\frac{2u_{j+1/2}}{p_j+p_{j+1}},
\]
and the high-to-low sweep solves
\[
N_N^{n+1}=r_N,\qquad
N_j^{n+1}=\max\!\left(0,r_j-c_jN_{j+1}^{n+1}\right).
\]
The second-order local interpolation primitive is the Lagrange polynomial
\[
P_2(x)=
y_0\frac{(x-x_1)(x-x_2)}{(x_0-x_1)(x_0-x_2)}
+y_1\frac{(x-x_0)(x-x_2)}{(x_1-x_0)(x_1-x_2)}
+y_2\frac{(x-x_0)(x-x_1)}{(x_2-x_0)(x_2-x_1)} .
\]
For conservative remaps the module reconstructs each cell average \(Q_j\) by a non-uniform-grid PPM parabola.  In local coordinate \(\xi=(x-x_{j-1/2})/\Delta x_j\),
\[
Q_j(\xi)=Q_{L,j}
+\left(Q_{R,j}-Q_{L,j}+Q_{6,j}\right)\xi
-Q_{6,j}\xi^2,
\qquad
Q_{6,j}=6Q_j-3(Q_{L,j}+Q_{R,j}).
\]
The interface values \(Q_L,Q_R\) are first obtained from the three-point interpolation above, then limited to the neighboring extrema; if the centered cell is a local extremum the reconstruction is flattened to \(Q_L=Q_R=Q_j\).  When the parabolic minimum is negative, the interface deviations are scaled by
\[
\theta_j=\frac{Q_j}{Q_j-Q_{\min,j}},
\qquad
Q_{L,R}\leftarrow Q_j+\theta_j(Q_{L,R}-Q_j),
\]
which preserves the cell average and keeps the reconstructed cell content non-negative.  The cell primitive used by all conservative remaps is
\[
{\cal M}_j(\xi_l,\xi_r)=\Delta x_j
\left[
Q_L(\xi_r-\xi_l)
+\frac{Q_R-Q_L+Q_6}{2}(\xi_r^2-\xi_l^2)
-\frac{Q_6}{3}(\xi_r^3-\xi_l^3)
\right],
\]
and a prefix sum of these primitives gives \(M(x)=\int_{x_{1/2}}^xQ(x')\,dx'\).

Positive analytic source arrays use a different conservative reconstruction, because power-law injection and exponential cutoffs are closer to straight lines in log density.  If three neighboring source-cell averages are positive, the local slope is
\[
\sigma_j=\operatorname{minmod}\left[
\frac{\ln Q_j-\ln Q_{j-1}}{x_j-x_{j-1}},
\frac{\ln Q_{j+1}-\ln Q_j}{x_{j+1}-x_j}
\right],
\]
and otherwise \(\sigma_j=0\).  The reconstructed source is
\[
Q_j(x)=A_j\exp[\sigma_j(x-x_j)],
\qquad
A_j=
\begin{cases}
Q_j, & z_j=0,\\
Q_jz_j/\sinh z_j, & z_j\ne0,
\end{cases}
\qquad
z_j=\frac{\sigma_j\Delta x_j}{2}.
\]
The corresponding prefix integral is
\[
{\cal S}_j(x_l,x_r)=
\begin{cases}
A_j(x_r-x_l), & \sigma_j=0,\\
A_j\left[e^{\sigma_j(x_r-x_j)}
-e^{\sigma_j(x_l-x_j)}\right]/\sigma_j, & \sigma_j\ne0 .
\end{cases}
\]
The diagnostic conversion from log-coordinate cell content to a centered physical spectrum is then
\[
\left.\frac{dN_e}{d\gamma_e}\right|_j
=\frac{A_j}{\gamma_j\ln10},
\]
where \(A_j\) is the exponential reconstruction amplitude of the transported \(dN_e/dx\) cell.

The characteristic solver works in \(u=1/\gamma_e=10^{-x}\).  For a global affine cooling law
\[
\frac{du}{dR}=a+bu,
\]
a point arriving at \(u\) after lag \(\tau\) is traced back to
\[
u_{\rm back}=
\begin{cases}
u-a\tau, & b=0,\\
(u+a/b)e^{-b\tau}-a/b, & b\ne0.
\end{cases}
\]
For the piecewise branch, the code constructs
\[
w(u)=uD(u),\qquad
w(u)=a_k+s_ku\quad {\rm in\ cell}\ k,
\]
from the supplied loss array and then uses
\[
\frac{du}{dR}=a_k+(s_k+b_{\rm ad})u .
\]
The same analytic inverse is applied until the traced point reaches a \(u\)-cell face; the remaining lag is then continued in the next cell.  With traced arrival faces \(x_{j\pm1/2}^{\rm back}(\tau)\), the common characteristic update is
\[
N_j^{n+1}=
\frac{M_N[x_{j+1/2}^{\rm back}(\Delta R)]
-M_N[x_{j-1/2}^{\rm back}(\Delta R)]}{\Delta x_j}
+\Delta R\,s_Q\sum_{m=1}^{4}w_m
\frac{M_Q[x_{j+1/2}^{\rm back}(s_m\Delta R)]
-M_Q[x_{j-1/2}^{\rm back}(s_m\Delta R)]}{\Delta x_j}.
\]
Here \(M_N\) is the PPM prefix of the old population, \(M_Q\) is the exponential-source prefix, \(s_Q\) is the supplied source scaling, and the quadrature nodes are
\[
s_m=t_m^4,\qquad w_m=4W_mt_m^3,
\]
with \(t_m,W_m\) the four-point Gauss--Legendre rule on \([0,1]\).  The source-free remap is the same formula with \(s_Q=0\) and only one traced boundary set.

The uniform-grid semi-Lagrangian primitive used by \texttt{slc1\_1d} applies this remap with a symmetric source split,
\[
N_j^{1/2}=\max\left(0,N_j^n+\frac{\Delta R}{2}Q_j\right),
\qquad
x_{j\pm1/2}^{\rm dep}
=\operatorname{clip}\!\left[x_{j\pm1/2}+\Delta R\,f_{j\pm1/2}\right],
\]
\[
N_j^{n+1}=
\max\left[
0,
\frac{M_{1/2}(x_{j+1/2}^{\rm dep})
-M_{1/2}(x_{j-1/2}^{\rm dep})}{\Delta x}
+\frac{\Delta R}{2}Q_j
\right].
\]
The implicit flux-split primitives solve the conservative equation with face velocity \(v_{j+1/2}\),
\[
N_j^{n+1}=N_j^n+\Delta RQ_j
+\frac{\Delta R}{\Delta x_j}
\left[
v_{j+1/2}^{+}N_{j+1}^{n+1}
+v_{j+1/2}^{-}N_j^{n+1}
-v_{j-1/2}^{+}N_j^{n+1}
-v_{j-1/2}^{-}N_{j-1}^{n+1}
\right],
\]
where \(\Delta x_j\) is either uniform or the local non-uniform cell width.  The integrated sequence primitive uses the same matrix with \(\Delta R\,v_{j+1/2}\) replaced by a pre-integrated face displacement \({\cal F}_{j+1/2}\) and \(\Delta RQ_j\) replaced by the pre-integrated source content \({\cal Q}_j\).

The legacy log-\(\gamma\) fullhide primitive is the special upper-triangular case
\[
v_{j+1/2}=D_{j+1/2}+\frac{1}{R\ln10},\qquad
u_{j+1/2}=-\frac{\Delta R}{\Delta x}v_{j+1/2},
\]
\[
p_j=1-u_{j-1/2},\qquad
c_j=\frac{2u_{j+1/2}}{p_j+p_{j+1}},
\qquad
r_j=\frac{N_j^n+\Delta RQ_j}{p_j},
\]
followed by the high-to-low sweep above.  The space-time fullhide primitive applies the same triangular solve over a sequence of source/coupling columns.  For substep \(m\),
\[
(1+f_{j-1/2}^{m})N_j^{m}
-f_{j+1/2}^{m}N_{j+1}^{m}
=N_j^{m-1}+S_j^{m},
\]
with the low- and high-energy end rows using only the existing adjacent face coefficient; solving this system for \(m=1,\ldots,N_{\rm step}\) gives the final column.

Two diagnostics are also centralized here.  A spectral peak sampled on positive neighboring bins is estimated by a log-parabola through \((\ln\nu_{l,c,r},\ln P_{l,c,r})\),
\[
\ln\nu_{\rm pk}
=x_c+\frac{1}{2}
\frac{y_l-y_r}{y_l-2y_c+y_r}(x_c-x_l),
\]
clamped to the bracketing interval.  The active energy and \(\chi\) ranges used by the two-dimensional driver are support definitions,
\[
i_{\rm act}=\max\left[
2,\ i_{\rm src},\
\min(N_\gamma,i_{\rm pop}+1)
\right],
\qquad
Q_i>10^{-12}Q_{\rm pk},\quad
N_i>10^{-12}\max(N_{\rm pk},Q_{\rm pk}),
\]
\[
k_{\rm act}=
\min(N_\chi,k_{\rm pop}+1),
\qquad
N_{\chi,k}>10^{-10}N_{\chi,\rm pk}.
\]
The radial substep estimate uses the largest active energy drift,
\[
\xi_{\max}=\max_{k\le k_{\rm act},\,i<i_{\rm act}}
\left|D_{i,k}+A_{{\rm ad},k}\right|,
\]
with a second pass over all \(\chi\) cells only when the active-population scan finds zero drift.

The default \texttt{fullhide\_1d} solver advances the same forward-shock electron equation with a fully implicit conservative finite-volume step.  Its production nonthermal path uses the shared four-velocity coordinate \(y\), with conservative cell averages
\[
N_{y,j}(R)=\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}\frac{dN_e}{dy}\,dy .
\]
At shell \(i\), the driver evaluates the local state at
\[
R_{\rm loc}=R_{i-1},\qquad
\bar\Gamma_i=\frac{\Gamma_i+\Gamma_{i-1}}{2},\qquad
n_i=n(R_{\rm loc}),
\]
and uses the same magnetic field and injection formulae,
\[
B_i'=0.39\left[\epsilon_Bn_i\bar\Gamma_i(\bar\Gamma_i-1)\right]^{1/2},
\qquad
\gamma_{\max,i}=\frac{3m_ec^2}{(8B_i'e^3)^{1/2}},
\]
\[
\gamma_{c,i}=\frac{7.7\times10^8(1+z)}
{\bar\Gamma_iB_i'^2t_{{\rm obs},i}},
\qquad
\beta_i=(1-\bar\Gamma_i^{-2})^{1/2}.
\]
The fixed-step estimate is
\[
\delta R_0=\frac{0.1}{
\left[(1.35\times10^{-19})B_i'^2\gamma_{\max,i}/(\pi\beta_i\bar\Gamma_i)
+1.333/(R_i+R_{i-1})\right]},
\]
and the actual fixed-substep count is
\[
L_i=\max\left[100,\min\left(1000,
\left\lfloor\frac{R_i-R_{i-1}}{\delta R_0}\right\rfloor\right)\right],
\qquad
\Delta R=(R_i-R_{i-1})/L_i .
\]

For one ordinary substep the code writes the cooling speed on a coordinate face as
\[
v_{j+1/2}=
\frac{(D_j+D_{j+1})/2+R^{-1}}
{\ln 10\,(dx_g/dy)_{j+1/2}},
\]
where positive \(v\) denotes motion toward lower electron energy.  With a closed low-energy boundary, the implicit update is the tridiagonal conservative solve
\[
N_j^{n+1}
=N_j^n+\Delta R\,Q_j
+\frac{\Delta R}{\Delta y_j}
\left[
v_{j+1/2}^{+}N_{j+1}^{n+1}
-v_{j-1/2}^{+}N_j^{n+1}
+v_{j+1/2}^{-}N_j^{n+1}
-v_{j-1/2}^{-}N_{j-1}^{n+1}
\right],
\]
where \(v^\pm=\max/\min(v,0)\) and \(N_0\) is not used when the low boundary is closed.  This is the physical reason for the solver's robustness in stiff cooling regimes: the high-energy loss flux is solved at the new radius instead of being applied explicitly.

For a strictly uniform medium with no thermal-electron branch, the fixed substeps are merged into one integrated implicit solve.  Let
\[
R_\ell=R_{i-1}+\ell\Delta R,\qquad \ell=1,\ldots,L_i .
\]
The integrated source normalization passed to the cell-averaged source builder is
\[
\mathcal{Q}_{i}=
\sum_{\ell=1}^{L_i}\Delta R\,
\frac{4\pi}{3}
\left[3R_\ell^2+\Delta R(3R_\ell+\Delta R)\right]
n_if_e
\frac{1-p}{\gamma_{\max,i}^{1-p}-\gamma_{m,i}^{1-p}} .
\]
The source cells are
\[
\bar Q_{y,j}^{\rm int}=
\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}
\mathcal{Q}_{i}\,
\ln 10\,\gamma_e^{1-p}
\mathcal{C}_{\max}(\gamma_e)
\frac{dx_g}{dy}\,dy ,
\]
and the integrated face displacement is
\[
\mathcal{F}_{j+1/2}=
\frac{
(R_i-R_{i-1})(D_j+D_{j+1})/2
+\sum_{\ell=1}^{L_i}\Delta R/R_\ell}
{\ln 10\,(dx_g/dy)_{j+1/2}} .
\]
The merged solve is the same tridiagonal system as the one-step update, with \(\Delta R\,v_{j+1/2}\) replaced by \(\mathcal{F}_{j+1/2}\) and \(\Delta R\,Q_j\) replaced by \(\bar Q_{y,j}^{\rm int}\).

In non-uniform density or thermal-electron mode, the solver advances the substeps individually.  At each substep endpoint \(R_\ell\), it re-evaluates \(n(R_\ell)\), \(B'\), \(\gamma_{\max}\), and \(\gamma_m\).  The local source is
\[
Q_{y,j}^{(\ell)}=
\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}
\dot N_{{\rm inj},R}(R_\ell,\Delta R)\,
\ln 10\,\gamma_e^{1-p}
\mathcal{C}_{\max}(\gamma_e)
\frac{dx_g}{dy}\,dy ,
\]
with an additional Maxwell--Juttner thermal population when \texttt{thermal\_electrons} is enabled.  The radiative cooling coefficient is assembled once from the shell photon field and scaled locally as
\[
D_j(R_\ell)=D_j(R_{i-1})\frac{n(R_\ell)}{n(R_{i-1})},
\]
which is exact for the local synchrotron term under fixed \(\bar\Gamma_i\) and fixed shell photon shape, and is the implemented density-response approximation for the complete cooling array.

When adaptive substeps are requested, the driver accepts a trial \(\Delta R\) by comparing one full implicit step with two half implicit steps,
\[
\epsilon_{\rm adapt}=
\max_j\frac{|N_j^{(2\times1/2)}-N_j^{(1)}|}
{\max(|N_j^{(2\times1/2)}|,10^{-99})}.
\]
The accepted state is the two-half-step solution.  If \(\epsilon_{\rm adapt}\le{\tt substep\_rtol}\), the step is accepted and may double for the next trial when the error is below one quarter of the tolerance; otherwise it is halved down to \((R_i-R_{i-1})/{\tt substep\_max}\).  This controls radial integration error without smoothing the electron spectrum after the solve.

The joint electron--photon coupled pass, \texttt{fs\_fullhide\_coupled}, keeps the legacy log-gamma coordinate \(x=\log_{10}\gamma_e\) and requires fixed substeps with \(\texttt{index\_Y}=1\).  It receives an externally closed photon field \(n_\nu^{\rm cool}\) and secondary pair source \(Q_{e,{\rm sec}}\).  The numeric IC budget is computed from \(n_\nu^{\rm cool}\), while SSA heating is computed from the local synchrotron seed field.  In each substep the source is
\[
Q_{x,j}^{\rm coupled}=Q_{x,j}^{\rm inj}+Q_{e,{\rm sec},j},
\]
and the implicit upper-triangular solve is the direct form used by
\texttt{fullhide\_step}.  Define the face speed and signed Courant factor
\[
w_{j+1/2}=\bar D_{j+1/2}+\frac{1}{R\ln 10},
\qquad
u_{j+1/2}=-\frac{\Delta R}{\Delta x}w_{j+1/2}.
\]
The diagonal and right-hand side are
\[
p_j=1-u_{j-1/2}\quad (j\ge2),\qquad p_1=p_2,
\qquad
r_j=\frac{N_j^n+\Delta R\,Q_{x,j}^{\rm coupled}}{p_j},
\]
and adjacent cells are coupled by the averaged coefficient
\[
c_j=\frac{2u_{j+1/2}}{p_j+p_{j+1}} .
\]
The spectrum is recovered by back-substitution from high to low energy,
\[
N_N^{n+1}=r_N,\qquad
N_j^{n+1}=\max\left(0,r_j-c_jN_{j+1}^{n+1}\right).
\]
As in the separated fullhide path, the last output radius is refreshed from the final electron spectrum through the same synchrotron optical-depth grid, so the returned \(\nu_m\), \(\nu_c\), and \(\nu_a\) arrays do not end with a stale zero diagnostic.

The \texttt{fullhide\_1d\_hz} branch uses the same shell state, cooling array, and
four-velocity flux-split update as the standard fullhide path, but replaces the
source shape when \texttt{thermal\_electrons} is enabled.  The conservative
variable is
\[
N_{y,j}(R)=\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}\frac{dN_e}{dy}\,dy,
\qquad
y=\log_{10}\!\left[1+\frac{\gamma_e^2-1}{s}\right],
\quad s=\gamma_s^2-1 .
\]
The grid centers still return \(\gamma_e\) for radiation calls, but source and
transport content live in \(y\).  Since \(x=\log_{10}\gamma_e\),
\[
\frac{dx}{dy}=\frac{s\,10^y}{2\gamma_e^2},
\qquad
\frac{dN_e}{dy}=\frac{dN_e}{d\gamma_e}\gamma_e\ln 10\,\frac{dx}{dy}.
\]
For a substep evaluated at source radius \(R_s\), the radial swept-electron rate
used by the source array is the finite-shell volume increment divided by
\(\Delta R\) exactly as assembled by the kernel,
\[
\dot N_R(R_s,\Delta R)=
\frac{4\pi}{3}
\left[3R_s^2+\Delta R(3R_s+\Delta R)\right]n(R_s).
\]
When the thermal branch is disabled, this reduces to the ordinary nonthermal
source
\[
Q_{y,j}=\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}
\dot N_R f_e
\frac{1-p}{\gamma_{\max}^{1-p}-\gamma_m^{1-p}}
\gamma_e^{-p}\mathcal{C}_{\max}(\gamma_e)
\gamma_e\ln 10\,\frac{dx}{dy}\,dy .
\]
When the thermal branch is enabled, the source is instead distributed over a
unit-normalized hybrid density \(\phi_{\rm hz}(\gamma)\),
\[
Q_{y,j}^{\rm hz}=
\frac{1}{\Delta y_j}
\int_{y_{j-1/2}}^{y_{j+1/2}}
\dot N_R\,\phi_{\rm hz}(\gamma_e)\,\gamma_e\ln 10
\frac{dx}{dy}\,dy .
\]
The implemented hybrid density is continuous at \(\gamma_m\) and partitions the
newly swept electrons into a thermal fraction \(1-f_e\) and a cutoff power-law
fraction \(f_e\):
\[
\phi_{\rm hz}(\gamma)=
\begin{cases}
\displaystyle
(1-f_e)\,
\frac{\gamma\sqrt{\gamma^2-1}\exp(-\gamma/\Theta)}
{I_1(\gamma_m,\Theta)}, & 1<\gamma<\gamma_m,\\[1.0ex]
\displaystyle
f_e\,
\frac{\gamma^{-p}\exp(-\gamma/\gamma_{\max})}
{I_{\rm pl}(\gamma_m,\gamma_{\max},p)}, & \gamma\ge\gamma_m .
\end{cases}
\]
Here
\[
I_1(\gamma_m,\Theta)=
\int_1^{\gamma_m}\gamma\sqrt{\gamma^2-1}\exp(-\gamma/\Theta)\,d\gamma,
\qquad
I_{\rm pl}=\gamma_{\max}^{1-p}\Gamma\!\left(1-p,\frac{\gamma_m}{\gamma_{\max}}\right).
\]
The temperature \(\Theta\) is not an adjustable parameter.  It is set by the
continuity condition at \(\gamma_m\),
\[
\frac{1-f_e}{I_1}\gamma_m\sqrt{\gamma_m^2-1}\exp(-\gamma_m/\Theta)
=
\frac{f_e}{I_{\rm pl}}\gamma_m^{-p}\exp(-\gamma_m/\gamma_{\max}) .
\]
Equivalently, the code solves
\[
F(\Theta)=\frac{\gamma_m}{\Theta}+\ln I_1-\ln C=0,
\]
with
\[
\ln C=
\ln\!\left[\left(\frac{1}{f_e}-1\right)\sqrt{\gamma_m^2-1}\right]
+(1+p)\ln\gamma_m+\ln I_{\rm pl}
+\frac{\gamma_m}{\gamma_{\max}} .
\]
The Newton derivative uses
\[
I_2(\gamma_m,\Theta)=
\int_1^{\gamma_m}\gamma^2\sqrt{\gamma^2-1}\exp(-\gamma/\Theta)\,d\gamma,
\]
so the relative iteration written in the kernel is
\[
\frac{\Theta_{k+1}}{\Theta_k}-1
=
\frac{F(\Theta_k)}
{\gamma_m/\Theta_k-I_2/(\Theta_k I_1)} .
\]
The special-function layer for this branch is deliberately only a mathematical
adapter.  The wrapper \texttt{hybrid\_special} exposes the upper incomplete
gamma function
\[
\Gamma(s,x)=\int_x^\infty t^{s-1}e^{-t}\,dt
\]
and the two modified Bessel functions
\[
K_\nu(z)=\int_0^\infty e^{-z\cosh u}\cosh(\nu u)\,du,\qquad
\nu\in\{0,1\},
\]
by forwarding \(\Gamma(s,x)\) to \texttt{dgamic} and evaluating
\(K_\nu(z)=\exp(-z)[\exp(z)K_\nu(z)]\) through the scaled SLATEC routines
\texttt{dbsk0e} and \texttt{dbsk1e}.  These SLATEC kernels use
\texttt{d1mach} only to define the local floating-point arithmetic.  In the
model assumed by that routine, a nonzero double-precision number is represented
as
\[
x=\pm B^E\sum_{j=1}^{T}X_jB^{-j},\qquad
0<X_1,\quad 0\le X_j<B,\quad E_{\min}\le E\le E_{\max}.
\]
The five returned constants are
\[
\begin{array}{ll}
\texttt{d1mach}(1)=B^{E_{\min}-1},&
\texttt{d1mach}(2)=B^{E_{\max}}\left(1-B^{-T}\right),\\
\texttt{d1mach}(3)=B^{-T},&
\texttt{d1mach}(4)=B^{1-T},\\
\texttt{d1mach}(5)=\log_{10}B.&
\end{array}
\]
The current source does not activate any historical platform-specific data
table; on first use it fills these five quantities from \texttt{dlamch}
(\texttt{U}, \texttt{O}, \texttt{E}, \texttt{P}, and \texttt{B}) and caches
them for later calls.  They set numerical convergence and range thresholds for
the special functions; they do not modify the electron distribution or add a
physical source term.  The \texttt{dgamic} dispatcher calls \texttt{d9gmic}
when \(x<1\) and \(a\) lies sufficiently close to a non-positive integer.  Let
\[
m=\left\lfloor\frac{1}{2}-a\right\rfloor,\qquad m\ge0 ,
\]
and let \(\epsilon=\texttt{d1mach}(3)/2\).  The first small-\(x\) series is
accumulated as
\[
e_0=1,\quad S_0=1,\qquad
e_k=-\frac{x\,e_{k-1}}{m+k+1},\quad
S_k=S_{k-1}+\frac{e_k}{k+1},
\]
until \(|e_k/(k+1)|<\epsilon S_k\).  It defines
\[
L_m(x)=-\ln x-\gamma_E+\frac{xS}{m+1},
\]
where \(\gamma_E\) is Euler's constant.  For \(m=0\), this is the retained
small-\(x\) expansion of \(\Gamma(0,x)\).  For \(m=1\), the recurrence
\(\Gamma(0,x)=-\Gamma(-1,x)+x^{-1}e^{-x}\) gives the code expression
\[
\Gamma(-1,x)=-L_1(x)-1+x^{-1}.
\]
For \(m\ge2\), the harmonic part and the finite pole series are
\[
H_m=\sum_{k=1}^{m}\frac{1}{k},\qquad
P_m(x)=1+\sum_{k=1}^{m-1}\frac{m(-x)^k}{k!(m-k)} .
\]
The returned value is therefore
\[
\Gamma(-m,x)
=\frac{(-1)^m\,[L_m(x)+H_m]}{\Gamma(m+1)}
+\frac{P_m(x)}{m x^m},
\]
with the first term formed in logarithmic arithmetic and skipped only when it
falls below the machine lower exponent.  This branch is a numerical evaluation
of the same upper incomplete gamma integral used in the hybrid normalization,
not a separate approximation to the electron spectrum.  The power-law
normalization follows directly from
\(t=\gamma/\gamma_{\max}\):
\[
\int_{\gamma_m}^{\infty}\gamma^{-p}e^{-\gamma/\gamma_{\max}}\,d\gamma
=\gamma_{\max}^{1-p}
\int_{\gamma_m/\gamma_{\max}}^\infty t^{-p}e^{-t}\,dt
=\gamma_{\max}^{1-p}
\Gamma\!\left(1-p,\frac{\gamma_m}{\gamma_{\max}}\right).
\]
The Bessel calls enter the thermal moments before the finite upper boundary is
subtracted.  With \(\gamma=\cosh u\) and
\(\sqrt{\gamma^2-1}\,d\gamma=\sinh^2u\,du\),
\[
\int_1^\infty \gamma\sqrt{\gamma^2-1}e^{-\gamma/\Theta}\,d\gamma
=2\Theta^2 K_1(1/\Theta)+\Theta K_0(1/\Theta),
\]
and
\[
\int_1^\infty \gamma^2\sqrt{\gamma^2-1}e^{-\gamma/\Theta}\,d\gamma
=\left(6\Theta^3+\Theta\right)K_1(1/\Theta)
+3\Theta^2K_0(1/\Theta).
\]
Let \(a=\gamma_m/\Theta\).  The finite-\(\gamma_m\) thermal integrals used by
the continuity solve subtract the \(\gamma_m\rightarrow\infty\) tails from
these complete moments.  The tail integrands are evaluated from
\[
\sqrt{\gamma^2-1}
=\gamma\left(1-\frac{1}{2\gamma^2}-\frac{1}{8\gamma^4}
-\frac{1}{16\gamma^6}-\frac{5}{128\gamma^8}
-\frac{7}{256\gamma^{10}}-\frac{21}{1024\gamma^{12}}
-\frac{33}{2048\gamma^{14}}\right),
\]
which gives the exact code expressions
\begin{align}
I_1(\Theta)
&=2\Theta^2 K_1(\Theta^{-1})+\Theta K_0(\Theta^{-1})
+\sum_{k=0}^{7} b_k\Theta^{3-2k}\Gamma(3-2k,a),\\
I_2(\Theta)
&=(6\Theta^3+\Theta)K_1(\Theta^{-1})+3\Theta^2K_0(\Theta^{-1})
+\sum_{k=0}^{7} b_k\Theta^{4-2k}\Gamma(4-2k,a),
\end{align}
with
\[
(b_0,\ldots,b_7)=
\left(-1,\frac{1}{2},\frac{1}{8},\frac{1}{16},
\frac{5}{128},\frac{7}{256},\frac{21}{1024},\frac{33}{2048}\right).
\]
The terms are accumulated in this order and the remaining tail series is
discarded once the current correction is smaller than
\(10^{-15}\max(I,10^{-30})\) for the moment being evaluated.
For non-positive orders, the recurrence
\[
\Gamma(s-1,a)=\frac{\Gamma(s,a)-a^{s-1}\exp(-a)}{s-1}
\]
steps downward from \(\Gamma(0,a)\).  The initial temperature is found by
evaluating \(F(\Theta)\) on
\[
\begin{aligned}
\frac{\Theta}{\gamma_m}\in
\{&0.06,0.07553552,0.09509438,0.11971855,0.15072,0.18975074,\\
&0.23888603,0.30074242,0.37861739,0.4766592,0.6\},
\end{aligned}
\]
shifting the lower or upper side by factors of ten until the signs bracket the
root, and applying a secant interpolation between the adjacent sign-changing
entries.  Newton iteration then applies
\[
\frac{\Delta\Theta}{\Theta}
=\frac{\gamma_m/\Theta+\ln I_1-\ln C}
{\gamma_m/\Theta-\Theta^{-1}I_2/I_1}.
\]
The iteration stops at \(|\Delta\Theta/\Theta|<10^{-6}\); failure to reach this
condition in 50 updates is treated as a failed physical solve, not as a
recoverable branch.
After \(\Theta\) is fixed, the pointwise hybrid distribution is evaluated from
\[
A_{\rm th}=\ln\frac{1-f_e}{I_1},\qquad
A_{\rm pl}=\ln\frac{f_e}{I_{\rm pl}},
\]
as
\[
\phi_{\rm hz}(\gamma)=
\begin{cases}
\exp[\ln(\gamma\sqrt{\gamma^2-1})-\gamma/\Theta+A_{\rm th}],
&1<\gamma<\gamma_m,\\
\exp[-p\ln\gamma-\gamma/\gamma_{\max}+A_{\rm pl}],
&\gamma\ge\gamma_m,\\
0,&\gamma\le1.
\end{cases}
\]
Logarithmic values below \(-700\) are outside the retained floating-point
exponent range and are recorded as zero.  Thus \texttt{hybrid\_special}
supplies exact special functions for normalization only; it adds no source
term, no cooling term, and no post-processing correction.  After the hybrid
source is assembled, the spectrum is advanced by the same upper-triangular
implicit system given above for \texttt{fullhide\_step}; the final output
radius is also refreshed from the final electron spectrum and the same
synchrotron optical-depth grid used for the active shells.

The \texttt{slc1\_1d} branch is a one-dimensional semi-Lagrangian alternative on
the same uniform log-gamma grid.  It keeps the conservative cell averages
\(N_{x,j}\) and uses the same shell-local \(B'\), \(\gamma_m\),
\(\gamma_{\max}\), \(\gamma_c\), synchrotron state, and forward-cooling array as
the log-gamma fullhide path.  The fixed radial substep count is again
\[
L_i=\max\left[100,\min\left(1000,
\left\lfloor\frac{R_i-R_{i-1}}{\delta R_0}\right\rfloor\right)\right],
\qquad
\Delta R=(R_i-R_{i-1})/L_i .
\]
Within a substep \(R_L\rightarrow R_R=R_L+\Delta R\), non-uniform media are
sampled at
\[
R_m=\frac{R_L+R_R}{2},\qquad n_m=n(R_m),\qquad n_R=n(R_R),
\]
while a uniform medium simply uses the shell density.  The injection source is
the log-gamma cell average
\[
Q_{x,j}^{\rm slc}=
\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
\mathcal{Q}_{\rm slc}(R_m,\Delta R)\,
\ln 10\,\gamma_e^{1-p}\mathcal{C}_{\max}(\gamma_e)\,dx ,
\]
where
\[
\mathcal{Q}_{\rm slc}=
\frac{4\pi}{3}
\left[3R_m^2+\Delta R(3R_m+\Delta R)\right]
n_m f_e
\frac{1-p}{\gamma_{\max,m}^{1-p}-\gamma_{m,m}^{1-p}} .
\]
The cooling face speed is the midpoint-density-scaled version of the shell
cooling array,
\[
f_{j+1/2,m}=
\frac{1}{\ln 10}
\left[
\frac{D_{j,m}+D_{j+1,m}}{2}+\frac{1}{R_m}
\right],
\qquad
D_{j,m}=D_{j,i-1}\frac{n_m}{n_{i-1}} .
\]
The actual semi-Lagrangian primitive is a source-split conservative remap.  First
the source half-step forms
\[
N_j^{1/2}=\max\left(0,N_j^n+\frac{\Delta R}{2}Q_{x,j}^{\rm slc}\right).
\]
The code builds a positivity-limited PPM reconstruction of \(N^{1/2}\) and its
prefix integral \(\mathcal{A}_{1/2}(x)\).  The arrival cell faces are traced
backward along the cooling characteristics,
\[
x_{j-1/2}^{\rm dep}=
{\rm clip}\!\left(x_{j-1/2}+\Delta R\,f_{j-1/2,m},
x_{1/2},x_{N+1/2}\right),
\]
so the conservative remap is
\[
N_j^{*}=
\frac{
\mathcal{A}_{1/2}(x_{j+1/2}^{\rm dep})
-\mathcal{A}_{1/2}(x_{j-1/2}^{\rm dep})}
{\Delta x_j}.
\]
The second source half-step gives the stored post-substep spectrum,
\[
N_j^{n+1}=\max\left(0,N_j^{*}+
\frac{\Delta R}{2}Q_{x,j}^{\rm slc}\right).
\]
After the last substep in the output shell, the same conservative exponential
cell-shape conversion used elsewhere maps \(dN/dx\) back to centered
\(dN/d\gamma\).  The \(\nu_m\), \(\nu_c\), and \(\nu_a\) diagnostics for this
branch are shell-left diagnostics for the active slots \(1,\ldots,N_R-1\), with
\(\nu_a\) obtained from the same synchrotron optical-depth grid used to compute
the emitted spectrum.

The \texttt{t2g1\_1d} branch uses the same log-gamma state, source builder, and
shell-left radiation diagnostics as \texttt{slc1\_1d}, but replaces the
semi-Lagrangian remap with a three-level implicit upwind solve.  Each output
shell uses the same fixed substep count \(L_i\), and each substep advances the
source radius directly to \(R_\ell=R_{\ell-1}+\Delta R\).  The injection source is
\[
Q_{x,j}^{\rm t2g}=
\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
\mathcal{Q}_{\rm t2g}(R_\ell,\Delta R)\,
\ln 10\,\gamma_e^{1-p}\mathcal{C}_{\max}(\gamma_e)\,dx ,
\]
with
\[
\mathcal{Q}_{\rm t2g}=
\frac{4\pi}{3}
\left[3R_\ell^2+\Delta R(3R_\ell+\Delta R)\right]
n(R_\ell)f_e
\frac{1-p}{\gamma_{\max,\ell}^{1-p}-\gamma_{m,\ell}^{1-p}} .
\]
The cooling face speed uses the same density scaling as the SLC branch, evaluated
at \(R_\ell\):
\[
f_{j+1/2,\ell}=
\frac{1}{\ln 10}
\left[
\frac{D_{j,\ell}+D_{j+1,\ell}}{2}+\frac{1}{R_\ell}
\right],
\qquad
D_{j,\ell}=D_{j,i-1}\frac{n(R_\ell)}{n_{i-1}} .
\]
Define the signed face Courant factor
\[
u_{j+1/2}=-\frac{\Delta R}{\Delta x}f_{j+1/2,\ell}.
\]
The first two global substeps bootstrap the three-level history with backward
Euler.  In this phase,
\[
p_j^{(1)}=1-u_{j-1/2}\quad (j\ge2),\qquad p_1^{(1)}=p_2^{(1)},
\]
\[
r_j^{(1)}=\frac{N_j^n+\Delta R\,Q_{x,j}^{\rm t2g}}{p_j^{(1)}},
\qquad
c_j^{(1)}=\frac{2u_{j+1/2}}{p_j^{(1)}+p_{j+1}^{(1)}} .
\]
After this bootstrap, the solver uses the BDF2 time discretization
\[
\frac{3N_j^{n+1}-4N_j^n+N_j^{n-1}}{2\Delta R}
+\mathcal{L}_j(N^{n+1})=Q_{x,j}^{\rm t2g},
\]
where \(\mathcal{L}\) is the same one-sided cooling-advection operator encoded by
the face coefficients.  The code therefore sets
\[
p_j^{(3/2)}=\frac{3}{2}-u_{j-1/2}\quad (j\ge2),\qquad
p_1^{(3/2)}=p_2^{(3/2)},
\]
\[
r_j^{(3/2)}=
\frac{2N_j^n-\frac{1}{2}N_j^{n-1}+\Delta R\,Q_{x,j}^{\rm t2g}}
{p_j^{(3/2)}},
\qquad
c_j^{(3/2)}=
\frac{2u_{j+1/2}}{p_j^{(3/2)}+p_{j+1}^{(3/2)}} .
\]
Both startup and BDF2 phases are solved by the same high-to-low-energy backward
sweep,
\[
N_N^{n+1}=r_N,\qquad
N_j^{n+1}=\max\left(0,r_j-c_jN_{j+1}^{n+1}\right).
\]
The pair \((N^n,N^{n-1})\) is then shifted forward, and the final substep in each
output shell is converted from \(dN/dx\) to centered \(dN/d\gamma\) with the same
conservative exponential cell-shape reconstruction used by the other log-gamma
drivers.

The \texttt{weno5\_1d} branch is an explicit finite-volume alternative on the
same uniform log-gamma coordinate,
\[
x=\log_{10}\gamma_e,\qquad
N_{x,j}(R)=\frac{1}{\Delta x}
\int_{x_{j-1/2}}^{x_{j+1/2}}\frac{dN_e}{dx}\,dx .
\]
For the output shell \(R_{i-1}\rightarrow R_i\), it freezes the shock energy
scales at
\[
R_{\rm loc}=R_{i-1},\qquad
\bar\Gamma_i=\frac{\Gamma_i+\Gamma_{i-1}}{2},
\]
and uses the same field, cutoff, injection minimum, and cooling coefficients as
the other forward one-dimensional solvers,
\[
B'_i=0.39\left[\epsilon_B n(R_{\rm loc})
\bar\Gamma_i(\bar\Gamma_i-1)\right]^{1/2},
\qquad
\gamma_{\max,i}=\frac{3m_ec^2}{(8B'_ie^3)^{1/2}},
\]
\[
\gamma_{c,i}=\frac{7.7\times10^8(1+z)}
{\bar\Gamma_iB_i'^2t_{{\rm obs},i}},
\qquad
\beta_i=(1-\bar\Gamma_i^{-2})^{1/2}.
\]
The local cooling assembler returns \(D_j\) such that
\[
\frac{d\gamma_j}{dR}=-D_j\gamma_j .
\]
The WENO driver stores face speeds for the conservative equation
\[
\frac{\partial N_x}{\partial R}
=\frac{\partial}{\partial x}\left(v_xN_x\right)+Q_x,
\qquad
v_{j+1/2}=
\frac{(D_j+D_{j+1})/2+R^{-1}}{\ln10},
\]
with the outer high-energy face extrapolated from the last interior cooling
face.  The trial radial step is set from the largest synchrotron-plus-adiabatic
speed,
\[
\delta R_0=
\frac{0.1}
{(1.35\times10^{-19})B_i'^2\gamma_{\max,i}/(\pi\beta_i\bar\Gamma_i)
+1.333/(R_i+R_{i-1})},
\]
and the actual substep count is
\[
L_i=\max\left[
\left\lfloor\frac{R_i-R_{i-1}}{\delta R_0}\right\rfloor+10,\,
\left\lceil
\frac{(R_i-R_{i-1})\max_j|v_j|}
{0.8\,\Delta x}
\right\rceil
\right],
\qquad
\Delta R=\frac{R_i-R_{i-1}}{L_i}.
\]
Inside a substep the radius is advanced first, \(R_s\leftarrow R_s+\Delta R\),
the density is resampled at this source radius, and the injected cell-average
source is
\[
Q_{x,j}^{\rm weno}=
\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}
\mathcal{Q}_{\rm weno}(R_s,\Delta R)\,
\ln10\,\gamma_e^{1-p}\mathcal{C}_{\max}(\gamma_e)\,dx ,
\]
where
\[
\mathcal{Q}_{\rm weno}=
\frac{4\pi}{3}\left[3R_s^2+\Delta R(3R_s+\Delta R)\right]
n(R_s)f_e
\frac{1-p}{\gamma_{\max,i}^{1-p}-\gamma_{m,i}^{1-p}} .
\]
Thus the source carries the swept electron number over the finite radial shell
increment, while \(\gamma_m\) and \(\gamma_{\max}\) remain the shell-level shock
values for this explicit transport option.

The flux variable reconstructed by the code is \(F=v_xN_x\).  Because the
equation uses \(+\partial_xF\), positive \(v_x\) moves particles toward lower
\(x\), so the upwind WENO stencil is the right-biased one; negative \(v_x\) uses
the left-biased stencil.  For a left-biased interface, with
\(f_m=F_{i+m}\), the three candidate fifth-order ingredients are
\[
\hat f_0=\frac{1}{3}f_{-2}-\frac{7}{6}f_{-1}+\frac{11}{6}f_0,
\quad
\hat f_1=-\frac{1}{6}f_{-1}+\frac{5}{6}f_0+\frac{1}{3}f_1,
\]
\[
\hat f_2=\frac{1}{3}f_0+\frac{5}{6}f_1-\frac{1}{6}f_2 .
\]
The Jiang--Shu smoothness indicators are
\[
\beta_0=\frac{13}{12}(f_{-2}-2f_{-1}+f_0)^2
+\frac{1}{4}(f_{-2}-4f_{-1}+3f_0)^2,
\]
\[
\beta_1=\frac{13}{12}(f_{-1}-2f_0+f_1)^2
+\frac{1}{4}(f_1-f_{-1})^2,
\]
\[
\beta_2=\frac{13}{12}(f_0-2f_1+f_2)^2
+\frac{1}{4}(3f_0-4f_1+f_2)^2 .
\]
With linear weights \(d=(0.1,0.6,0.3)\), the implemented WENO-Z weights are
\[
\tau_5=|\beta_0-\beta_2|,\qquad
\alpha_k=d_k\left[1+
\left(\frac{\tau_5}{\beta_k+\epsilon_W}\right)^2\right],
\qquad
\omega_k=\frac{\alpha_k}{\sum_m\alpha_m},
\]
where \(\epsilon_W=10^{-30}\) is the smoothness-weight regularization in the
Fortran kernel.  The left-biased numerical flux is
\[
F_{i+1/2}^{-}=\sum_{k=0}^{2}\omega_k\hat f_k .
\]
The right-biased flux used for \(v_x>0\) is the mirror of the same formula over
\((f_{i-1},f_i,f_{i+1},f_{i+2},f_{i+3})\).  Constant ghost cells at both energy
ends provide the five-point WENO stencil; they are numerical boundary states and
are not returned as physical electron bins.

Given
\[
\lambda=\frac{\Delta R}{\Delta x},
\qquad
\mathcal{D}_j(N)=F_{j+1/2}(N)-F_{j-1/2}(N),
\]
the time integrator is the third-order TVD Runge--Kutta sequence
\[
N_j^{(1)}=N_j^n+\lambda\mathcal{D}_j(N^n)+\Delta R\,Q_j,
\]
\[
N_j^{(2)}=\frac{3}{4}N_j^n+
\frac{1}{4}\left[N_j^{(1)}+
\lambda\mathcal{D}_j(N^{(1)})\right]
+\frac{1}{4}\Delta R\,Q_j,
\]
\[
N_j^{n+1}=\frac{1}{3}N_j^n+
\frac{2}{3}\left[N_j^{(2)}+
\lambda\mathcal{D}_j(N^{(2)})\right]
+\frac{2}{3}\Delta R\,Q_j .
\]
After each substep the stored conservative spectrum is projected to the physical
domain \(N_x\ge0\).  This is a positivity projection on the transported electron
population, not a smoothing operation on a light curve.  At the last substep in
an output shell the same exponential cell-shape reconstruction used by the
log-gamma solvers converts
\[
\left.\frac{dN_e}{d\gamma_e}\right|_j
=\frac{N_{x,j}^{\rm exp}}{\gamma_j\ln10}.
\]
The radiation arrays written during shell preparation are shell-left fields used
to build the cooling seed.  The final output point has no following shell, so
the WENO driver refreshes \(L_\nu^{\rm syn}\) and \(n_\nu^{\rm syn}\) from the
final transported electron spectrum and the final dynamics-grid field.

The public \texttt{charint\_1d} forward solver advances the same conservative cell averages
\[
N_{x,j}(R)=\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}\frac{dN_e}{dx}\,dx,
\qquad x=\log_{10}\gamma_e,
\]
by direct characteristic integration.  For the output shell \(R_{i-1}\rightarrow R_i\), the solver uses
\[
R_{\rm loc}=R_{i-1},\qquad
\Gamma_{\rm sh}=\frac{\Gamma_i+\Gamma_{i-1}}{2},\qquad
n_{\rm ext}=n(R_{\rm loc}),
\]
and constructs
\[
B'=0.39\left[\epsilon_Bn_{\rm ext}\Gamma_{\rm sh}(\Gamma_{\rm sh}-1)\right]^{1/2},
\qquad
\gamma_{\max}=\frac{3m_ec^2}{(8B'e^3)^{1/2}},
\]
\[
\gamma_c=\frac{7.7\times10^8(1+z)}
{\Gamma_{\rm sh}B'^2t_{\rm obs,i}},
\qquad
\beta_{\rm sh}=(1-\Gamma_{\rm sh}^{-2})^{1/2}.
\]
The minimum injection Lorentz factor is the same \(\gamma_m\) solution given above, with
\[
\frac{\epsilon_e}{f_e}\frac{m_p}{m_e}(\Gamma_{\rm sh}-1)
\]
as the energy per accelerated electron.  These shell quantities set the diagnostics and the initial trial substep.  During non-uniform-density transport, the same \(B'\), \(\gamma_{\max}\), and \(\gamma_m\) formulae are re-evaluated at \(R_{\rm mid}\) with \(n_{\rm step}=n(R_{\rm mid})\).  The non-adaptive radial split is set by the local high-energy cooling scale,
\[
f_r=\frac{1.35\times10^{-19}}{\pi\beta_{\rm sh}\Gamma_{\rm sh}}B'^2,
\qquad
\delta R_0=\frac{3.2}
{f_r\gamma_{\max}+1.333/(R_i+R_{i-1})},
\]
\[
L_i=\max\left[4,\min\left(2048,
\left\lceil\frac{R_i-R_{i-1}}{\delta R_0}\right\rceil\right)\right],
\qquad
\Delta R=(R_i-R_{i-1})/L_i .
\]
When adaptive substeps are enabled, the candidate step is bounded by
\[
\Delta R_{\min}=\frac{R_i-R_{i-1}}{N_{\max}},
\qquad
\Delta R_{\max}=\frac{R_i-R_{i-1}}{N_{\min}},
\]
and is accepted when
\[
\epsilon_R\le 8\,{\tt substep\_rtol}
\]
or the lower bound is reached.  For a uniform medium
\[
\epsilon_R=\Delta R/R_{\rm mid},
\]
whereas density jumps use
\[
\epsilon_R=\max\left[
\frac{\Delta R}{R_{\rm mid}},
\frac{|n(R+\Delta R)-n(R)|}{|n(R)|}
\right].
\]

At a substep midpoint, the injected electron source is normalized per radial length as
\[
\dot N_{{\rm inj},R}=
\frac{4\pi}{3}\frac{(R+\Delta R)^3-R^3}{\Delta R}
n_{\rm step}f_e
\frac{1-p}{\gamma_{\max}^{1-p}-\gamma_m^{1-p}} .
\]
The source profile placed on the \(x\) grid is
\[
S_x(x)=
\dot N_{{\rm inj},R}\ln 10\,\gamma_e^{1-p}
\,\mathcal{C}_{\max}(\gamma_e),
\qquad \gamma_e\ge\gamma_m,
\]
with \(S_x=0\) below \(\gamma_m\) and
\[
\mathcal{C}_{\max}(\gamma_e)=
\begin{cases}
1, & \gamma_e\le\gamma_{\max},\\
\exp(1-\gamma_e/\gamma_{\max}), & \gamma_e>\gamma_{\max}.
\end{cases}
\]
The cell source is the conservative average
\[
S_j=\frac{1}{\Delta x_j}
\int_{x_{j-1/2}}^{x_{j+1/2}}S_x(x)\,dx .
\]

The characteristic variable is \(u=1/\gamma_e\).  In the synchrotron-only branch, the loss law over one substep is
\[
\frac{d\gamma}{dR}=-a\gamma^2-b\gamma,\qquad
a=\frac{1.35\times10^{-19}}{\pi\beta_{\rm sh}\Gamma_{\rm sh}}B'^2,
\qquad b=R_{\rm mid}^{-1}.
\]
Thus
\[
\frac{du}{dR}=a+bu .
\]
For a face that arrives at \(u\) after a lag \(\tau\), the backward characteristic used by the code is
\[
u_{\rm back}=
\begin{cases}
u-a\tau, & |b|\tau\simeq0,\\[0.8ex]
(u+a/b)e^{-b\tau}-a/b, & {\rm otherwise}.
\end{cases}
\]
The general cooling branch first computes the node loss coefficients \(D_j\) from synchrotron, IC, and SSA terms.  In a non-uniform external medium the stored shell loss array is rescaled by \(n_{\rm step}/n_{\rm ext}\) before the characteristic map is built.  With \(u_j=1/\gamma_j\), it linearly reconstructs
\[
w(u)=uD(u)
\]
inside each \(u\)-cell as \(w(u)=a_k+s_ku\), then adds adiabatic cooling to obtain
\[
\frac{du}{dR}=a_k+(s_k+b_{\rm ad})u,\qquad b_{\rm ad}=R_{\rm mid}^{-1}.
\]
The same analytic backward map is applied in the current \(u\)-cell; when the traced point reaches a cell edge, the remaining lag is carried into the adjacent cell with the new coefficients.

Let \(M_N(x)\) be the prefix integral of the positivity-limited PPM reconstruction of \(N_x\), and let \(M_S(x)\) be the corresponding exponential-reconstructed prefix integral of \(S_x\).  For arrival cell \(j\), direct conservation gives
\[
N_{x,j}^{n+1}=
\frac{M_N[x_{j+1/2}^{\rm back}(\Delta R)]
-M_N[x_{j-1/2}^{\rm back}(\Delta R)]}{\Delta x_j}
{}+\Delta R\sum_{q=1}^{4}w_q
\frac{M_S[x_{j+1/2}^{\rm back}(s_q\Delta R)]
-M_S[x_{j-1/2}^{\rm back}(s_q\Delta R)]}{\Delta x_j}.
\]
The quadrature nodes are \(s_q=t_q^4\), with weights \(w_q=4W_qt_q^3\), where \(t_q,W_q\) are the four-point Gauss--Legendre nodes and weights on \([0,1]\).  This is the implemented fourth-order source-in-characteristic integral.  After each output shell, the solver converts back to the centered diagnostic spectrum by the local exponential relation
\[
\frac{dN_e}{d\gamma_e}\bigg|_j
=\frac{N_{x,j}^{\rm exp}}{\gamma_j\ln 10}.
\]
The reported break frequencies are
\[
\nu_m=\frac{4.2\times10^6B'\gamma_m^2}
{\Gamma_{\rm sh}(1-\beta_{\rm sh})(1+z)},
\qquad
\nu_c=\frac{4.2\times10^6B'\gamma_c^2}
{\Gamma_{\rm sh}(1-\beta_{\rm sh})(1+z)},
\]
and the self-absorption diagnostic is obtained from the same final synchrotron optical-depth grid,
\[
\tau_\nu(\nu_a)=1,\qquad
\nu_{a,{\rm obs}}=\frac{\nu_a}
{\Gamma_{\rm sh}(1-\beta_{\rm sh})(1+z)}.
\]

The \texttt{dg\_1d} solver replaces the cell-average upwind update by a moving multi-domain nodal DG discretization on this same coordinate \(y\).  The represented state is the conservative coordinate density
\[
N_y(y,R)=\frac{dN_e}{dy}
=\frac{dN_e}{dx_g}\frac{dx_g}{dy}.
\]
On element \(K_k=[y_{k,L},y_{k,R}]\), with \(y=y_k+\Delta y_kr/2\) and \(r\in[-1,1]\),
\[
N_y^h(y,R)\big|_{K_k}=
\sum_{\ell=0}^{p_{\rm DG}}N_{k\ell}(R)\ell_\ell(r),
\qquad p_{\rm DG}=12,
\]
where \(\ell_\ell\) are Lagrange polynomials on the Legendre--Gauss--Lobatto nodes.  The mesh is rebuilt at each shell from active break positions \(\log_{10}\gamma_m\), \(\log_{10}\gamma_c\), and \(\log_{10}\gamma_{\max}\); active intervals are split into six DG elements, and breaks outside the electron grid or indistinguishable at the current log-grid width are removed from the element-boundary list.

The forward \texttt{dg\_1d} entry supplies the physical shell data to this DG kernel.  Its fixed diagnostic electron grid is the shared four-velocity grid with \(\gamma_{\rm scale}=2\), but its upper edge is chosen as a coverage estimate
\[
\gamma_{\rm grid,max}=30\,\frac{3m_ec^2}{(8B'_{\rm ref}e^3)^{1/2}},
\qquad
B'_{\rm ref}=0.39\left[\epsilon_Bn(R_1)\Gamma_N(\Gamma_N-1)\right]^{1/2},
\]
where \(\Gamma_N\) is the last dynamics-grid Lorentz factor.  At every output shell the driver uses
\[
\bar\Gamma_i=\frac{\Gamma_i+\Gamma_{i-1}}{2}
\]
and computes the current shell break values
\[
\gamma_{\max,i}=\frac{3m_ec^2}{(8B_i'e^3)^{1/2}},
\qquad
\gamma_{m,i}=\gamma_m\!\left[
\frac{\epsilon_e}{f_e}\frac{m_p}{m_e}(\bar\Gamma_i-\!1),
\gamma_{\max,i},p\right],
\qquad
\gamma_{c,i}=\frac{7.7\times10^8(1+z)}
{\bar\Gamma_iB_i'^2t_{{\rm obs},i}},
\]
before writing the local break-frequency diagnostics and constructing the substep injection source.  The ordinary shell remesh keeps the existing active support unless the high-energy source support requires extension.  For a trial upper cutoff \(\gamma_u\), the source support endpoint is
\[
x_{{\rm src},\max}=
\log_{10}\left[\min(\gamma_{\rm grid,max},30\gamma_u)\right],
\]
and the active high-energy edge is not contracted while the existing DG state carries a significant high-energy moment,
\[
\frac{\int_{\gamma_e\ge10^{x_{{\rm src},\max}}}
N_y\gamma_e^2\,dy}
{\int N_y\gamma_e^2\,dy}
>10^{-10}.
\]
If a substep source extends beyond the current active DG edge, the driver rebuilds the mesh using the current \(\gamma_{m,i}\), \(\gamma_{c,i}\), and \(\gamma_{\max,i}\) for that remap.  The regular radial split is
\[
\Delta R_{\rm DG}=\frac{R_i-R_{i-1}}{10}.
\]
For each Gaussian density jump with width \(\sigma_j=w_jR_j\), the candidate step is cut at the marker set
\[
R_j+\sigma_j\{-4,-2,-1,0,1,2,4\},
\]
and inside the \(|R-R_j|<4\sigma_j\) window it also obeys
\[
\Delta R\le \frac{\sigma_j}{8}.
\]
The final density-slope limiter uses the jump enhancement
\[
\mathcal{E}(R)=1+\sum_j(f_j-1)
\exp\left[-\frac{(R-R_j)^2}{2\sigma_j^2}\right],
\qquad
\Delta R\le \frac{0.05}{|d\ln\mathcal{E}/dR|}.
\]

At a DG substep midpoint \(R_{\rm mid}\), the driver re-evaluates \(n(R_{\rm mid})\), \(B'\), \(\gamma_{\max}\), and \(\gamma_m\) unless the medium is strictly uniform.  It first builds a unit-normalized DG source template \(\widetilde Q_y^h\), then rescales that template so that its DG integral equals the conservative finite-cell source integral in the same \(y\) measure,
\[
\widetilde Q_y^h\leftarrow
\widetilde Q_y^h
\frac{\sum_j \bar Q_{y,j}\Delta y_j}
{\int \widetilde Q_y^h\,dy}.
\]
The source entering the implicit DG step is
\[
Q_y^h(R_{\rm mid})=
\dot N_{{\rm inj},R}(R_{\rm mid},\Delta R)\,\widetilde Q_y^h .
\]
The cooling array is computed once from the shell radiation field and, for a non-uniform medium, scaled locally as
\[
D_j(R_{\rm mid})=
D_j(R_{i-1})\frac{n(R_{\rm mid})}{n(R_{i-1})}.
\]
The substep sent to the DG kernel is therefore
\[
\frac{\partial N_y}{\partial R}
+\frac{\partial}{\partial y}
\left[
-\frac{D(R_{\rm mid})+R_{\rm mid}^{-1}}
{\ln 10\,dx_g/dy}N_y
\right]
=Q_y^h(R_{\rm mid}).
\]

After each output radius, the DG polynomial is projected back to the fixed diagnostic grid by exact cell-overlap quadrature,
\[
\bar N_{y,j}^{\rm out}=
\frac{1}{\Delta y_j}
\sum_k\int_{[y_{j-1/2},y_{j+1/2}]\cap K_k}
N_y^h(y)\,dy .
\]
The published electron array is then
\[
\left.\frac{dN_e}{d\gamma_e}\right|_j=
\frac{N_{y,j}^{\rm exp}}
{\gamma_j\ln 10\,(dx_g/dy)_j},
\]
where \(N_{y,j}^{\rm exp}\) is the center value of the local exponential reconstruction of the cell average.  The driver requires the DG integral and the projected fixed-grid integral to remain positive,
\[
\int N_y^h\,dy>0,\qquad
\sum_j\frac{dN_e}{d\gamma_e}\bigg|_j
\gamma_j\ln 10\,\Delta x_j>0,
\]
and the final output radius is explicitly refreshed through the same synchrotron optical-depth grid used for \(\nu_a\), so the returned \(\nu_m\), \(\nu_c\), and \(\nu_a\) arrays are tied to the final electron spectrum rather than to a stale pre-advance shell.

Source projection uses the same conservative density.  For a source written in log-energy form \(Q_{x_g}\), the DG integrand is
\[
Q_y(y)=Q_{x_g}[x_g(y)]\frac{dx_g}{dy}.
\]
The modal source coefficients in one element are
\[
\widehat Q_{km}=
\frac{2m+1}{\Delta y_k}
\int_{y_{k,L}}^{y_{k,R}}Q_y(y)P_m[r(y)]\,dy,
\qquad
Q_{k,i}=\sum_{m=0}^{p_{\rm DG}}\widehat Q_{km}P_m(r_i),
\]
with Gauss--Legendre quadrature for the integral.  The reverse-shock kinetic source uses
\[
Q_y=\dot N_0\gamma_e\ln 10\,
(\gamma_e-1)^{-p}\exp(-\gamma_e/\gamma_{\max})\frac{dx_g}{dy},
\]
while the forward source uses the shared cutoff power-law profile and is scaled so that the DG source carries the same shell-integrated injected electron number as the edge-integrated source.

In the DG coordinate the transport equation is
\[
\frac{\partial N_y}{\partial R}
+\frac{\partial}{\partial y}\left(v_yN_y\right)=Q_y,
\qquad
v_y=-\frac{D_{\rm rad}+D_{\rm ad}}
{\ln 10\,dx_g/dy}.
\]
The forward path passes \(D_{\rm ad}=R^{-1}\) and \(D_{\rm rad}\) from the cooling assembler; the reverse path uses either \(R^{-1}\) before crossing or the stored post-crossing volume loss \(d\ln V_3/(3\,dR)\).  For the production \texttt{dg\_1d} path the local advection problem is advanced with a fully implicit nodal DG step.  In each element the code forms the dense \(13\times13\) block
\[
\left[
\delta_{ij}
-\Delta R
\frac{2}{\Delta y_k}
\frac{w_j}{w_i}D_{ji}v_{y,j}
\right]N_{k,j}^{n+1}
=N_{k,i}^{n}+\Delta R\,Q_{k,i}
+\mathcal{F}_{k,i}^{\rm up},
\]
where \(D_{ji}=d\ell_i/dr|_{r_j}\), \(w_i\) are the LGL quadrature weights, and \(\mathcal{F}_{k,i}^{\rm up}\) is the upwind boundary contribution.  Radiative and adiabatic losses usually give \(v_y<0\), so the element blocks are solved from the high-energy element to the low-energy element with the already-computed upstream right-face state entering the next block.  If any node has \(v_y>0\), the same DG flux matrix is assembled as one global dense implicit system with upwind face states on both sides.  In four-velocity DG coordinates the first low-energy face is closed, so cooled particles that trace below the finite grid are kept in the first element rather than being removed.  Density jumps activate additional shell substeps: candidate substep boundaries are placed around each Gaussian jump, and a local logarithmic density-slope limit prevents the DG mesh from advancing across a sharp density change in one radial solve.

Mesh changes and characteristic updates are conservative in the same coordinate measure.  If a new coordinate \(y_{\rm n}\) and old coordinate \(y_{\rm o}\) represent the same \(\gamma_e\), the remapped density is
\[
N_{\rm n}(y_{\rm n})=
N_{\rm o}(y_{\rm o})
\frac{dy_{\rm o}}{dy_{\rm n}}
=
N_{\rm o}(y_{\rm o})
\frac{(dx_g/dy)_{\rm n}}{(dx_g/dy)_{\rm o}},
\]
and a final scalar rescaling enforces equality of
\[
N_{\rm tot}=\sum_k\frac{\Delta y_k}{2}
\sum_i w_iN_{k,i}.
\]
After a projection or step, the element-local positivity limiter keeps the cell average
\[
\bar N_k=\frac{1}{2}\sum_iw_iN_{k,i}
\]
fixed and replaces nodal values by
\[
N_{k,i}\leftarrow
\bar N_k+\theta_k(N_{k,i}-\bar N_k),
\qquad
\theta_k=\min\left[1,\frac{\bar N_k}{\bar N_k-N_{k,\min}}\right],
\]
when \(N_{k,\min}<0<\bar N_k\).  The optional Jackson or Fejer modal filter multiplies only high-order modal coefficients in flagged DG elements; it is a numerical positivity kernel for the DG representation, not an observer-level smoothing of light curves.

The DG kernel also contains a conservative characteristic projector for the same loss equation.  For an affine loss law
\[
\frac{d\gamma}{dR}=-a_{\rm rad}\gamma^2-b_{\rm ad}\gamma,
\]
the forward map over lag \(\Delta R\) is
\[
\gamma(R+\Delta R)=
\begin{cases}
\displaystyle \frac{\gamma(R)}
{1+a_{\rm rad}\gamma(R)\Delta R}, &
|b_{\rm ad}\Delta R|\ll1,\\[1.1ex]
\displaystyle
\frac{\gamma(R)e^{-b_{\rm ad}\Delta R}}
{1+(a_{\rm rad}/b_{\rm ad})\gamma(R)
\left[1-e^{-b_{\rm ad}\Delta R}\right]}, & {\rm otherwise}.
\end{cases}
\]
The inverse map used by \texttt{dg\_project\_char} is
\[
\gamma_{\rm back}=
\begin{cases}
\displaystyle \frac{\gamma_{\rm now}}
{1-a_{\rm rad}\gamma_{\rm now}\Delta R}, &
|b_{\rm ad}\Delta R|\ll1,\\[1.1ex]
\displaystyle \frac{\gamma_{\rm now}}
{e^{-b_{\rm ad}\Delta R}-(a_{\rm rad}/b_{\rm ad})
\left[1-e^{-b_{\rm ad}\Delta R}\right]\gamma_{\rm now}}, &
{\rm otherwise}.
\end{cases}
\]
The inverse map is used to project upstream DG polynomials onto the arrival element with Gauss--Legendre quadrature and Legendre modal moments.  Any finite-grid content whose characteristic exits below the first four-velocity element is accumulated as \(M_{\rm low}\) and written back as a uniform first-element density \(M_{\rm low}/\Delta y_1\).  This characteristic projector is part of the DG transport kernel and is used for conservative remapping and diagnostic characteristic advances; the public \texttt{dg\_1d} forward light-curve path currently advances the shell-local transport operator with the fully implicit block solve described above.

Cooling is assembled from synchrotron, inverse-Compton, and self-absorption terms before the transport solver adds adiabatic drift.  The forward cooling kernel stores a positive radial loss coefficient \(D_i(R)\) at each electron grid node,
\[
\frac{d\gamma_i}{dR}=-D_i\gamma_i,
\qquad
v_{\log\gamma,i+1/2}
=\frac{(D_i+D_{i+1})/2+R^{-1}}{\ln 10},
\]
so positive \(v_{\log\gamma}\) advects the distribution toward lower \(\gamma_e\).  The synchrotron coefficient follows from
\[
\left.\frac{d\gamma_i}{dR}\right|_{\rm syn}
=-\frac{\sigma_T B'^2}{6\pi m_ec^2\,\beta\Gamma}\gamma_i^2
\equiv -a_{\rm syn}\gamma_i^2,
\qquad
a_{\rm syn}=\frac{\sigma_T B'^2}{6\pi m_ec^2\,\beta\Gamma},
\]
where the code constant \(1.35\times10^{-19}/\pi\) is
\(\sigma_T/(6\pi m_ec^2)\) in cgs units.  The comoving-to-radial conversion for photon-mediated terms is \(dt'/dR=(\beta\Gamma c)^{-1}\).  Let \(A_{{\rm IC},i}\) be the numerical IC/KN coefficient from the seed photon field, \(A_{{\rm SSA},i}\) the synchrotron-self-absorption heating coefficient, and \(Y_i\) an analytic Compton factor.  The assembler implements
\[
D_i=
\begin{cases}
a_{\rm syn}\gamma_i, & \texttt{index\_Y}=0,\\[0.6ex]
\left[a_{\rm syn}+
\dfrac{A_{{\rm IC},i}-A_{{\rm SSA},i}}{\beta\Gamma c}
\right]\gamma_i, & \texttt{index\_Y}=1,\\[2ex]
\left[a_{\rm syn}(1+Y_{{\rm N},i})
-\dfrac{A_{{\rm SSA},i}}{\beta\Gamma c}
\right]\gamma_i, & \texttt{index\_Y}=2,\\[2ex]
\left[a_{\rm syn}(1+Y_{{\rm F},i})
-\dfrac{A_{{\rm SSA},i}}{\beta\Gamma c}
\right]\gamma_i, & \texttt{index\_Y}=3.
\end{cases}
\label{eq:electron-forward-cooling-assembly}
\]
The \(Y\)-kernel supplies the two analytic Compton closures used by Eq.~(\ref{eq:electron-forward-cooling-assembly}).  The Nakar-style branch computes the seed-luminosity part below the electron-dependent Klein--Nishina threshold \citep{NakarAndoSari2009},
\[
\hat\nu_i=\frac{m_ec^2}{h\gamma_i},\qquad
L_{<,i}^{\rm syn}=
\int_{\nu_{\min}}^{\min(\hat\nu_i,\nu_{\max})}
L_\nu^{\rm syn}\,d\nu,
\]
and the assembler converts that luminosity to the Compton factor
\[
Y_{{\rm N},i}=
\frac{L_{<,i}^{\rm syn}}
{4\pi R^2c\,4\Gamma^2nm_pc^2},
\]
using two-point logarithmic Gauss integration in every seed-frequency cell.  The Fan-style branch uses an analytic Klein--Nishina energy fraction \citep{FanPiran2008}.  For each electron node,
\[
\eta=\min\left[1,\left(\frac{\gamma_m}{\gamma_c}\right)^{p-2}\right],
\qquad
\hat\gamma_i=
\left(\frac{m_ec^2}{hC_\nu B'\gamma_i}\right)^{1/2}
=5.4246\times10^6(B'\gamma_i)^{-1/2},
\]
where \(C_\nu=3e/(4\pi m_ec)\).  The returned analytic factor solves
\[
Y_{{\rm F},i}(1+Y_{{\rm F},i})
=\eta\,\eta_{{\rm KN},i}\frac{\epsilon_e}{\epsilon_B},
\qquad
Y_{{\rm F},i}=
\frac{-1+\sqrt{1+4\eta\eta_{{\rm KN},i}\epsilon_e/\epsilon_B}}{2}.
\]
For fast cooling, \(\gamma_m>\gamma_c\), the code evaluates
\[
\eta_{{\rm KN},i}=
\begin{cases}
0, & \hat\gamma_i<\gamma_c,\\[0.6ex]
\dfrac{\hat\gamma_i-\gamma_c}
{(p-1)\gamma_m/(p-2)-\gamma_c},
& \gamma_c\le\hat\gamma_i<\gamma_m,\ p>2,\\[2ex]
\dfrac{(2-p)(\hat\gamma_i-\gamma_c)}
{\gamma_m^{p-1}\gamma_{\max}^{2-p}-(p-1)\gamma_m-(2-p)\gamma_c},
& \gamma_c\le\hat\gamma_i<\gamma_m,\ p\le2,\\[2ex]
1-\dfrac{\gamma_m^{p-1}\hat\gamma_i^{2-p}}
{(p-1)\gamma_m-(p-2)\gamma_c},
& \gamma_m\le\hat\gamma_i<\gamma_{\max},\ p>2,\\[2ex]
1-\dfrac{\gamma_m^{p-1}\gamma_{\max}^{2-p}
-(p-1)\gamma_m-(2-p)\gamma_c}
{\gamma_m^{p-1}(\gamma_{\max}^{2-p}-\hat\gamma_i^{2-p})},
& \gamma_m\le\hat\gamma_i<\gamma_{\max},\ p\le2,\\[2ex]
1, & \hat\gamma_i\ge\gamma_{\max}.
\end{cases}
\]
For slow cooling, \(\gamma_m\le\gamma_c\), it uses
\[
\eta_{{\rm KN},i}=
\begin{cases}
0, & \hat\gamma_i<\gamma_m,\\[0.6ex]
\dfrac{\hat\gamma_i^{3-p}-\gamma_m^{3-p}}
{\gamma_c^{3-p}/(p-2)-\gamma_m^{3-p}},
& \gamma_m\le\hat\gamma_i<\gamma_c,\ p>2,\\[2ex]
\dfrac{(2-p)(\hat\gamma_i^{3-p}-\gamma_m^{3-p})}
{(3-p)\gamma_c\gamma_{\max}^{2-p}
-\gamma_c^{3-p}-(2-p)\gamma_m^{3-p}},
& \gamma_m\le\hat\gamma_i<\gamma_c,\ p\le2,\\[2ex]
1-\dfrac{(3-p)\gamma_c\hat\gamma_i^{2-p}}
{\gamma_c^{3-p}-(p-2)\gamma_m^{3-p}},
& \gamma_c\le\hat\gamma_i<\gamma_{\max},\ p>2,\\[2ex]
1-\dfrac{(3-p)\gamma_c(\gamma_{\max}^{2-p}-\hat\gamma_i^{2-p})}
{(3-p)\gamma_c\gamma_{\max}^{2-p}
-\gamma_c^{3-p}-(2-p)\gamma_m^{3-p}},
& \gamma_c\le\hat\gamma_i<\gamma_{\max},\ p\le2,\\[2ex]
1, & \hat\gamma_i\ge\gamma_{\max}.
\end{cases}
\]
Self-absorption appears with the opposite sign because absorbed synchrotron photons heat the same electron grid.  Joint hadronic feedback requires the numeric IC/KN cooling path because the secondary source \(Q_{e,{\rm sec},R}\) and the attenuated photon field must be evaluated against the same local \(N_e,n_\gamma\) state; an analytic \(Y\) closure would decouple those two objects.  The public Python cooling modes expose the no-IC, numeric IC/KN, and Nakar-style branches; the Fan-style branch is an internal Fortran closure.

The SSA cooling helper computes the coefficient \(A_{{\rm SSA},i}\) in Eq.~(\ref{eq:electron-forward-cooling-assembly}) from the local seed photon number density \(n_\nu\).  With
\[
\nu_B=\frac{eB'}{2\pi m_ec},\qquad
\nu_{\min,i}=\frac{\nu_B}{\gamma_i},\qquad
\nu_{u,i}=\frac{3}{2}\gamma_i^2\nu_B,
\]
the implemented absorption kernel is split at \(\nu_{u,i}\):
\[
\Sigma_i(\nu)=
\begin{cases}
C_1\dfrac{B_Q}{B'}(3\nu_{\min,i})^{5/3}\nu^{-5/3},
& \nu_{\min,i}<\nu\le\nu_{u,i},\\[2ex]
C_2\dfrac{B_Q}{B'}\gamma_i^{-3}
\dfrac{\nu_B}{\nu}\exp(-\nu/\nu_{u,i}),
& \nu>\nu_{u,i},
\end{cases}
\]
where \(B_Q=4.4\times10^{13}\,{\rm G}\),
\(C_1=2.5042\times10^{-22}\), and
\(C_2=7.787\times10^{-22}\) are the cgs constants used by the single-particle absorption kernel.  The returned coefficient is
\[
A_{{\rm SSA},i}
=c\int_{\nu_{\min,i}}^{\nu_{\max}}
h\nu\,n_\nu\,\Sigma_i(\nu)\,d\nu .
\]
The helper finds the first seed-frequency node above \(\nu_{\min,i}\), the first node above \(\nu_{u,i}\), and clips only the two boundary cells; complete low-frequency cells are accumulated with a prefix sum
\[
P_k=\sum_{\ell=1}^{k}
hc\sum_{q=1}^{2}w_{\ell q}
n_\nu(\nu_{\ell q})\nu_{\ell q}^{-2/3},
\]
so their contribution is
\[
C_1\frac{B_Q}{B'}(3\nu_{\min,i})^{5/3}
\left(P_{k_2}-P_{k_1-1}\right).
\]
The high-frequency cells use the same two-point logarithmic Gauss nodes and evaluate
\[
C_2\frac{B_Q}{B'}\gamma_i^{-3}\nu_B hc
\sum_{\ell,q} w_{\ell q}n_\nu(\nu_{\ell q})
\exp(-\nu_{\ell q}/\nu_{u,i}).
\]
Here \(\nu_{\ell q}\) and \(w_{\ell q}\) are obtained by applying two-node Gauss--Legendre quadrature in \(x=\ln\nu\), so \(w_{\ell q}\) already includes the \(d\nu=\nu\,dx\) Jacobian.  Within each frequency cell the shared interpolation helper supplies the local \(n_\nu\); for positive endpoints this is a log--log power-law interpolation.

The grid-level IC cooling kernel first moves the seed photon field to logarithmic frequency-cell midpoints,
\[
\nu_{0,k+1/2}=(\nu_{0,k}\nu_{0,k+1})^{1/2},\qquad
\Delta\nu_{0,k+1/2}=\nu_{0,k+1/2}
\left(\ln\nu_{0,k+1}-\ln\nu_{0,k}\right),
\]
and evaluates the photon number density \(n_{\nu_0}\) there by power-law interpolation.  For each electron node \(\gamma_i\), the dimensionless seed and scattered photon energies are
\[
\epsilon_0=\frac{h\nu_0}{m_ec^2},\qquad
\epsilon=\frac{h\nu}{m_ec^2},
\]
with \(\Gamma_\epsilon=4\gamma_i\epsilon_0\), scattering limit
\[
\epsilon\le
\epsilon_{\max}=\frac{4\gamma_i^2\epsilon_0}
{1+4\gamma_i\epsilon_0},
\]
and Jones variable
\[
q=\frac{\epsilon}{\Gamma_\epsilon(\gamma_i-\epsilon)} .
\]
Scattered bins that satisfy the kinematic limits and lie in the low-frequency Thomson branch
\(\nu_0/(4\gamma_i^2)<\nu\le\nu_0\) use
\[
G_{\rm T}=\frac{\nu}{\nu_0}-\frac{1}{4\gamma_i^2},
\]
and the remaining allowed bins use \(G(q,\Gamma_\epsilon)\) from Eq.~(\ref{eq:ssc-kernel}).  The auxiliary loss coefficient passed to the cooling assembler is therefore
\[
A_{\rm IC}(\gamma_i)=
\frac{3ch\sigma_T}{4m_ec^2\gamma_i^3}
\int d\nu_0\,\frac{n_{\nu_0}}{\nu_0}
\int d\nu\,\nu\,G_{\rm loss}(\nu,\nu_0,\gamma_i),
\]
where \(G_{\rm loss}\) denotes the branch-selected kernel above.  This is the \(A_{{\rm IC},i}\) coefficient in Eq.~(\ref{eq:electron-forward-cooling-assembly}).  The coupled electron--photon budget path evaluates the same kernel with Simpson weights on the log-spaced seed and scattered-frequency grids,
\[
A_{\rm IC}^{\rm budget}(\gamma_i)=
\frac{3ch\sigma_T}{4m_ec^2\gamma_i^3}
\frac{\Delta\ln\nu^2}{9}
\sum_l w_l\nu_l^2
\left[\sum_k w_k n_{\nu_k}K_{lk}(\gamma_i)\right],
\]
using \(K_{lk}=G(q,\Gamma_\epsilon)\) when the seed bin is below the scattered bin and \(K_{lk}=\max[\nu_l/\nu_k-1/(4\gamma_i^2),0]\) for the low-frequency branch.  This path supplies the auxiliary coefficient used by the implicit cooling solve in the joint feedback calculation.

The synchrotron emissivity uses the standard single-particle kernel and the same electron distribution that is transported,
\[
L_\nu^{\rm syn}(R)=
\frac{\sqrt{3}e^3B'}{m_ec^2}
\int N_e(\gamma_e,R)
F\!\left(\frac{\nu}{\nu_c}\right)d\gamma_e,
\qquad
\nu_c=\frac{3eB'}{4\pi m_ec}\gamma_e^2,
\]
with self-absorption applied through the shell transfer factor \((1-e^{-\tau_\nu})/\tau_\nu\) and seed photon density \(n_\nu^{\rm syn}=L_\nu^{\rm syn}/(4\pi R^2ch\nu)\) \citep{RybickiLightman1979,Sari1998,Granot2002}.

The implementation in \texttt{electron\_radiation\_kernel} resolves this local statement into explicit quadratures.  The frequency kernel used by the fast synchrotron paths is the analytic fit
\[
F_{\rm fit}(x)=
\begin{cases}
1.81x^{1/3}, & x<3\times10^{-6},\\
1.81\exp(-x)\left[x^{-2/3}+(3.62/\pi)^2\right]^{-1/2},
&3\times10^{-6}\le x\le30,\\
0, &x>30,
\end{cases}
\qquad x=\frac{\nu}{\nu_c}.
\]
On the one-dimensional logarithmic electron grid \(x_i=\ln\gamma_i\) with spacing \(h\), Simpson weights \(w_i=(1,4,2,\ldots,4,1)\), and \(N_i=dN_e/d\gamma_e(\gamma_i)\), the fixed-grid branch evaluates
\[
L_{\nu,{\rm em}}=
C_{\rm syn}B'\frac{h}{3}
\sum_i w_iN_i\gamma_i
F_{\rm fit}\!\left(\frac{\nu}{4.2\times10^6B'\gamma_i^2}\right),
\qquad
C_{\rm syn}=\frac{\sqrt{3}e^3}{m_ec^2}.
\]
The self-absorption optical depth is the column-density form of the standard absorption coefficient.  With
\[
q_i=\frac{N_i}{\gamma_i^2},\qquad
\bar\gamma_{i+1/2}=\frac{\gamma_i+\gamma_{i+1}}{2},
\]
the finite-volume endpoint difference gives
\[
\tau_\nu=
\frac{C_\tau B'}{4\pi R^2\nu^2}
\sum_i
\bar\gamma_{i+1/2}^2
\left(q_i-q_{i+1}\right)
F_{\rm fit}\!\left[
\frac{\nu}{4.2\times10^6B'\bar\gamma_{i+1/2}^2}
\right],
\qquad
C_\tau=\frac{\sqrt{3}e^3}{8\pi m_e^2c^2}
\simeq1.046\times10^4 .
\]
The emitted, transferred, and seed fields stored on the radius grid are then
\[
{\cal T}(\tau_\nu)=\frac{1-\exp(-\tau_\nu)}{\tau_\nu},\qquad
L_\nu^{\rm syn}=L_{\nu,{\rm em}}{\cal T}(\tau_\nu),\qquad
n_\nu^{\rm syn}=\frac{L_\nu^{\rm syn}}{4\pi R^2ch\nu}.
\]
For the state grid used by the fixed one-zone path, the stored transfer argument is \(\max(\tau_\nu,10^{-4})\); the adaptive \(\nu_a\) root below evaluates the unfloored optical depth.

When \(\texttt{index\_syn\_intger}=4\), electrons with \(\gamma_e\ge2\) use the same synchrotron quadrature and electrons with \(\gamma_e<2\) add a fundamental cyclotron-bin contribution.  For an electron segment
\[
N_{{\rm seg},i}=\frac{N_i+N_{i+1}}{2}(\gamma_{i+1}-\gamma_i),
\qquad
\gamma_{{\rm seg},i}=\frac{\gamma_i+\gamma_{i+1}}{2},
\]
the code places the power at
\[
\nu_0=\frac{\nu_B}{\gamma_{{\rm seg},i}},\qquad
\nu_B=\frac{eB'}{2\pi m_ec},
\]
in the frequency bin that contains \(\nu_0\).  The bin luminosity increment is
\[
\Delta L_{\nu_k,{\rm em}}=
\frac{N_{{\rm seg},i}}{\Delta\nu_k}
\frac{4}{3}\sigma_Tc\frac{B'^2}{8\pi}
\gamma_{{\rm seg},i}^2
\left(1-\gamma_{{\rm seg},i}^{-2}\right),
\]
and the same transfer factor \({\cal T}(\tau_{\nu_k})\) converts it to the absorbed luminosity and seed photon density.

Several public helpers in this kernel are numerical forms of the same local radiation quantities.  Positive endpoint interpolation uses the power-law form
\[
Y(\nu)=Y_0
\left(\frac{\nu}{\nu_0}\right)^{
\ln(Y_1/Y_0)/\ln(\nu_1/\nu_0)}
\]
between adjacent positive frequency bins, while non-positive endpoints are interpolated linearly.  For at least five output frequencies, the reduced frequency table keeps logarithmic spacing from \(x_0=\ln\nu_{\min}\) to \(x_t=x_0+0.85(x_1-x_0)\) and places the last point at \(x_1=\ln\nu_{\max}\); smaller reduced tables use ordinary logarithmic spacing.  The two-point log-Gauss rule used by \texttt{pl\_integral} and \texttt{ssa\_segment} is
\[
\int_{\nu_0}^{\nu_1}Y(\nu)d\nu
\simeq
\sum_{a=1}^2 \Delta x\,\nu_a\,Y(\nu_a),
\qquad
\nu_a=\exp(x_m\pm\Delta x/\sqrt{3}),
\]
with \(x_m=(\ln\nu_0+\ln\nu_1)/2\) and \(\Delta x=(\ln\nu_1-\ln\nu_0)/2\).  The self-absorption heating segment integrates
\[
\int_{\nu_0}^{\nu_1}\sigma_{\rm SSA}(\nu)n_\nu h\nu c\,d\nu,
\qquad
\sigma_{\rm SSA}=
\begin{cases}
C_{\rm SSA}\nu^{-5/3}, & \nu<\nu_u,\\
C_{\rm SSA}(\nu_B/\nu)\exp(-\nu/\nu_u), & \nu\ge\nu_u,
\end{cases}
\]
using this same quadrature and the local power-law photon interpolation.

The adaptive \(\nu_a\) solver evaluates the optical-depth integral off the stored frequency grid.  On a cell \([x_i,x_{i+1}]\) it linearly reconstructs \(N_e\) and \(q=N_e/\gamma^2\) in \(x=\ln\gamma\), compares two- and three-point Gauss estimates for both emissivity and optical depth, and splits the cell at its midpoint if
\[
\max\left(
\frac{|P^{(3)}-P^{(2)}|}{|P^{(3)}|},
\frac{|T^{(3)}-T^{(2)}|}{|T^{(3)}|}
\right)>5\times10^{-4}.
\]
The root condition is \(\tau_\nu(\nu_a)=1\).  Starting from \(10^4\) Hz, the bracket is expanded by factors of ten toward lower or higher frequency until it encloses unity, with lower and upper search bounds \(10^{-20}\) Hz and
\[
\nu_{\rm cap}=\max\left[10^{14}{\rm Hz},
\min\left(10^{30}{\rm Hz},10\max_i\nu_{c,i+1/2}\right)\right].
\]
Inside the bracket, the log-secant update is
\[
\ln\nu_\ast=
\ln\nu_l-\ln\tau_l
\frac{\ln\nu_h-\ln\nu_l}{\ln\tau_h-\ln\tau_l},
\]
clipped to the current bracket and iterated until the logarithmic width is below \(5\times10^{-3}\) or ten iterations have been reached.  When the optical-depth grid has already been computed, \texttt{nua\_fromtau} applies the same log-log root formula between the adjacent bins that straddle \(\tau_\nu=1\); if the crossing lies outside the supplied grid, it returns the corresponding boundary frequency.

The polarization helper keeps the same transferred intensity and computes only the local intrinsic synchrotron polarization fraction.  For a single particle,
\[
P_\perp\propto\frac{F(x)+G(x)}{2},\qquad
P_\parallel\propto\frac{F(x)-G(x)}{2},
\]
where
\[
F(x)=x\int_0^\infty
\exp[-x\cosh u]\frac{\cosh(5u/3)}{\cosh u}\,du,\qquad
G(x)=x\int_0^\infty
\exp[-x\cosh u]\cosh(2u/3)\,du .
\]
The frequency-local fraction is
\[
\Pi_\nu=
\frac{\int N_e(\gamma_e)[P_\perp(x)-P_\parallel(x)]d\gamma_e}
{\int N_e(\gamma_e)[P_\perp(x)+P_\parallel(x)]d\gamma_e},
\]
and the returned polarized luminosities are
\[
L_{\nu,\perp}=\frac{1+\Pi_\nu}{2}L_\nu^{\rm syn},\qquad
L_{\nu,\parallel}=\frac{1-\Pi_\nu}{2}L_\nu^{\rm syn}.
\]
For \(\chi\)-resolved states, the cumulative absorption path is
\[
\tau_{\nu,\le k}=\sum_{j=1}^k\tau_{\nu,j},
\qquad
\tau_{\nu,\le k}(\nu_{a,k})=1,
\]
and the shell-reduced spectra are log-\(\chi\) integrals,
\[
L_{\nu,{\rm shell}}=\sum_k \chi_k\Delta\eta\ln10\,L_{\nu,k},
\qquad
n_{\nu,{\rm shell}}=\sum_k \chi_k\Delta\eta\ln10\,n_{\nu,k}.
\]
The auxiliary modified Bessel function used by thermal normalizations returns the small-argument limit \(K_2(z)=2/z^2\), a tabulated piecewise-linear \(K_2\) value for \(10^{-4}\le z\le10\), and the large-argument expansion
\[
K_2(z)\simeq
\left(\frac{\pi}{2z}\right)^{1/2}e^{-z}
\left(1+\frac{15}{8z}+\frac{105}{128z^2}\right)
\]
outside the table at high \(z\).

The \texttt{adaptive\_resampling\_mod} helper implements an optional compression of a one-dimensional active electron spectrum before a synchrotron quadrature is evaluated.  This operation is not an electron-transport update: it does not evolve, renormalize, or smooth \(N_e\).  It selects a subset of already transported pairs \((\gamma_i,N_{e,i})\) for use by the emissivity integral above.  The direct wrapper \texttt{electron\_radiation\_grid} is compiled with the electron common kernels, but the currently inspected production light-curve kernels do not call this wrapper; the equations below are therefore the contract of the helper itself.  That contract is positive, ordered \(\gamma_i\) and positive \(N_{e,i}\).  The wrapper forms a candidate interval from the first and last positive spectrum bins, \(i_-\le i\le i_+\), and is correct for the contiguous positive spectra generated by the one-dimensional electron solvers.  If \(N_{\rm act}=i_+-i_-+1\le180\), the full grid is retained.  Otherwise the wrapper requests \(m=160\) samples and the resampler works on
\[
x_i=\log_{10}\gamma_i,\qquad y_i=\log_{10}N_{e,i}.
\]
The first derivative is evaluated by one-sided edge differences and two-sided interior differences,
\[
y'_1=\frac{y_2-y_1}{x_2-x_1},\qquad
y'_n=\frac{y_n-y_{n-1}}{x_n-x_{n-1}},\qquad
y'_i=\frac{y_{i+1}-y_{i-1}}{x_{i+1}-x_{i-1}},
\]
and the same stencil is applied to \(y'\) to estimate the log-log curvature,
\[
y''_1=\frac{y'_2-y'_1}{x_2-x_1},\qquad
y''_n=\frac{y'_n-y'_{n-1}}{x_n-x_{n-1}},\qquad
y''_i=\frac{y'_{i+1}-y'_{i-1}}{x_{i+1}-x_{i-1}} .
\]
With local log-grid width
\[
h_1=x_2-x_1,\qquad h_n=x_n-x_{n-1},\qquad
h_i=\frac{x_{i+1}-x_{i-1}}{2},
\]
the point importance is the curvature measure \(q_i=|y''_i|h_i\).  A five-point moving average gives \(\bar q_i\), and the sampling weight is
\[
w_i=\max\left(\bar q_i,\frac{\sum_j\bar q_j}{mg}\right),
\qquad g=4 .
\]
Point weights are converted to log-cell integral weights,
\[
W_1=w_1(x_2-x_1),\qquad
W_n=w_n(x_n-x_{n-1}),\qquad
W_i=w_i\frac{x_{i+1}-x_{i-1}}{2},
\]
with cumulative coordinate \(C_i=\sum_{j=1}^i W_j\).  Uniform targets in this coordinate,
\[
T_k=\frac{(k-1)C_n}{m-1},\qquad k=1,\ldots,m,
\]
are mapped back to the first source index satisfying \(C_i\ge T_k\).  Duplicate indices are removed; if curvature concentration produces fewer than \(m\) distinct indices, the missing slots are filled uniformly from the absent original indices and the final list is sorted.  In the exact zero-curvature limit all \(C_i\) vanish, so the same duplicate-removal and missing-index fill gives a uniform subset of the original log grid.  The radiation grid then keeps the first and last positive active bins, the selected interior active bins, and one neighboring bin on each side when such a bin exists.  The physical reason for this construction is that synchrotron emissivity depends on the shape of \(N_e(\gamma)\) in log energy: power-law parts are nearly straight in \((\log\gamma,\log N_e)\), while cooling breaks, injection turnovers, and cutoffs have large \(|d^2\log N_e/d(\log\gamma)^2|\) and require denser quadrature support.

The two-dimensional forward-electron wrapper advances the transported electron content on a finite downstream mass coordinate, not on an infinite \(\log_{10}\chi\) grid.  Let the strong-shock compression used by the kernel be \(r_{\rm sh}=4\).  The active domain is
\[
q_\ast=1-\left(1-\frac{1}{r_{\rm sh}}\right)^{r_{\rm sh}},
\qquad
q_{k+1/2}=k\Delta q,\qquad
\Delta q=\frac{q_\ast}{N_\chi},
\]
with \(q=0\) at the shock front.  The default \texttt{fullhide\_2d} branch uses the four-velocity coordinate \(y\) defined above and advances cell averages
\[
U_{ik}(R)=\frac{1}{\Delta y_i\Delta q}
\int_{\Delta y_i}\int_{\Delta q_k}\frac{dN_e}{dy\,dq}\,dq\,dy .
\]
The \texttt{charint\_2d} and optional \texttt{pwn\_cr\_v1} branches use \(x=\log_{10}\gamma_e\) in the same \(q\) domain.  The initial finite-width state is a shock-front injection of the already computed shell spectrum,
\[
U_{i1}(R_1)=\frac{N_i^{\rm init}}{\Delta q},
\qquad
U_{ik}(R_1)=0\quad(k>1),
\qquad
N_i(R_j)=\sum_{k=1}^{N_\chi}U_{ik}(R_j)\Delta q .
\]
This normalization is the reason the shell-reduced spectrum returns to the one-zone spectrum when the downstream dimension is integrated out.

The stored diagnostic \(\chi\) coordinate is derived from \(q\), while the transport geometry is evaluated by a finite-speed bridge between the ultra-relativistic Blandford--McKee limit and the planar strong-shock limit.  For an external profile index \(k\in\{0,2\}\),
\[
q_t=1-q,\qquad
\alpha=\frac{4-k}{3-k},\qquad
\chi_{\rm BM}=q_t^{-\alpha}.
\]
With shock-front four-speed \(u_f=(\Gamma_f^2-1)^{1/2}\), \(\beta_f=u_f/\Gamma_f\), and interpolation weight \(w=u_f^2/(1+u_f^2)\), the two limiting radius laws are
\[
\ell_{\rm BM}=-\frac{\chi_{\rm BM}-1}{4(4-k)\Gamma_f^2},
\qquad
\ell_{\rm ST}=\frac{\ln q_t}{r_{\rm sh}(3-k)} .
\]
The code stores
\[
r(q)=R\exp\!\left[w\ell_{\rm BM}+(1-w)\ell_{\rm ST}\right],
\]
and interpolates the downstream rapidity rather than \(\Gamma\) itself,
\[
u_{\rm BM}=\frac{u_f}{\chi_{\rm BM}^{1/2}},\qquad
\beta_{\rm ST}=\beta_f e^{\ell_{\rm ST}},\qquad
u_{\rm ST}=\frac{\beta_{\rm ST}}{(1-\beta_{\rm ST}^2)^{1/2}},
\]
\[
u(q)=\sinh\!\left[w\sinh^{-1}u_{\rm BM}
+(1-w)\sinh^{-1}u_{\rm ST}\right],
\qquad
\Gamma(q)=\left(1+u(q)^2\right)^{1/2}.
\]
The same limiting argument fixes the shock-pattern speed used for magnetic decay.  With
\[
u_{\rm pat}=\sinh\!\left[
w\sinh^{-1}\!\left(2\Gamma_f^2-1\right)^{1/2}
+(1-w)\sinh^{-1}\!\left(\frac{r_{\rm sh}}{r_{\rm sh}-1}u_f\right)
\right],
\]
\[
\beta_{\rm pat}=\frac{u_{\rm pat}}{(1+u_{\rm pat}^2)^{1/2}},
\qquad
\beta_{\rm rel,\chi}=
\frac{\beta_{\rm pat}-\beta_\chi}{1-\beta_{\rm pat}\beta_\chi}.
\]
The downstream cell width is built from \(dx'_\chi=\Gamma_\chi dx_{\rm lab}\), so the microturbulent-age variable entering the field decay is
\[
t'_\chi=\frac{x'_\chi}{\beta_{\rm rel,\chi}c}.
\]
When the magnetic-decay option is active,
\[
\epsilon_{B,\chi}=\epsilon_{B,\rm floor}
+(\epsilon_B-\epsilon_{B,\rm floor})
\left(1+\frac{t'_\chi}{t_0}\right)^{\alpha_t},
\]
and otherwise \(\epsilon_{B,\chi}=\epsilon_B\).  The local field used by synchrotron emission, SSA, cooling, and diffusion is
\[
B'_\chi=\left[32\pi\epsilon_{B,\chi}n(R)m_pc^2
\Gamma_f(\Gamma_f-1)\right]^{1/2},
\qquad
\kappa_{B,i\chi}=\frac{\gamma_i m_ec^3}{3eB'_\chi}.
\]

For every radial interval \([R_{j-1},R_j]\), the wrapper first constructs the local photon field that enters Eq.~(\ref{eq:electron-forward-cooling-assembly}).  The proper time along the front is integrated as
\[
t'_j=t'_{j-1}
+\frac{R_j-R_{j-1}}{\bar\beta_j\bar\Gamma_j c}.
\]
Radiation emitted in an older downstream cell is mapped to a target cell with the relative Doppler factor
\[
{\cal D}_{s\to t}=\Gamma_{\rm rel}(1+\beta_{\rm rel}),
\qquad
\beta_{\rm rel}=\frac{\beta_t-\beta_s}{1-\beta_t\beta_s},
\]
the source luminosity weight \({\cal D}_{s\to t}^3\), the seed-photon-density weight \({\cal D}_{s\to t}^2\), and the path transfer factor
\[
{\cal T}(\tau)=\frac{1-e^{-\tau}}{\tau}.
\]
The effective cooling seed in cell \(k\) is the sum of the current cell synchrotron seed and this streamed history field.  The cooling assembler then gives node coefficients \(D_{ik}\) satisfying \(d\gamma_i/dR=-D_{ik}\gamma_i\), using the same synchrotron, IC/KN, Nakar, Fan, and SSA terms as the one-dimensional forward solver.

The implementation in \texttt{electron\_seed\_history\_kernel} makes this history field a comoving light-cone transport problem on the finite downstream grid.  The proper time grid used by both the reference and production paths is
\[
t'_1=0,\qquad
t'_j=t'_{j-1}+
\frac{R_j-R_{j-1}}
{\bar\beta_j\bar\Gamma_jc},
\qquad
\bar\Gamma_j=\frac{\Gamma_j+\Gamma_{j-1}}{2}.
\]
For a source cell \(s=(m,a)\) and target cell \(t=(j,k)\), the source can contribute only if it lies upstream of the target and inside the comoving light cone,
\[
x_{m,a}\ge x_{j,k},\qquad
c(t'_j-t'_m)\ge x_{m,a}-x_{j,k}.
\]
The full-history accumulator uses the finite emitting fraction
\[
w_s=\min\left[1,\frac{c\Delta t'_m}{\Delta x'_{m,a}}\right],
\qquad
\Delta t'_m=t'_m-t'_{m-1},
\]
with \(\Delta t'_1=t'_2-t'_1\).  The relative Doppler factor between source and target cells is
\[
\beta_{\rm rel}=
\frac{\beta_t-\beta_s}{1-\beta_t\beta_s},\qquad
{\cal D}_{s\to t}=
\frac{1+\beta_{\rm rel}}{(1-\beta_{\rm rel}^2)^{1/2}}.
\]
The target frequency \(\nu\) samples the source spectrum at
\[
\nu_s=\frac{\nu}{{\cal D}_{s\to t}},
\]
and the code accepts the contribution only when \(\nu_s\) lies inside the cooling-frequency table.  Between two positive source bins \(\nu_l<\nu_s<\nu_{l+1}\), the interpolation is log-log,
\[
Q_s(\nu_s)=Q_{s,l}
\exp\!\left[
\frac{\ln\nu_s-\ln\nu_l}
{\ln\nu_{l+1}-\ln\nu_l}
\ln\!\left(\frac{Q_{s,l+1}}{Q_{s,l}}\right)
\right],
\]
where \(Q\) denotes either the locally transferred synchrotron luminosity field or the seed-photon-density field; a non-positive endpoint gives zero contribution.

The path absorption uses the same uniform-source transfer factor as the local synchrotron state, applied to every path segment,
\[
{\cal T}(\tau)=
\begin{cases}
1-\tau/2+\tau^2/6, & \tau<10^{-10},\\
(1-e^{-\tau})/\tau, & \tau\ge10^{-10}.
\end{cases}
\]
For a partial path length \(\Delta x\) inside cell \(q\),
\[
\tau_{\nu,q}^{\rm seg}
=\tau_{\nu,q}^{\rm prop}
\frac{\Delta x}{\Delta x'_q}.
\]
In code this is stored as \(\tau_{\nu,q}^{\rm prop}\Delta x/\Delta x'_q\).  Complete cells are accumulated through prefix sums of \(\ln{\cal T}(\tau_{\nu,q}^{\rm prop})\), so a path from \(x_{\rm start}\) to \(x_{\rm stop}<x_{\rm start}\) has
\[
{\cal A}_\nu(x_{\rm start},x_{\rm stop})
=
{\cal T}(\tau_{\nu,{\rm start}}^{\rm seg})
\exp\left[
\sum_{q={\rm stop}+1}^{{\rm start}-1}
\ln{\cal T}(\tau_{\nu,q}^{\rm prop})
\right]
{\cal T}(\tau_{\nu,{\rm stop}}^{\rm seg}) .
\]
The propagation optical depth on the reduced cooling grid is the sum of synchrotron self-absorption and local pair-production opacity,
\[
\tau_{\nu,q}^{\rm prop}
=\tau_{\nu,q}^{\rm SSA}
+
\tau_{\nu,q}^{\gamma\gamma},
\qquad
\tau_{\nu,q}^{\gamma\gamma}
=\Delta x'_q\int \sigma_{\gamma\gamma}(\nu,\nu')n_{\nu',q}\,d\nu',
\]
where the \(\gamma\gamma\) cross section is the same kernel used in the photon-absorption stage.

The full-history contribution to a target cell is therefore
\[
\Delta L_{\nu,t}^{\rm hist}
=w_s{\cal D}_{s\to t}^3
{\cal A}_\nu Q_{L,s}(\nu/{\cal D}_{s\to t}),
\qquad
\Delta n_{\nu,t}^{\rm hist}
=w_s{\cal D}_{s\to t}^2
{\cal A}_\nu Q_{n,s}(\nu/{\cal D}_{s\to t}).
\]
The production path avoids rescanning all older shells by evolving two streamed arrays, \(P_{\nu,k}^{\rm stream}\) and \(n_{\nu,k}^{\rm stream}\), from \(j-1\) to \(j\).  For target cell \(k\), the one-step light-cone interval in the previous shell is
\[
[x_{j,k},\,x_{j,k}+c(t'_j-t'_{j-1})].
\]
The old streamed field is sampled at the upper endpoint if that point lies inside the previous shell, while newly emitted photons from previous-shell cells \(a\) are added with overlap weight
\[
w_{a\to k}^{(j)}
=
\frac{
\max\!\left[0,
\min(x_{a+1/2}^{j-1},x_{j,k}+c\Delta t'_j)
-\max(x_{a-1/2}^{j-1},x_{j,k})
\right]}
{\Delta x'_{a,j-1}} .
\]
Each of these source terms is then mapped with the same \({\cal D}_{s\to t}\), log-frequency interpolation, and current-shell path attenuation.  The cooling field used by the two-dimensional electron solve is
\[
L_{\nu,k}^{\rm cool}(R_j)
=L_{\nu,k}^{\rm local}(R_{j-1})
+P_{\nu,k}^{\rm stream}(R_j),
\qquad
n_{\nu,k}^{\rm cool}(R_j)
=n_{\nu,k}^{\rm local}(R_{j-1})
+n_{\nu,k}^{\rm stream}(R_j),
\]
on the reduced cooling-frequency grid.  These history arrays enter only the local cooling calculation; observer-time projection still uses the stored synchrotron luminosity, optical depth, radius, Lorentz factor, and volume-weight arrays described below.

The \(q\)-transport equation solved by the default branch is the conservative radial equation
\[
\frac{\partial U_i}{\partial R}
+\frac{\partial}{\partial q}\!\left[A_q(q,R)U_i\right]
=
\frac{\partial}{\partial q}\!\left[
\frac{\kappa_{B,i\chi}}{\beta_f c}
\left(\frac{\partial q}{\partial s}\right)^2
\frac{\partial U_i}{\partial q}
\right]
+S_i(q,R),
\]
where
\[
A_q(q,R)=\frac{(3-k)(q_\ast-q)}{R}.
\]
Thus the advection speed vanishes at the finite active outer face \(q=q_\ast\), not at a formal \(q=1\) tail.  The injection source is applied at the shock-front cell,
\[
S_i(q,R)\Delta R=
\frac{Q_i(R,\Delta R)}{\Delta q}\,\delta_{k1},
\]
with \(Q_i\) given by the same power-law cutoff injection integral used by the one-dimensional forward solvers.  The characteristic \(q\)-advection branch solves
\[
\frac{dq}{dR}=A_q(q,R).
\]
Inside a cell the code linearly reconstructs the face speed,
\[
A_q(q)=a_k+b_kq ,
\]
so a face at \(q_f^{n+1}\) is traced back over \(\Delta R\) to
\[
q_f^n+\frac{a_k}{b_k}
=
\left(q_f^{n+1}+\frac{a_k}{b_k}\right)
e^{-b_k\Delta R},
\]
with the constant-speed limit \(q_f^n=q_f^{n+1}-a_k\Delta R\).  If the back-traced characteristic crosses a cell face, the same analytic formula is restarted in the adjacent cell until the full step is consumed.  Before this remap the shock-front source is added to the first cell,
\[
U_{i1}^{\rm src}=U_{i1}^n+\Delta R\,S_i/\Delta q .
\]
The cell profile used for remapping is the positivity-preserving PPM reconstruction from the common transport layer.  Let \(M_i(q)=\int_0^q U_i(q')\,dq'\) be its prefix integral.  Conservation then gives the remapped state
\[
U_{ik}^{\rm adv}
=\frac{M_i(q_{k+1/2}^n)-M_i(q_{k-1/2}^n)}{\Delta q}.
\]

The diffusion metric is derived from the same bridged radius law.  With
\[
x(q)=R-r(q),\qquad
\frac{\partial q}{\partial s}
=\left[-R\frac{\partial(r/R)}{\partial q}\right]^{-1},
\]
the spatial diffusion term in the shock-frame radial equation is written in \(q\) coordinates as
\[
\frac{\partial}{\partial q}
\left[
C_{i,k+1/2}
\frac{U_{i,k+1}-U_{ik}}{\Delta q}
\right],
\qquad
C_{i,k+1/2}=
\frac{\kappa_{B,i,k+1/2}}{\beta_{\rm sh}c}
\left(\frac{\partial q}{\partial s}\right)_{k+1/2}^{2}.
\]
The implicit centered diffusion step is therefore
\[
U_{ik}^{n+1}
-\frac{\Delta R}{\Delta q}
\left[
C_{i,k+1/2}\frac{U_{i,k+1}^{n+1}-U_{ik}^{n+1}}{\Delta q}
-C_{i,k-1/2}\frac{U_{ik}^{n+1}-U_{i,k-1}^{n+1}}{\Delta q}
\right]
=U_{ik}^{\rm rhs}.
\]
The default implicit \(q\) step combines advection and diffusion in one tridiagonal solve.  Its upwind advective face flux is
\[
F_{i,k+1/2}^{\rm adv}
=A_{k+1/2}^{+}U_{ik}^{n+1}
+A_{k+1/2}^{-}U_{i,k+1}^{n+1},
\qquad
A^\pm=\max/\min(A,0),
\]
and the matrix equation is
\[
U_{ik}^{n+1}
+\frac{\Delta R}{\Delta q}
\left(F_{i,k+1/2}^{\rm adv}-F_{i,k-1/2}^{\rm adv}\right)
-\frac{\Delta R}{\Delta q}
\left(F_{i,k+1/2}^{\rm diff}-F_{i,k-1/2}^{\rm diff}\right)
=U_{ik}^{n}+\Delta R\,S_i\delta_{k1}/\Delta q .
\]
The direct implicit driver uses the joint \(q\) solve before the energy solve, whereas the split finite-width driver applies the conservative PPM advection remap plus the implicit diffusion solve as half steps around the energy update.  The \texttt{charint\_2d} diagnostic path uses the same remap-plus-diffusion \(q\) operator.  In the optional \texttt{pwn\_cr\_v1} branch, setting the outer escape flag adds the last-face term \(C_{i,N_\chi+1/2}U_{i,N_\chi}^{n+1}\) to the diagonal, which is the absorbing outer-boundary form \(U_{i,N_\chi+1}=0\).  Without that flag, the outer diffusive flux is closed.

The energy step in the default branch is the integrated four-velocity finite-volume solve.  At an energy face,
\[
{\cal F}_{i+1/2,k}=
\frac{
(R_j-R_{j-1})(D_{ik}+D_{i+1,k})/2
+\ln(R_j/R_{j-1})
}
{\ln10\,(dx_g/dy)_{i+1/2}},
\]
and the conservative tridiagonal solve is the same implicit face-flux system used by the one-dimensional fullhide kernel, with \({\cal F}_{i+1/2,k}\) replacing \(\Delta R\,v_{i+1/2}\).  The \(\ln(R_j/R_{j-1})\) term is the integrated adiabatic loss \(d\ln\gamma_e/dR=1/R\).  The split log-\(\gamma\) kernel uses the same backward-sweep primitive column by column.  With \(x=\log_{10}\gamma_e\),
\[
\xi_{i+1/2,k}=D_{i+1/2,k}+\frac{1}{R\ln10},
\qquad
u_{i+1/2,k}=-\frac{\Delta R}{\Delta x}\xi_{i+1/2,k},
\]
and the implicit upper-triangular coefficients are
\[
p_{ik}=1-u_{i-1/2,k},\qquad
c_{ik}=\frac{2u_{i+1/2,k}}{p_{ik}+p_{i+1,k}},
\]
followed by the high-to-low-energy recovery
\[
U_{N_\gamma,k}^{n+1}=r_{N_\gamma,k},\qquad
U_{ik}^{n+1}=\max\left(0,r_{ik}-c_{ik}U_{i+1,k}^{n+1}\right),
\quad
r_{ik}=U_{ik}^{n}/p_{ik}.
\]
In the \texttt{charint\_2d} branch, the energy coordinate is \(x\) and each \(q\) column is updated by the same piecewise cooling characteristic map used by the one-dimensional characteristic solver.  The source term is supplied only to the shock-front column, so
\[
S_{ik}^{x}=S_i^x\delta_{k1}.
\]
When \(\texttt{index\_Y}=0\), the characteristic cooling law is the affine synchrotron-plus-adiabatic form
\[
\frac{d\gamma_e}{dR}
=-a_{\rm syn,k}\gamma_e^2-\frac{\gamma_e}{R},
\qquad
a_{\rm syn,k}=
\frac{1.35\times10^{-19}B_k'^2}{\pi\,\beta_{\rm sh}\Gamma_{\rm sh}},
\]
and otherwise the tabulated piecewise loss array \(D_{ik}\) supplies the characteristic map.  In the optional \texttt{pwn\_cr\_v1} branch, the adiabatic coefficient is local,
\[
\frac{d\log_{10}\gamma_e}{dR}\bigg|_{\rm ad}
=
\frac{1}{3\beta_f\ln10}
\left(\frac{2\beta_\chi}{r_\chi}
+\frac{\partial\beta_\chi}{\partial r}\right),
\]
which is evaluated by finite differences of the bridged \(\beta_\chi(r_\chi)\) profile.  A positive stochastic-acceleration normalization adds a zero-flux diffusion step in \(x\), half before and half after the cooling solve,
\[
\frac{\partial U_k}{\partial R}
=
\frac{\alpha_{\rm st}}{R}
\frac{\partial^2 U_k}{\partial x^2},
\]
with the implicit matrix
\[
-\lambda U_{i-1,k}^{n+1}
+(1+2\lambda)U_{ik}^{n+1}
-\lambda U_{i+1,k}^{n+1}
=U_{ik}^{n},
\qquad
\lambda=\frac{\Delta R\,\alpha_{\rm st}}{R\,\Delta x^2},
\]
and edge diagonals \(1+\lambda\), which enforce zero stochastic flux through the low- and high-energy boundaries.  That branch is a research transport option for the \(\chi\)-resolved electron path, not a general PWN or cosmic-ray propagation model.

After each radius is stored, the wrapper converts \(U_{ik}\) back to \(dN_e/d\gamma_e\) with the coordinate Jacobian and sums over \(q\) for the shell-level state.  The returned \(\chi\)-resolved projection arrays are \(r_\chi\), \(\Gamma_\chi\), \(\Delta q\), \(B'_\chi\), the unabsorbed cell synchrotron luminosity, the local seed field, and the cell optical depth.  If only the one-dimensional shell contract is requested, the shell synchrotron field is recomputed from the summed spectrum; if the direct \(\chi\)-resolved projection is requested, local luminosities and optical depths are retained so foreground absorption can be evaluated during observer projection.  SSC, hadronic transport, pair-cascade feedback, and reverse-shock coupling remain shell-level or one-dimensional contracts and are not promoted to \(q\)-local physics by this wrapper.

\section{Photon-Field Assembly and Absorption} \label{sec:photon}

The photon stage converts the electron solution into local radiation fields before observer projection.  The state passed to later stages contains the seed frequency grid, the forward synchrotron seed field, a forward SSC seed field used only when forward SSC is enabled, the hadronic target field, and separate absorption seed arrays for synchrotron and SSC photons.  In separated calculations,
\[
n_\nu^{\rm target}
=n_\nu^{\rm syn}
+\mathcal{I}_{\rm SSC}\,n_\nu^{\rm SSC},
\]
where \(\mathcal{I}_{\rm SSC}=1\) only when forward SSC is enabled for the hadronic target.  In the joint branch, \(p\gamma\), Bethe-Heitler, and \(\gamma\gamma\) photon-survival factors are applied to this target field before the next electron solve.

Forward SSC is computed from the same transported electron distribution and local seed photon density.  The implemented kernel is the Jones/Klein--Nishina form,
\[
L_\nu^{\rm SSC}
=\frac{3}{4}ch\sigma_T
\int d\gamma_e\,\frac{N_e(\gamma_e)}{\gamma_e}
\int d\nu_s\,n_{\nu_s}
\,G(q,\Gamma_\epsilon),
\]
with
\[
G(q,\Gamma_\epsilon)=
2q\ln q+(1+2q)(1-q)
+\frac{\Gamma_\epsilon^2q^2(1-q)}{2(1+\Gamma_\epsilon q)}.
\label{eq:ssc-kernel}
\]
The numerical implementation precomputes the kinematic bounds in \((\nu_s,\gamma_e)\), uses Simpson weights on the log-spaced grids, and accumulates low-seed and high-seed contributions separately so that the Thomson and Klein--Nishina parts are evaluated by the same kernel \citep{Jones1968,BlumenthalGould1970}.

Photon survival is applied as a shell-cell transfer, not as a point-screen attenuation.  The common transfer factor is
\[
\mathcal{T}(\tau)=
\begin{cases}
1, & \tau\le 10^{-4},\\
(1-e^{-\tau})/\tau, & \tau>10^{-4}.
\end{cases}
\]
The \(\gamma\gamma\) optical-depth kernel uses the pair-production cross section
\[
\sigma_{\gamma\gamma}(s)=
\frac{3\sigma_T}{16}(1-\beta_s^2)
\left[
(3-\beta_s^4)\ln\frac{1+\beta_s}{1-\beta_s}
-2\beta_s(2-\beta_s^2)
\right],
\qquad
\beta_s=(1-s^{-1})^{1/2},
\]
for \(s>1\).  The angular integral uses weights proportional to \(1-\beta\mu\), adds any extra hadronic photon-loss optical depth, and returns the absorption factor that enters the observer prefactor \citep{GouldSchreder1967,Svensson1987}.

The observer-side assembly uses a fixed order.  It first adds forward SSC if enabled, then reverse-shock synchrotron and optional reverse SSC/cross-zone IC, then hadronic luminosities after forward synchrotron self-absorption transfer, then pair-production luminosity and pair seed photons if that branch is active.  The final local-to-observer prefactor is
\[
\mathcal{P}_\nu(R)=
\frac{1+z}{4\pi d_L^2}\,
\mathcal{A}_{\rm abs}(\nu,R),
\]
and all component luminosities are multiplied by this prefactor before equal-arrival-time interpolation.

\section{Hadronic Transport and Secondary Feedback} \label{sec:hadronic}

Hadronic transport runs only when the hadronic stage is enabled and \(\epsilon_p>0\).  The current formal forward-shock hadronic path is one-dimensional, and the runtime rejects non-1D forward electron solvers for formal hadronic feedback.  The \texttt{legacy\_1d} solver transports protons and computes proton synchrotron only.  The \texttt{am3\_1d} solver with \texttt{hummer\_2010\_response} is the formal path for \(p\gamma\), neutrino, Bethe-Heitler, hadronic inverse-Compton, \(pp\), secondary-species, and pair-production branches \citep{Murase2007,Hummer2010,KelnerAharonian2008,Chodorowski1992,GouldSchreder1967,IceCube2017GRBNeutrinos,Sahu2022GRB190829AHadronic,Sahu2024GRB221009AHadronic}.

The formal species ledger is
\[
\left\{
N_p,N_n,N_{\pi^0},N_{\pi^\pm},N_{\mu^\pm},
N_\nu,Q_{e,{\rm BH}},Q_{e,pp},Q_{e,\gamma\gamma}
\right\},
\]
with photons and pairs coupled through the local target field and photon-survival factors.  The proton equation can be written in compact operator form as
\[
\frac{\partial N_p}{\partial R}
=Q_{p,R}
-\mathcal{L}_{p,{\rm syn}}
-\mathcal{L}_{p\gamma}
-\mathcal{L}_{\rm BH}
-\mathcal{L}_{pp}
+\mathcal{R}_{p\gamma},
\]
where \(\mathcal{R}_{p\gamma}\) denotes proton and neutron reinjection from the photohadronic response.  This equation is compressed only in its notation: each loss/source term corresponds to a separate implemented process operator, and inactive switches remove the corresponding operator before the observer stage is assembled.

The forward-shock shell energy assigned to nonthermal protons is
\[
E_{p,{\rm inj}}(R_i)=
\epsilon_p[\Gamma_i-1]\,\Delta V_i\,n(R_i)m_pc^2,
\qquad
\Delta V_i=\frac{4\pi}{3}\left(R_i^3-R_{i-1}^3\right).
\]
The injected proton content is normalized by the energy moment
\[
Q_p(\gamma_p)=
E_{p,{\rm inj}}
\frac{\gamma_p^{-p_p}}
{\int_{\gamma_{p,\min}}^{\gamma_{p,\max}}
(\gamma_p-1)m_pc^2\gamma_p^{-p_p}\,d\gamma_p},
\]
with \(\gamma_{p,\min}=\max(\gamma_{p,1},\Gamma)\).  The upper proton grid is set from acceleration constraints using
\[
t_{\rm acc}=\eta_{\rm acc}\frac{\gamma m c}{|q|B'},
\qquad
t_{\rm syn}=\frac{6\pi m^3c}
{\sigma_T m_e^2B'^2\gamma},
\]
and the dynamical time \(t_{\rm dyn}=R/(\Gamma c)\).

The proton transport equation is advanced on a log-\(\gamma_p\) grid,
\[
\frac{\partial N_p}{\partial t'}
+\frac{\partial}{\partial\gamma_p}
\left(\dot{\gamma}_pN_p\right)
=Q_p+Q_{p,{\rm reinj}},
\]
with an upwind flux update.  The baseline losses are
\[
\dot{\gamma}_{p,{\rm ad}}=-\frac{\gamma_p}{t_{\rm dyn}},
\qquad
\dot{\gamma}_{p,{\rm syn}}=
-\frac{\sigma_T B'^2}{6\pi m_ec}
\left(\frac{m_e}{m_p}\right)^3\gamma_p^2.
\]
When enabled, Bethe-Heitler, \(pp\), and \(p\gamma\) loss rates are added before the final proton update, and \(p\gamma\) reinjection is included as \(Q_{p,{\rm reinj}}\).  The formal \(p\gamma\) operator is evaluated twice in each shell: first on the unattenuated target photon density to compute the photon-loss depth and the shell survival factor, and then on the survived photon density used for the actual interaction rates.  The survival factor is the same shell-cell form,
\[
S_\gamma(\nu,R)=\frac{1-e^{-\tau_\gamma(\nu,R)}}{\tau_\gamma(\nu,R)},
\]
with the continuous small-\(\tau_\gamma\) limit used internally.

Secondary species are transported only in the formal one-dimensional path.  The \(p\gamma\) response generates neutral-pion gamma rays, charged pions, muons, neutrinos, neutron reinjection, and proton reinjection.  The \(pp\) branch uses the implemented delta-approximation source with inelasticity \(0.5\), pion energy fraction \(0.17\), and neutral-pion fraction \(1/3\).  Bethe-Heitler and \(pp\) pairs are accumulated as a secondary electron source.  In the separated branch, Bethe-Heitler secondary electrons can be merged into the forward electron distribution and the separate Bethe-Heitler luminosity is then suppressed to avoid double counting.

The joint branch iterates the local electron, photon, and hadronic state before observer projection:
\[
N_e^{(k)}
\rightarrow n_\gamma^{(k)}
\rightarrow
\left\{Q_{e,{\rm sec}}^{(k)},\tau_{\gamma\gamma}^{(k)}\right\}
\rightarrow N_e^{(k+1)}.
\]
The secondary source enters \(Q_{e,{\rm sec},R}\), the updated electron solution rebuilds the photon field, and the hadronic operators are evaluated again on the survived target field.  Pair-cascade iterations greater than one select the shell-sequence time-dependent \(\gamma\gamma\) pair/synch cascade path; the single-shell branch remains a diagnostic mode.  This branch does not implement an IC-mediated electromagnetic cascade.  Neutrino arrays are outputs of the charged-pion and muon decay chain, and the manuscript does not interpret them as a detection prediction without a separate exposure calculation.

\section{Reverse-Shock and Secondary Reverse-Shock Stages} \label{sec:reverse-shock}

The reverse-shock stage is enabled only when a shell duration is supplied.  It uses
\[
\Delta_0=c\Delta t,\qquad
M_{{\rm ej},b}=\frac{E_{\rm iso}}{(1+\sigma)\eta_0c^2},
\qquad
\Delta(R)=\max\left(\Delta_0,\frac{R}{\eta_0^2}\right),
\]
and an upstream ejecta density
\[
n_4(R)=\frac{M_{{\rm ej},b}}{4\pi m_pR^2\eta_0\Delta(R)}.
\]
Here \(E_{\rm iso}\) is the total ejecta energy.  A finite upstream magnetization therefore reduces the transported baryonic mass by the matter fraction \((1+\sigma)^{-1}\), while the dynamical inertia of the unshocked ejecta uses the corresponding matter-plus-magnetic factor \((1+\sigma)\).  The code keeps these two roles separate: \(n_4\) is the baryon target density for shock heating and particle injection, whereas \(n_{4,{\rm in}}=(1+\sigma)n_4\) enters the inertia carried by the waiting shell.
The relative Lorentz factor used for reverse-shock electron injection is the shock-front value
\[
\gamma_{34}=
\frac{\Gamma_2^2+\eta_0^2-1}
{\eta_0\Gamma_2+\sqrt{\Gamma_2^2-1}\sqrt{\eta_0^2-1}},
\]
not a postprocessed observer-time estimate.  For magnetized ejecta the outer driver keeps the reverse RHS
in a waiting phase until the local pressure and fast-mode checks are both satisfied,
\[
\sigma_{\rm cr}=
\frac{2(4\Gamma_2+3)(\Gamma_2-1)n_1}{3n_4}\ge\sigma,
\qquad
u_{4s}^2>\sigma .
\]
Here \(u_{4s}\) is the upstream four-speed in the reverse-shock frame from the same jump relation used below.
Before these checks pass, \(dM_3=0\), no reverse-shock heating is applied,
\(B_{3,{\rm ord}}=0\), and the decelerating forward shell carries the waiting ejecta inertia
\[
M_{\rm wait}=
M_{{\rm ej},b}(1+\sigma)\frac{\eta_0}{\eta_0-1}f_{\rm fast},
\]
\[
\beta_{\rm f}=\left(\frac{\sigma}{1+\sigma}\right)^{1/2},
\qquad
f_{\rm fast}=
\min\left[
1,\,
\frac{R\beta_{\rm f}}
{\eta_0^2(1-\beta_4\beta_{\rm f})\beta_4\Delta(R)}
\right].
\]
The waiting-phase Lorentz equation is therefore
\[
\frac{d\Gamma_2}{dR}
=-\frac{u_2^2\,dM_2/dR}
{M_{\rm wait}+[\epsilon_2+2(1-\epsilon_2)\Gamma_2]M_2}.
\]
The crossing from waiting to active reverse shock is bracketed within the current radial step rather than being assigned to the next stored output radius.  The reverse-shock framework follows the standard early-afterglow treatment, including wind reverse-shock diagnostics, and uses the same magnetized jump-condition variables as the \vegas\ comparison calculation without treating \vegas\ as a light-curve target \citep{SariPiran1999,Kobayashi2000,ZhangKobayashi2005,PeerWijers2006,Giannios2008,Wang2025VegasAfterglow}.

The active magnetized jump is solved as a finite-strength local MHD shock for a cold upstream shell with a transverse ordered field in a one-dimensional shock frame.  Let \(g=\gamma_{34}\), \(\hat{\gamma}=4/3+1/(3g)\), \(h_1=\hat{\gamma}-1\), and \(h_2=\hat{\gamma}-2\).  For \(\sigma>10^{-6}\) the code solves a cubic for the downstream four-speed squared \(y=u_d^2\),
\[
A y^3+B y^2+C y+D=0,
\]
with
\[
A=-\hat{\gamma}h_2(g-1)+2,
\]
\[
B=-(g+1)\left[-h_2(\hat{\gamma}g^2+1)
+\hat{\gamma}h_1g\right]\sigma
-(g-1)\left[-\hat{\gamma}h_2(g^2-2)+2g+3\right],
\]
\[
C=(g+1)\left[\hat{\gamma}\left(1-\frac{\hat{\gamma}}{4}\right)
(g^2-1)+1\right]\sigma^2
+(g^2-1)\left[2g+h_2(\hat{\gamma}g-1)\right]\sigma
+(g+1)(g-1)^2h_1^2,
\]
\[
D=-\frac{1}{4}(g-1)(g+1)^2h_2^2\sigma^2 .
\]
The code reduces the polynomial to its depressed cubic before selecting the
physical root.  With
\[
b=\frac{B}{A},\qquad c=\frac{C}{A},\qquad d=\frac{D}{A},
\]
\[
p_c=c-\frac{b^2}{3},\qquad
q_c=\frac{2b^3}{27}-\frac{bc}{3}+d,\qquad
a_c=\left(-\frac{p_c}{3}\right)^{1/2},
\]
the selected branch is
\[
y=2a_c\cos\left[
\frac{\cos^{-1}\!\left(3q_c/(2p_ca_c)\right)-2\pi}{3}
\right]-\frac{b}{3},
\qquad u_d=\sqrt{y}.
\]
This is the finite, positive downstream four-speed root selected by the implemented shock state.  The other real branches are not used.  The upstream four-speed in the downstream frame is
\[
u_u=\sqrt{(1+u_d^2)(g^2-1)}+u_dg,
\]
and the compression ratio used by the active RHS is \(r_\sigma=u_u/u_d\).
In the \(\sigma\le10^{-6}\) branch the module uses the finite-strength hydrodynamic downstream-speed expression
\[
y_{\rm h}=
\frac{(g-1)(\hat{\gamma}-1)^2}
{-\hat{\gamma}(\hat{\gamma}-2)(g-1)+2},
\]
which gives \(u_u/u_d=4g\) for the same \(\hat{\gamma}\).  The public compression helper therefore returns \(r_0=4g\) in this limit.  The thermal helper returns \(g-1\) only for exactly unmagnetized ejecta; for \(0<\sigma\le10^{-6}\) it evaluates the finite-\(\sigma\) enthalpy expression below with \(y_{\rm h}\), approaching \(g-1\) continuously.
The manuscript therefore does not use the ultra-relativistic \(4g+3\) approximation as the active dynamical jump condition.  This MHD jump is used only by the primary ejecta reverse shock; the density-jump secondary branches described below remain hydrodynamic diagnostics and do not carry ordered-field compression or magnetic enthalpy feedback.

The ordered upstream field is
\[
B_4=\left(4\pi c^2\sigma\rho_4\right)^{1/2},
\qquad \rho_4=m_pn_4,
\]
and the downstream field stored by the reverse state is
\[
B_3=\left(8\pi\epsilon_{B,r}\frac{U_3}{V_3}+B_{\rm ord}^2\right)^{1/2}.
\]
Before crossing, \(B_{\rm ord}=r_\sigma B_4\).  After crossing, the ordered component is advected as
\[
B_{\rm ord}(R)=B_{{\rm ord},\times}
\frac{V_{3,\times}}{V_3(R)}
\frac{R}{R_\times}.
\]
The ordered component also enters the dynamics.  The reverse solver adds the magnetic enthalpy inertia of region~3,
\[
M_{B,3}=
\frac{E_{B,{\rm ord}}+p_{B,{\rm ord}}V_3}{c^2}
+\frac{p_{B,{\rm ord}}V_3}{\Gamma_2^2c^2},
\qquad
E_{B,{\rm ord}}=p_{B,{\rm ord}}V_3,\quad
p_{B,{\rm ord}}=\frac{B_{\rm ord}^2}{8\pi},
\]
to the denominator of the \(\Gamma_2\) update.  The stored reverse field is therefore not only an emissivity input: the ordered component feeds back into the shell inertia, while the turbulent component sets the local synchrotron cooling and emissivity.
The same jump solution supplies the thermal specific internal energy.  For finite \(\sigma\),
\[
\frac{e_{{\rm th},3}}{c^2}
=\frac{h_d-1}{\hat{\gamma}},
\qquad
h_d=(1+\sigma)\frac{\gamma_u}{\gamma_d}
-r_\sigma\sigma,
\]
where \(\gamma_u=(1+u_u^2)^{1/2}\) and \(\gamma_d=(1+u_d^2)^{1/2}\).  This quantity, not \(\gamma_{34}-1\), is the heat deposited per shocked baryon when the magnetized branch is active.
During the active pre-crossing stage the \(\Gamma_2\) denominator also carries the region-3 thermal-response factor used by the code,
\[
\mathcal{R}_{\rm th,3}=
\begin{cases}
1, & \sigma=0,\\
(e_{{\rm th},3}/c^2)/(\gamma_{34}-1), & \sigma>0,
\end{cases}
\]
so the magnetized jump changes both the explicit ordered-field inertia and the heat-inertia coupling of the shocked ejecta.

The reverse dynamics evolve \((\Gamma_2,R,M_2,M_3,U_3,V_3)\), with
\[
\frac{dM_2}{dR}=4\pi R^2m_pn_1 .
\]
The public reverse-dynamics entry stores this state as
\[
Y_{\rm RS}=\left(\Gamma_2,R,M_2,\frac{M_3}{M_{{\rm ej},b}},
\frac{U_3}{M_{{\rm ej},b}c^2},\frac{V_3}{V_{3,0}},\ldots\right),
\]
where \(V_{3,0}=M_{{\rm ej},b}/(n_{3,0}m_p)\) is only a volume normalization.
The output grid is a source-frame on-axis time grid,
\[
T_i=T_{\rm base}+10^{\ell_0+(\ell_{\max}-\ell_0)(i-1)/(N_R-1)},
\qquad
T_{\rm obs,i}=(1+z)T_i,
\]
where \(\ell_{\max}\) is the requested \(\log_{10}\) observer-time solve horizon stored in the boundary vector, and
\[
T_{\rm base}=\frac{R_0(\beta_0^{-1}-1)}{c},
\qquad
\ell_0=\min\left[\log_{10}T_{\rm base}-2,\,
\log_{10}\left(\frac{0.1R_{\rm dec}}{2\eta_0^2c}\right)\right].
\]
Before shell crossing,
\[
\frac{dM_3}{dT}=
4\pi R^2m_p(\beta_4-\beta_{\rm rs})\eta_0 n_4
\frac{dR}{dT},
\]
where \(dR/dT=\beta_2c/(1-\beta_2)\).  The reverse-shock velocity is computed from
\[
\beta_{\rm rs}=\beta_4-\Delta\beta_{\rm rs},
\]
\[
\Delta\beta_{\rm rs}
=
\frac{r_\sigma(\eta_0^2-\Gamma_2^2)}
{\eta_0(\Gamma_2u_4+\eta_0u_2)
(\Gamma_2r_\sigma-\eta_0)},
\qquad
u_2=\sqrt{\Gamma_2^2-1},\quad
u_4=\sqrt{\eta_0^2-1}.
\]
In the active pre-crossing branch the Lorentz-factor RHS is
\[
\frac{d\Gamma_2}{dR}
=-\frac{4\pi R^2m_p\left[
(\Gamma_2^2-1)n_1+(\Gamma_2\gamma_{34}-\eta_0)
\Delta\beta_{\rm rs}\eta_0 n_{4,{\rm in}}\right]}
{\mathcal I_{\rm pre}},
\qquad
\Delta\beta_{\rm rs}\equiv\beta_4-\beta_{\rm rs},
\]
where \(n_{4,{\rm in}}=(1+\sigma)n_4\), \(\epsilon_{{\rm th},3}\equiv e_{{\rm th},3}/c^2\), and
\[
\begin{split}
\mathcal I_{\rm pre}={}&
[\epsilon_2+2(1-\epsilon_2)\Gamma_2]M_2
+M_3+M_{B,3}+M_{{\rm sec,eff}} \\
& +(1-\epsilon_3)\epsilon_{{\rm th},3}M_3
+(1-\epsilon_3)\Gamma_2\mathcal R_{{\rm th},3}M_3\mathcal A_{34}.
\end{split}
\]
The last factor is the implemented derivative of the relative Lorentz factor,
\[
\mathcal A_{34}=
\eta_0(1-\beta_4\beta_2)
-\frac{\eta_0\beta_4}{\Gamma_2^2\beta_2}.
\]
The reverse radiative fraction in this inertia term is computed with the same cooling diagnostic as the forward dynamics,
\[
\gamma_{c,3}=\frac{6\pi m_ec}{\sigma_T B_3^2\Gamma_2T},
\qquad
\gamma_{m,3}=1+
\frac{\epsilon_{e,r}}{f_{e,r}}
\frac{p_r-2}{p_r-1}
\frac{m_p}{m_e}\epsilon_{{\rm th},3},
\]
\[
\epsilon_3=\epsilon_{e,r}\min\left[
1,\left(\frac{\gamma_{m,3}}{\gamma_{c,3}}\right)^{p_r-2}
\right].
\]
The region-3 thermal state is advanced as
\[
dU_3=\frac{e_{{\rm th},3}}{c^2}c^2\,dM_3
-(\hat{\gamma}_{{\rm ad},3}-1)U_3\frac{dV_{3,{\rm exp}}}{V_3},
\qquad
\hat{\gamma}_{{\rm ad},3}=
\frac{4\gamma_{{\rm th},3}+1}{3\gamma_{{\rm th},3}},
\quad
\gamma_{{\rm th},3}=1+\frac{e_{{\rm th},3}}{c^2},
\]
\[
dV_3=\frac{dM_3}{r_\sigma n_4m_p}
+V_3\left(\frac{3\,dR}{R}-\frac{d\Gamma_2}{\Gamma_2}\right).
\]
After crossing, \(dM_3=0\), the shock-heating term is removed, and the stored \(U_3/V_3\) thermal state controls the post-crossing electron cooling.  The post-crossing bulk update removes the active reverse-shock source and uses
\[
\frac{d\Gamma_2}{dR}
=-\frac{u_2^2\,dM_2/dR}
{[\epsilon_2+2(1-\epsilon_2)\Gamma_2]M_2+M_3+M_{B,3}+M_{{\rm sec,eff}}}.
\]
Before crossing, the integrator changes the independent variable to
\(q=M_3/M_{{\rm ej},b}\).  If the RHS gives \(D=dY/dT\), the RK stages use
\[
\frac{dY}{dq}=\frac{D}{D_4},
\qquad
\frac{dT}{dq}=\frac{1}{D_4},
\qquad
D_4=\frac{d(M_3/M_{{\rm ej},b})}{dT}.
\]
The crossing event is therefore the fixed endpoint \(q=1\), not an interpolated afterthought.
For log-time stages the code evolves \(s=\ln(T/T_0)\), so each smooth-branch RHS is multiplied by \(T\):
\[
\frac{dY}{ds}=T\frac{dY}{dT}.
\]
The event-split RHS is controlled by a small state register rather than by a new dynamical variable:
\[
\begin{gathered}
\phi\in\{-1,0,1,2\}
=\{{\rm waiting},{\rm default},{\rm pre},{\rm post}\},\\
W=(\phi=-1),\qquad
P=(\phi=1)\ {\rm or}\ [\phi=0\ {\rm and}\ M_3<M_{{\rm ej},b}],\\
\mathbf S_{\rm RS}=
(B_{3,{\rm cur}},T_\times,R_\times,e_{3,\times},\Gamma_{2,\times},
U_{3,\times},V_{3,\times},M_{3,\times},\gamma_{m,\times},
B_{{\rm ord},\times}) .
\end{gathered}
\]
Here \(W\) selects the waiting equations and \(P\) selects the active pre-crossing source terms.  The default \(\phi=0\) is reset after each forced RK stage; it is not an additional physical branch.  The first slot carries the instantaneous reverse magnetic field returned by the RHS.  The crossing slots start with \(T_\times=-1\); the first post-crossing RHS evaluation writes
\[
(T_\times,R_\times,e_{3,\times},\Gamma_{2,\times},
U_{3,\times},V_{3,\times},M_{3,\times},\gamma_{m,\times},B_{{\rm ord},\times})
=
\left(T,R,\frac{U_3}{V_3},\Gamma_2,U_3,V_3,M_3,\gamma_{m,3},B_{\rm ord}\right),
\]
and later post-crossing steps read, but do not rewrite, this event state.
If a pre-crossing log-time stage reaches \(q=1\), the step is bisected to the event, the crossing state
\[
(T_\times,R_\times,U_{3,\times},V_{3,\times},
M_{3,\times},\gamma_{m,\times},B_{{\rm ord},\times})
\]
is written once by a post-crossing RHS evaluation, and the remaining part of the step is advanced with the post-crossing RHS.
Waiting-to-shock activation is handled in the same event style: a trial waiting step is first evaluated at the target \(T\), and if the pressure/fast-mode conditions turn on inside the interval, the activation time is bisected before the active reverse-shock equations are used.
Smooth-step refinement compares two successive RK resolutions through
\[
P=\max_a\frac{2|a_N-a_{2N}|}{a_N+a_{2N}},
\]
with \(a\in\{\Gamma_2,R,M_2\}\) for log-time steps and \(a\in\{\Gamma_2,R,M_2,T\}\) for the \(q\)-step.
Event points are excluded from a formal smooth-branch order claim because the physics branch changes there.
Reverse-shock electrons are then transported through the same one-dimensional log-\(\gamma_e\) transport interface used by the forward solver, but their injection rate is tied to the newly shocked ejecta mass,
\[
\frac{dN_{e,r}}{dR}=f_{e,r}\frac{1}{m_p}\frac{dM_3}{dR},
\qquad
\gamma_{m,r}=1+
\frac{\epsilon_{e,r}}{f_{e,r}}
\frac{p_r-2}{p_r-1}
\frac{m_p}{m_e}
\frac{e_{{\rm th},3}}{c^2}.
\]
The actual reverse source inserted into the selected one-dimensional electron solver is kinetic rather than an ultra-relativistic \(\gamma^{-p}\) approximation:
\[
Q_{x,r}\propto
\gamma_e\ln10\,(\gamma_e-1)^{-p_r}
\exp\left(-\frac{\gamma_e}{\gamma_{\max,r}}\right),
\]
with the normalization fixed by \(dN_{e,r}/dR\).  Reverse electron transport may use either \texttt{fullhide\_1d} or \texttt{dg\_1d}; both paths share the same shell source and the same post-crossing adiabatic rate from the stored \(V_3(R)\).  The reverse synchrotron luminosity is computed with the same selected synchrotron kernel as the forward shock.  Optional reverse SSC and cross-zone IC are added only in the observer assembly; reverse hadronic full-chain flags reuse the formal one-dimensional hadronic kernels with the reverse magnetic field, reverse seed photons, reverse shell energy, and reverse baryon target density.

The implementation in \texttt{electron\_reverse\_kernel} uses this physical source in a fixed radius-output sweep.  For the interval \([R_{i-1},R_i]\), the local state entering the electron solve is reconstructed at the shell midpoint,
\[
\bar{\Gamma}_{2,i}=\frac{\Gamma_{2,i}+\Gamma_{2,i-1}}{2},\qquad
\bar B_{3,i}=\frac{B_{3,i}+B_{3,i-1}}{2},
\]
and the relative Lorentz factor is evaluated from the stored ejecta Lorentz factor \(\eta_0\),
\[
\gamma_{34,i}=
\frac{\bar\Gamma_{2,i}^2+\eta_0^2-1}
{\eta_0\bar\Gamma_{2,i}+u_{2,i}u_4},
\qquad
u_{2,i}=(\bar\Gamma_{2,i}^2-1)^{1/2},
\qquad
u_4=(\eta_0^2-1)^{1/2}.
\]
The instantaneous injection break and synchrotron-limited cutoff are therefore
\[
\gamma_{m,r,i}=
1+\frac{\epsilon_{e,r}}{f_{e,r}}
\frac{p_r-2}{p_r-1}
\frac{m_p}{m_e}(\gamma_{34,i}-1),
\qquad
\gamma_{\max,r,i}=
\frac{3m_ec^2}{(8e^3\bar B_{3,i})^{1/2}},
\]
with the code using the finite \(p_r=2.05\) coefficient \(0.05/1.05\) for the near-\(p=2\) branch.  If crossing occurs inside the interval, only the pre-crossing part receives fresh electrons:
\[
\Delta R_{\rm inj}=\min(R_i,R_\times)-R_{i-1},\qquad
\dot N_{{\rm inj},R,i}
=f_{e,r}\frac{M_{3,{\rm hi}}-M_{3,i-1}}
{m_p\Delta R_{\rm inj}},
\]
where \(M_{3,{\rm hi}}=M_{3,\times}\) when \(R_i>R_\times\) and \(M_{3,i}\) otherwise.  Intervals entirely after crossing set \(\dot N_{{\rm inj},R}=0\).

The reverse cooling coefficient sent to the one-dimensional transport solver is also explicit.  The synchrotron part is
\[
a_{\rm syn}(R)=
\frac{\sigma_T B_3^2}{6\pi m_ec^2\,\beta_2\Gamma_2},
\qquad
\left.\frac{d\gamma}{dR}\right|_{\rm syn}
=-a_{\rm syn}\gamma^2 .
\]
For \(\texttt{index\_Y}=0\), this is the only radiative term.  For \(\texttt{index\_Y}=1\), the numeric IC/KN auxiliary coefficient from the local synchrotron seed field adds
\[
\left.\frac{d\gamma_i}{dR}\right|_{\rm rad}
=-\left[
a_{\rm syn}
+
\frac{A_{{\rm IC},i}}{\beta_2\Gamma_2c}
\right]\gamma_i^2 .
\]
For \(\texttt{index\_Y}=2\), the Nakar-style Compton factor is
\[
Y_i=
\frac{A_{{\rm Nakar},i}}
{4\pi R^2c\,4\Gamma_2^2n_4m_pc^2},
\qquad
n_4=\frac{M_{\rm ej,b}}
{4\pi m_pR^2\eta_0\Delta},
\qquad
\Delta=\max(\Delta_0,R/\eta_0^2),
\]
and the transported loss is \(-a_{\rm syn}(1+Y_i)\gamma_i^2\), while the local cutoff is reduced as
\[
\gamma_{\max,r}\leftarrow
\gamma_{\max,r}(1+Y_{\max})^{-1/2}.
\]
The adiabatic coefficient is \(a_{\rm ad}=1/R\) before crossing and
\[
a_{\rm ad}=\frac{1}{3}\frac{d\ln V_3}{dR}
\simeq
\frac{\ln(V_{3,i}/V_{3,i-1})}{3(R_i-R_{i-1})}
\]
after crossing, with \(V_{3,\times}\) used when the current output interval contains the crossing point.  In the conservative coordinate \(y\), the fullhide branch advances
\[
\frac{\partial N_y}{\partial R}
+
\frac{\partial}{\partial y}
\left[
-\frac{D_{\rm rad}(\gamma)+a_{\rm ad}}
{\ln10\,dx_g/dy}N_y
\right]
=Q_y ,
\]
where \(D_{\rm rad}\) is defined by \(-d\gamma/dR|_{\rm rad}=D_{\rm rad}\gamma\).  This is the same face-flux equation as the forward shell solver with the reverse source \(Q_y\).  The radial substep size is chosen from the largest local loss rate.  For the first reverse shock in the fullhide branch,
\[
\Delta R_{\rm cand}
=\frac{0.7}
{a_{\rm syn}\gamma_{\max}+1.333/(R_i+R_{i-1})},
\]
while the secondary-reservoir and reacceleration branches use
\[
\Delta R_{\rm cand}
=\frac{0.7}{a_{\rm syn}\gamma_{\max}+1/R_{i-1}}.
\]
The resulting substep count is
\[
N_{\rm sub}=
\max\!\left[100,
\min\!\left(1000,
\left\lfloor\frac{R_i-R_{i-1}}{\Delta R_{\rm cand}}\right\rfloor
\right)\right],
\]
for the fullhide branch, while the DG branch uses ten substeps and the DG transport formulas given above.

After crossing, the kernel removes the source and transports the existing spectrum by composing characteristic maps rather than reinjecting a new distribution.  With \(u=1/\gamma\) and synchrotron-only cooling, the characteristic equation is affine,
\[
\frac{du}{dR}=a_{\rm syn}+a_{\rm ad}u .
\]
The back-traced edge for one substep is
\[
u_{\rm prev}=
\begin{cases}
u_{\rm now}-a_{\rm syn}\Delta R, & a_{\rm ad}=0,\\
\left(u_{\rm now}+a_{\rm syn}/a_{\rm ad}\right)
\exp(-a_{\rm ad}\Delta R)-a_{\rm syn}/a_{\rm ad}, & a_{\rm ad}\ne0,
\end{cases}
\]
and the corresponding \(x_g=-\log_{10}u\) edges are composed with the stored crossing map.  When IC/KN cooling is active, the code builds a piecewise-affine form \(du/dR=a_k+b_ku\) on each energy cell and applies the same back-tracing/remap operation cell by cell.  The final diagnostic \(dN_e/d\gamma_e\) is obtained from the remapped log-energy content by the same exponential cell reconstruction used in the forward characteristic path.

The secondary-reservoir electron path, \texttt{multiple\_evolve}, repeats the same synchrotron cooling and volume-loss transport for each density-jump reservoir.  Its source is
\[
\dot N_{{\rm sec},j,R}
=f_{e,r}\frac{M_{{\rm sec},j,i}-M_{{\rm sec},j,i-1}}
{m_p(R_i-R_{i-1})},
\qquad
a_{{\rm ad},j}=
\frac{\ln(V_{{\rm sec},j,i}/V_{{\rm sec},j,i-1})}
{3(R_i-R_{i-1})},
\]
with \(a_{{\rm ad},j}=0\) only when the branch volume is not yet positive.  \texttt{multiple\_synch} then evaluates the same synchrotron and SSA kernels as the forward shock for each stored secondary spectrum and reports the observer-frame absorption break as
\[
\nu_{a,{\rm obs}}=
\frac{\nu_a'}
{\Gamma_2(1-\beta_2)(1+z)} .
\]
The branch-summed secondary luminosity is a direct sum over independently evolved reservoirs,
\[
L_{\nu,{\rm sec}}=\sum_jL_{\nu,j}.
\]

The optional reacceleration diagnostic, \texttt{branch\_reaccel}, transfers already shocked electrons from a parent reservoir into a new dissipative branch before adding any fresh mass source.  If branch \(j\) has parent \(p(j)\), the transferred spectrum is
\[
N_{\log}^{\rm seed}(\gamma)
=f_{\rm tr}N_{\log,p}(\gamma),
\qquad
f_{\rm tr}=
\frac{\min[\Delta M_j,M_{p,{\rm avail}}]}
{M_{p,{\rm avail}}}.
\]
Compression and relative motion shift this seed spectrum in log energy by
\[
b_j=\Gamma_{43,j}\,\mathcal{C}_j^{1/3},
\qquad
N_{\log}^{\rm boost}(\gamma)
=N_{\log}^{\rm seed}(\gamma/b_j),
\]
where \(\mathcal{C}_j\) is applied only when the stored compression factor exceeds unity.  The diffusive-shock-acceleration remapping is the standard integral transform
\[
\frac{dN_{\rm reacc}}{d\gamma}
=(p_r-1)\gamma^{-p_r}
\int_1^\gamma
\frac{dN_{\rm boost}}{d\gamma'}\gamma'^{p_r-1}\,d\gamma',
\qquad p_r>2 .
\]
The branch energy diagnostics are computed from the same log-energy content,
\[
E_{\rm seed/reacc}=
\int(\gamma-1)m_ec^2\,N_{\log}^{\rm seed/reacc}\,
d\log_{10}\gamma .
\]
The remaining untransferred dissipative mass is inserted through the fresh kinetic source above, so the diagnostic separates reprocessed parent electrons from newly accelerated electrons in the same branch spectrum.

Secondary reverse shocks are tied to density-jump events rather than to an independent free component.  For a Gaussian jump \(j\), the branch weight is nonzero only on the rising side,
\[
R_j-4w_jR_j\le R<R_j,
\qquad
n_{\rm exc,j}(R)=n_{\rm base}(R)(f_j-1)
\exp\left[-\frac{(R-R_j)^2}{2(w_jR_j)^2}\right].
\]
All active secondary branches contribute their hot-gas enthalpy to the same bulk inertia,
\[
p_{\rm sec}=\frac{U_{\rm sec}}{3V_{\rm sec}},
\qquad
M_{{\rm sec,eff}}=
\frac{M_{\rm sec,b}c^2+U_{\rm sec}+p_{\rm sec}V_{\rm sec}}{c^2}
+\frac{p_{\rm sec}V_{\rm sec}}{\Gamma_2^2c^2}.
\]
The branch RHS uses the actual total density \(n_1=n_{\rm base}+\sum_k n_{\rm exc,k}\)
and the selected excess density \(n_{\rm exc,j}\), so the first secondary upstream is
\[
n_{\rm pre}=n_1-n_{\rm exc,j},
\qquad
n_4=4\Gamma_2 n_{\rm pre},
\]
\[
e_4=4\Gamma_2(\Gamma_2-1)n_{\rm pre}m_pc^2,
\qquad
p_4=\frac{e_4}{3}.
\]
If a previous secondary branch has finite mass, energy, and volume, that parent branch instead supplies
\[
n_4=\frac{M_{\rm parent}}{m_pV_{\rm parent}},
\qquad
e_4=\frac{U_{\rm parent}}{V_{\rm parent}},
\qquad
p_4=\frac{e_4}{3}.
\]
The secondary contact state is solved from a scalar pressure-balance root.
For a trial contact Lorentz factor \(\Gamma_{\rm c}\), the external shocked pressure is
\[
p_2(\Gamma_{\rm c})=
\frac{4}{3}(\Gamma_{\rm c}^2-1)n_1m_pc^2,
\]
while the hot upstream branch is closed with
\[
p_3(\Gamma_{\rm c})=
p_4+\frac{4}{3}(\Gamma_{43}^2-1)(e_4+p_4),
\qquad
\Gamma_{43}=\Gamma_{\rm c}\Gamma_4(1-\beta_{\rm c}\beta_4).
\]
The code bisects \(p_2-p_3=0\) on \(1<\Gamma_{\rm c}<\Gamma_4\).
The reverse-shock speed is then found in the shock frame,
\[
\beta_{4s}=\frac{\beta_4-\beta_s}{1-\beta_4\beta_s},
\qquad
\beta_{3s}=\frac{\beta_{\rm c}-\beta_s}{1-\beta_{\rm c}\beta_s},
\qquad
u_{is}=\Gamma_{is}|\beta_{is}|,
\]
and the compression follows from baryon-flux continuity,
\[
\chi\equiv\frac{n_3}{n_4}=\frac{u_{4s}}{u_{3s}} .
\]
Only the compressive interval \(\chi>1\) is searched.
The accepted root satisfies the shock-frame momentum flux equation
\[
w_4u_{4s}^2+p_4=w_3u_{3s}^2+p_3,
\]
\[
w_4=n_4m_pc^2+e_4+p_4,\qquad
e_3=3p_3,\qquad
w_3=\chi n_4m_pc^2+e_3+p_3 .
\]
This is therefore a relativistically hot-gas closure for the secondary diagnostic branch,
not a general finite-temperature Taub solve: after \(p_3\) is fixed by contact balance,
only the shock speed and compression are solved from mass and momentum flux.
If no compressive momentum root exists, the branch is left inactive.  Otherwise it deposits energy only when
\[
u_{\rm diss}=e_3-e_4\chi^{4/3}>0,
\]
which subtracts the adiabatically compressed upstream internal energy from the newly shocked hot-gas state.
Its mass, energy, and volume are then accumulated as
\[
dM_{\rm sec}=4\pi R^2n_4m_p\Gamma_2
\frac{\beta_2-\beta_{\rm rs}}{\beta_c}\,dR,
\]
\[
dU_{\rm sec}=u_{\rm diss}\,dV_{\rm sec}
-\frac{1}{3}U_{\rm sec}\frac{dV_{{\rm sec},{\rm exp}}}{V_{\rm sec}},
\qquad
dV_{\rm sec}=\frac{dM_{\rm sec}}{n_3m_p}
+V_{\rm sec}\left(\frac{3\,dR}{R}-\frac{d\Gamma_2}{\Gamma_2}\right).
\]
The event windows returned for these branches are diagnostic roots of the same source function
\[
S_j(R)=e_{3,j}-e_{4,j}\chi_j^{4/3}.
\]
Between two stored first-RS states, the scanner subdivides the overlap with the active rising side
\([R_j-4w_jR_j,R_j)\) into intervals no wider than \(w_jR_j/16\), linearly interpolates
\((Y,\Gamma_2,T_{\rm obs})\) within the bracket, and bisects sign changes of \(S_j\).
Thus \(S_j>0\) marks an active secondary reverse-shock window, while a branch that remains open to the last sampled radius is closed at the last known state rather than extrapolated.
The public branch arrays are the dimensional forms
\[
M_{{\rm sec},j}=Y_{m,j}M_{{\rm ej},b},\qquad
U_{{\rm sec},j}=Y_{u,j}M_{{\rm ej},b}c^2,\qquad
V_{{\rm sec},j}=Y_{v,j}V_{3,0}.
\]
Newly dissipated energy, not accumulated mass, weights the combined secondary diagnostics:
\[
\Delta E_{{\rm diss},j,i}=E_{{\rm diss},j,i}-E_{{\rm diss},j,i-1},
\qquad
\langle Q\rangle_i=
\frac{\sum_j \Delta E_{{\rm diss},j,i}Q_{j,i}}
{\sum_j \Delta E_{{\rm diss},j,i}}.
\]
The combined secondary state reported to the observer stage is
\[
M_{\rm sec,tot}=\sum_j M_{{\rm sec},j},\quad
U_{\rm sec,tot}=\sum_j U_{{\rm sec},j},\quad
V_{\rm sec,tot}=\sum_j V_{{\rm sec},j},
\]
\[
B_{\rm sec,tot}=\left(8\pi\epsilon_{B,r}\frac{U_{\rm sec,tot}}{V_{\rm sec,tot}}\right)^{1/2},
\quad
p_{\rm sec,tot}=\frac{U_{\rm sec,tot}}{3V_{\rm sec,tot}},
\quad
w_{\rm sec,tot}=\frac{M_{\rm sec,tot}c^2+U_{\rm sec,tot}}{V_{\rm sec,tot}}+p_{\rm sec,tot}.
\]
The associated break-frequency diagnostics use the same energy weights,
\[
\bar{\gamma}_{m,{\rm sec}}=
\frac{\sum_j \Delta E_{{\rm diss},j}\gamma_{m,j}}
{\sum_j \Delta E_{{\rm diss},j}},
\]
\[
\nu_{m,{\rm sec}}=
\frac{4.2\times10^6 B_{\rm sec,tot}\bar{\gamma}_{m,{\rm sec}}^2}
{\langle\Gamma_{\rm c}\rangle[1-\beta(\langle\Gamma_{\rm c}\rangle)](1+z)},
\]
\[
\gamma_{c,{\rm sec}}=
\frac{7.7\times10^8(1+z)}
{\Gamma_2 B_{\rm sec,tot}^2T_{\rm obs}},
\qquad
\nu_{c,{\rm sec}}=
\frac{4.2\times10^6 B_{\rm sec,tot}\gamma_{c,{\rm sec}}^2}
{\Gamma_2(1-\beta_2)(1+z)}.
\]
The current multi-density reverse-shock path is deliberately narrow: it requires \(p_r>2\), a supported one-dimensional electron solver, \texttt{fullhide\_1d} or \texttt{dg\_1d}, the direct 1D observer path, no hadronic processes, no forward SSC cooling, no reverse SSC, no cross-zone IC, and separated electron-photon coupling.  The event windows are diagnostic roots obtained from linearly interpolated adjacent output states, and the adaptive RK refinement controls the first-RS variables \(\Gamma_2,R,M_2\), not a separate conservative error norm for every secondary branch variable.  The manuscript therefore treats the secondary reverse-shock outputs as a diagnostic branch, not as a general reverse-shock model \citep{DaiLu2002,NakarGranot2007,UhmZhang2014,Laskar2016GRB160509A,Alexander2017GRB160625B,Laskar2019GRB181201A,PangDai2024OffaxisRS}.

\section{Observer Projection and Component Assembly} \label{sec:projection}

Observer projection is performed after local luminosities have been assembled.  For a direct top-hat model with a supported medium, \asgard\ uses the direct kernel-backed path.  Other active jet profiles are solved as angular patches through either the Fortran structured backend or the Python patch backend.  The Fortran structured backend currently requires uniform patch sampling and a supported one-dimensional electron solver, \texttt{fullhide\_1d} or \texttt{dg\_1d}; it does not migrate reverse-shock SSC, cross-zone IC, reverse-shock hadronic branches, Bethe-Heitler, \(pp\), hadronic IC, or pair-cascade branches.  The \texttt{dominant\_region\_ioka\_v1} and \texttt{dominant\_region\_ioka\_time\_v1} samplers are restricted to \texttt{python\_patch}.

For a shell element with direction cosine \(\mu\) relative to the line of sight, observer time is computed from
\[
t_{\rm obs}=(1+z)\left(T-\frac{R\mu}{c}\right).
\]
This map is evaluated after local emissivity and optical-depth factors have been written on the radius grid.  The geometry kernel then interpolates local component luminosities onto requested observer times rather than modifying the dynamics to match an observer-time feature.

The patch-level sum is
\[
F_\nu(t_{\rm obs})=
\sum_j \Delta\Omega_j\,
\mathcal{I}_j[
L_{\nu'}'(R),\Gamma(R),R,t_{\rm obs},\nu],
\]
where \(\mathcal{I}_j\) denotes the interpolation/projection operator and \(\Delta\Omega_j\) is the angular element.  For an axisymmetric surface element,
\[
\Delta\Omega_j=
2\pi(\cos\theta_a-\cos\theta_b),
\]
while a two-dimensional patch uses
\[
\Delta\Omega_j=
(\phi_b-\phi_a)(\cos\theta_a-\cos\theta_b).
\]
The same component arrays are projected for total flux and for component-resolved fluxes.  A sky image is rendered from the projected state and compared with the direct flux.  Polarization is computed through the supported synchrotron Stokes-emissivity paths \citep{Sari1999Polarization,GhiselliniLazzati1999}:
\[
\{I,Q,U\}_\nu
=
\int j'_{\nu'}\mathcal{D}^3
\{1,\Pi\cos2\psi,\Pi\sin2\psi\}
\,d\Omega\,dR .
\]
The supported magnetic geometries are \texttt{shock\_random} and axisymmetric \texttt{toroidal}.  The intrinsic polarization fraction is either the analytic synchrotron value \(\Pi=(p+1)/(p+7/3)\) or a frequency-local synchrotron-kernel value in the \texttt{analytic\_then\_kernel} path.  Stokes sums are accumulated for forward synchrotron, reverse synchrotron, hadronic synchrotron, and reverse-hadronic synchrotron when those components exist.  Polarization is not assigned by analogy to neutrinos, SSC, or generic hadronic components.

The geometry kernel options are \texttt{sed\_legacy}, \texttt{sed\_adaptive\_theta}, and \texttt{chi\_eats\_2d}.  The \(\chi\)-resolved projection requires a two-dimensional electron solver and the stored \(\chi\)-resolved luminosity, optical depth, radius, bulk Lorentz factor, and volume weights.  Its finite-cell self-absorption transfer averages through the emitting cell instead of applying a single front-face optical depth, and the interpolation handles nonmonotonic \(\chi\)-arrival ordering by sorting cell arrival times before accumulation.  This path replaces only the forward-shock synchrotron plus SSA light-curve projection; SSC, hadronic, and pair-cascade components remain shell-level components.  An off-axis top-hat projection also requires \(\texttt{num\_phi}\ge2\); \(\texttt{num\_phi}=1\) is only valid for the on-axis collapsed case.

\subsection{Ray-traced synchrotron self-absorption in the \texorpdfstring{\(\chi\)}{chi}-resolved projection}

The \(\chi\)-resolved synchrotron projection treats synchrotron self-absorption as a local comoving transfer problem followed by a global ray projection.  For an angular cell centered at \((\theta,\phi)\), the line-of-sight cosine is
\[
\mu=\hat{\boldsymbol n}\cdot\hat{\boldsymbol r}
=\cos\theta_v\cos\theta+\sin\theta_v\sin\theta\cos\phi .
\]
The equal-arrival-time condition for a downstream cell at radius \(R_\chi\) is
\[
T_{\rm obs}=(1+z)\left(t_{\rm lab}-\frac{\mu R_\chi}{c}\right).
\]
Equivalently, in the stored radius-ordered variables the projection solves
\[
T_{\rm obs}=T_0(R)+\frac{1+z}{c}\left[R_{\rm front}(R)-\mu R_\chi(R)\right],
\]
and interpolates local quantities between the two radius grid points that bracket the requested observer time.

The Doppler factor is written through
\[
D=\Gamma(1-\beta\mu)=\delta^{-1},
\qquad
\nu'=(1+z)D\nu_{\rm obs}.
\]
For an angular element
\[
d\Omega=\left(\cos\theta_{\rm lo}-\cos\theta_{\rm hi}\right)d\phi ,
\]
the optically thin contribution is
\[
dF_{\nu_{\rm obs}}=
\frac{1+z}{4\pi D_L^2}\,
\frac{d\Omega}{4\pi}\,
D^{-3}L'_{\nu'}\,W_\chi ,
\]
where \(L'_{\nu'}\) is the comoving synchrotron luminosity of the \(\chi\) cell and \(W_\chi\) is the stored downstream volume weight.  Frequency interpolation is performed in \(\log\nu'\)-\(\log L'_{\nu'}\) and \(\log\nu'\)-\(\log\tau'_{\nu'}\) space where both adjacent values are positive.

The absorption coefficient is a comoving quantity, so the optical depth along a ray segment is
\[
d\tau'_{\nu'}=\alpha'_{\nu'}\,ds' .
\]
If the local radial optical-depth grid stores
\[
\tau'_{\nu',{\rm rad}}=\alpha'_{\nu'}\Delta r',
\qquad
\Delta r'=\Gamma\left(r_{\rm out}-r_{\rm in}\right),
\]
then a ray segment of comoving length \(\Delta s'\) contributes
\[
\tau'_{\nu',{\rm ray}}=
\tau'_{\nu',{\rm rad}}\frac{\Delta s'}{\Delta r'} .
\]
For a foreground cell this length is defined by the intersection of the source ray with the cell volume.  The lab-frame ray is
\[
\boldsymbol x(s)=\boldsymbol x_{\rm src}+s\hat{\boldsymbol n},
\qquad s>0 .
\]
For the foreground cell with local radial direction \(\hat{\boldsymbol e}_{r,{\rm fg}}\),
\[
\mu_{\rm fg}=\hat{\boldsymbol n}\cdot\hat{\boldsymbol e}_{r,{\rm fg}},
\qquad
\Delta s'_{\rm fg}=
\Gamma_{\rm fg}\left(1-\beta_{\rm fg}\mu_{\rm fg}\right)
\Delta s_{\rm lab}.
\]
The segment \(\Delta s_{\rm lab}=s_{\rm out}-s_{\rm in}\) is the positive line-cell intersection length.  In a local cell basis \((r,\theta,\phi)\), the intersection is computed by the slab equations
\[
x_i(s)=x_{0,i}+s n_i,
\]
\[
s_{\rm in}=\max_i\left[\min\left(\frac{x_{i,{\rm lo}}-x_{0,i}}{n_i},
\frac{x_{i,{\rm hi}}-x_{0,i}}{n_i}\right)\right],
\qquad
s_{\rm out}=\min_i\left[\max\left(\frac{x_{i,{\rm lo}}-x_{0,i}}{n_i},
\frac{x_{i,{\rm hi}}-x_{0,i}}{n_i}\right)\right].
\]
A foreground cell contributes only when \(s_{\rm out}>s_{\rm in}\).  Its optical-depth contribution is therefore
\[
\tau'_{\nu',{\rm fg}}=
\tau'_{\nu',{\rm rad,fg}}\,
\frac{\Gamma_{\rm fg}(1-\beta_{\rm fg}\mu_{\rm fg})\Delta s_{\rm lab}}
{\Gamma_{\rm fg}(r_{\rm out}-r_{\rm in})}
=
\tau'_{\nu',{\rm rad,fg}}\,
\frac{(1-\beta_{\rm fg}\mu_{\rm fg})\Delta s_{\rm lab}}
{r_{\rm out}-r_{\rm in}} .
\]
The foreground attenuation of a source cell is
\[
\tau_{\rm front}=\sum_{\rm fg}\tau'_{\nu',{\rm fg}} .
\]

The emitting cell is treated as a uniform source and absorber over its own ray segment.  Its transfer factor is
\[
\mathcal{E}(\tau_{\rm cell})=
\frac{1-\exp(-\tau_{\rm cell})}{\tau_{\rm cell}},
\qquad
\tau_{\rm cell}=\tau'_{\nu',{\rm rad}}\frac{\Delta s'_{\rm cell}}{\Delta r'} .
\]
The final ray-traced synchrotron contribution is
\[
F_{\nu_{\rm obs}}(T_{\rm obs})=
\sum_{\rm EATS\ cells}
\frac{1+z}{4\pi D_L^2}
\frac{d\Omega}{4\pi}
D^{-3}
L'_{\nu'}W_\chi
\exp(-\tau_{\rm front})
\frac{1-\exp(-\tau_{\rm cell})}{\tau_{\rm cell}} .
\]
This expression is nonlocal in angle because a foreground cell can attenuate emission from a different angular cell.  Consequently, local flux-pair criteria such as \(F(A\cup B)=F(A)+F(B)\) are not valid convergence tests for ray-traced SSA.  The supported convergence checks are global resolution tests in \(\theta\), \(\phi\), \(\chi\), and radius, while adaptive initial grids may only choose the starting angular resolution before the global ray projection is evaluated.

\section{Fitting, Runtime, and Reproducibility} \label{sec:fitting}

The fitting layer changes neither the dynamics nor the radiation kernels.  It binds model parameters to public constructors, solves the state chain, and evaluates residuals against observation blocks.  For flux-density and spectral points the implemented log likelihood is the Gaussian residual sum
\[
\ln\mathcal{L}
=-\frac{1}{2}\sum_i
\left[
\frac{F_i-F_{\rm model}(t_i,\nu_i)}{\sigma_i}
\right]^2 ,
\]
with the normalization term omitted because the current likelihood is used for parameter comparison at fixed data uncertainties.  Band-flux blocks integrate \(F_\nu\) over sampled frequencies before the residual is formed.

The public fitting interface supports flux-density blocks, spectra at a fixed observer time, band-integrated fluxes, and exposure-averaged flux queries.  Exposure averaging uses Gauss--Legendre nodes across each exposure interval and a pair cache keyed by \((t_{\rm obs},\nu)\), so repeated data blocks reuse solved observer pairs rather than changing the underlying physical model.  The same runtime state also supports direct flux, spectrum, sky-image, polarization, and component-output queries.  These interfaces are part of the reproducibility contract, but installation commands and temporary benchmark scripts are kept out of the scientific argument.

\section{Unsupported Boundaries} \label{sec:limits}

The current release rejects or excludes the following combinations.
\begin{itemize}
\item User-defined medium kernels do not dispatch to the Fortran backend.
\item Wind media support \(k=2\) only.
\item Tabulated media are limited to 96 positive, strictly increasing radius-density points.
\item Density jumps are limited to eight Gaussian jumps.
\item Jet spreading is not implemented in the current backend.
\item Adaptive observer-time grids are limited to direct top-hat kernel-backed models.
\item The structured Fortran backend requires uniform patch sampling and either \texttt{fullhide\_1d} or \texttt{dg\_1d}; the non-uniform dominant-region samplers require the Python patch backend.
\item Thermal electrons are limited to the one-dimensional implicit electron solvers.
\item Formal hadronic transport requires a one-dimensional forward electron solver.
\item The legacy hadronic transport branch does not support \(p\gamma\) or neutrino channels.
\item Joint electron-photon coupling requires the one-dimensional implicit electron solver, the AM3-based one-dimensional hadronic solver, Hummer--2010 photohadronic response, enabled Bethe-Heitler physics, numeric IC/KN cooling, no reverse shock, no \(\chi\)-resolved transport, and fixed electron substeps.
\item Multi-density reverse-shock v1 requires \(p_r>2\) and excludes hadronic processes, forward SSC, reverse SSC, cross-zone IC, and joint electron-photon coupling.
\item The current formal hadronic path is not chi-resolved.
\item Pair-cascade iterations cover shell-sequence \(\gamma\gamma\) pair/synch feedback, not IC-mediated electromagnetic cascades.
\item \texttt{toroidal} polarization currently requires an axisymmetric jet; non-axisymmetric toroidal Stokes projection is not implemented.
\item \texttt{chi\_eats\_2d} replaces only forward-shock synchrotron plus SSA projection; it does not make SSC, hadronic emission, or pair cascades \(\chi\)-local.
\end{itemize}
These limits are part of the published method.  A future extension should add a physical contract and validation evidence before the manuscript claims support for a new case.

\section{Summary} \label{sec:summary}

\asgard\ is a radius-ordered GRB afterglow toolkit whose observer products are derived from an inspectable state chain.  The present manuscript documents the model as implemented: supported media, jet constructors, dynamics branches, electron solvers, photon-field state, one-dimensional hadronic transport, reverse-shock diagnostics, component assembly, fitting interfaces, and projection boundaries.  Its core object is \(\mathcal{S}(R)\), not a final light curve alone.  The validation figures support state inspection, component accounting, bounded comparisons, reverse-shock diagnostics, and exposed electron/feedback quantities.  The current limitations are part of the model contract: unsupported couplings are rejected or explicitly excluded rather than treated as hidden defaults.
