## 验证层级

```bash
rtk bash -lc 'source ~/.wsl_env && cd "/mnt/c/Users/jia/Documents/New project/ASGARD_GRBAfterglow" && git diff --check'
```

Fortran 重要改动必须跑：

- 受影响 `build_extensions.py --module ... --force`
- `gfortran -Wall -Wline-truncation -fsyntax-only`
- 最小相关 smoke test

Line check 必须从 `/tmp` 执行，并指定临时 `-J` / `-I` 目录。

## Artifact Policy

Commit:

- Reproducible benchmark figures intended as documentation assets.
- CSV summaries if generated by committed scripts and physically accepted.
- Scripts and documentation needed to reproduce figures.

Do not commit:

- `.buildcache/`
- `__pycache__/`
- temporary debug scripts
- failed placeholder images
- partial CSV files
- one-off notebook exports
- local compiled `.so`, `.o`, `.mod`

## Physical Acceptance

Forward-shock:

- Light curves should be smooth unless a physical density jump or injection event produces a documented feature.
- Characteristic frequencies should evolve continuously.
- SSA breaks should not show grid-cell discontinuity.

Reverse-shock:

- `sigma -> 0` must recover unmagnetized baseline.
- `B3`, `gamma34`, `U3/V3`, `nu_m`, `nu_c`, `nu_a` should be smooth.
- VegasAfterglow is comparison backend, not target truth.

Hadronic:

- Enabled processes must be explicitly listed.
- Formal path must remain shell-level 1D until chi-local contract is defined.
- Pair cascade must conserve interpretation as gamma-gamma pair/synch branch, not IC-mediated cascade.

Polarization:

- Peak amplitude and peak time are separate diagnostics.
- Do not correct timing mismatch with empirical time shift or smoothing.

## Failure Handling

If a validation fails:

1. Identify the exact command and artifact.
2. Determine whether failure is compile, API, numerical, or physical.
3. Inspect the smallest source closure.
4. Avoid adding fallback or guard code unless the failure is at a real system boundary.
5. Rerun the narrowest check that exercises the fix.
